# 추론

[훈련](/docs/physical-labs/training)에서 만든 정책(모델)을 실제 로봇에 올려 봅니다. 추론에서는 리더암을 잡은 사람 대신 **정책이 카메라 영상과 관절 값을 보고 팔의 다음 동작을 정합니다.** 이 페이지는 **추론** 탭에서 모델을 고르고, 시작 전 검사를 통과하고, 안전하게 멈추는 방법을 다룹니다.

> 🎯 **학습 목표**
>
> - 로컬 모델과 Hugging Face Hub 모델의 차이를 알고 알맞은 모델을 고를 수 있다.
> - 추론을 시작하기 전에 앱이 무엇을 검사하는지 설명할 수 있다.
> - 실행 화면의 상태 · Hz · 로그를 보고 추론이 제대로 도는지 판단할 수 있다.
> - 두 단계 정지(시작 자세로 복귀 → 즉시 정지)로 로봇을 안전하게 멈출 수 있다.

## 1. 추론 탭 알아보기

### 1.1. 텔레오퍼레이션과 무엇이 다른가요?

추론은 [텔레오퍼레이션](/docs/physical-labs/teleoperation)과 같은 방식으로 돌아갑니다. 1초에 여러 번 로봇의 관측(카메라 영상 · 관절 값)을 받고 팔에 명령을 보냅니다. 달라지는 것은 **명령을 만드는 쪽**입니다.

| | 텔레오퍼레이션 | 추론 (이 페이지) |
|---|---|---|
| 팔을 움직이는 것 | 사람 (리더암) | 학습한 정책 |
| 리더암 | 필요합니다 | 필요 없습니다 |
| 멈추는 방법 | 리더암을 멈추면 팔도 멈춥니다 | **■ 정지** 를 누를 때까지 멈추지 않습니다 |

> **경고** ⚠️ `WARN`
> <br>**추론 중에는 로봇이 스스로 움직입니다** 리더암을 놓아도 멈추지 않고, 시작하는 순간 팔이 정책이 예측한 자세로 바로 움직입니다. 처음 돌리기 전에 [7절 안전 수칙](#7-안전-수칙)을 꼭 읽으세요.

### 1.2. 준비물

| 준비물 | 설명 |
|---|---|
| 학습한 모델 | [훈련](/docs/physical-labs/training) 탭에서 학습한 체크포인트, 또는 Hugging Face Hub 에 올린 모델. 앱이 다루는 종류는 **ACT** · **SmolVLA** · **X-VLA** · **GR00T** 입니다. |
| 같은 기종의 로봇 | 정책을 학습한 데이터셋을 모은 로봇과 **같은 기종**이어야 합니다. 관절 수가 SO-101 은 6개, SO-102 는 7개, LeKiwi 는 9개(팔 6 + 바퀴 3)라서 기종이 다르면 시작되지 않습니다. |
| 로봇 설정 | SO-101 · SO-102 는 **follower 포트**와 **카메라**, LeKiwi 는 **로봇 주소**를 저장해 둡니다. [로봇 설정](/docs/physical-labs/robot-settings)을 보세요. |
| 팔로워 보정 | [칼리브레이션](/docs/physical-labs/calibration)에서 보정을 마친 팔로워. 리더암은 쓰지 않으므로 꽂혀 있지 않아도 됩니다. |
| 기능 패키지 | **로봇 제어 패키지** · **데이터 패키지**. 탭을 처음 열면 설치 카드가 뜹니다. |
| Hugging Face 토큰 (선택) | Hub 의 내 모델 목록을 보려면 필요합니다. [설정](/docs/physical-labs/settings)에 저장합니다. |
| 작업 환경 | 데이터를 모을 때와 같은 물체 · 배치 · 조명 · 카메라 각도. 정책은 배운 장면과 비슷할 때 가장 잘 움직입니다. |

### 1.3. 들어가는 길

**[앱]** 사이드바 **로봇 창고** → 로봇 카드 → 위쪽 탭 줄의 **추론** 을 누릅니다. 사이드바 **최근 로봇** 에서 바로 들어가도 됩니다. 추론 탭은 두 화면으로 되어 있습니다.

1. **모델 선택** — 어떤 정책을 쓸지 고릅니다 (2절).
2. **추론 실행** — 설정을 확인하고 **▶ 추론하기** 로 시작, **■ 정지** 로 멈춥니다 (3~5절).

기능 패키지가 아직 없으면 탭 자리에 `추론을 사용하려면 추가 설치가 필요합니다` 카드가 뜹니다. **설치하기** 를 누르면 로봇 제어 패키지와 데이터 패키지를 받고(합계 내려받기 약 338MB, 약 3분), 끝나면 추론 화면이 바로 열립니다. 자세한 과정은 [기능 패키지 설치](/docs/physical-labs/feature-packs)에 있습니다.

> **정보** ℹ️ `INFO`
> <br>**이 문서는 Ubuntu 판 0.1.9 기준입니다** Windows 판(최신 0.1.7)은 SO-102 와 새 A-Go(ROS 2 SD 이미지)를 지원하지 않으므로, 이 두 로봇은 Windows 에서 추론할 수 없습니다.

## 2. 모델 고르기 [앱]

![추론 탭의 모델 선택 화면 — 왼쪽은 로컬 모델 목록, 오른쪽은 HuggingFace Hub 목록](/img/physical_labs/inference-model-select.webp)

*`모델 선택` 화면입니다. 왼쪽은 이 PC 에 있는 모델, 오른쪽은 Hugging Face 계정의 모델입니다 (오른쪽 목록은 가렸습니다).*

카드를 누르면 바로 **추론 실행** 화면으로 넘어갑니다. 모델은 두 곳에서 고릅니다.

### 2.1. 💾 로컬 모델

이 PC 에 있는 모델입니다. 카드 이름은 두 가지 모양입니다.

| 카드 이름 | 무엇인가 |
|---|---|
| `<로봇>/<정책>/<데이터셋> — 020000 step · 최신` (예: `lekiwi01/act/pick_and_place_1004 — 020000 step · 최신`) | 이 PC 의 **훈련** 탭이 만든 체크포인트입니다. 지금 연 로봇뿐 아니라 **모든 로봇**의 학습 결과가 함께 보입니다. 예전 판이 쓰던 저장 위치의 학습도 찾아 주는데, 이때는 위 그림의 `act_lekiwi/…/checkpoints — 100000 step · 최신` 처럼 이름 모양이 다를 수 있습니다. |
| `<계정>/<모델 이름>` (예: `HueyWoo/lekiwi_pick_and_place_act`) | 이 PC 에 한 번 내려받은 Hub 모델입니다. |

- 카드 둘째 줄은 종류와 날짜입니다 (예: `ACT · 2026-10-04`, 이 PC 에 받은 Hub 모델은 종류만). 종류는 `ACT` · `SMOLVLA` · `XVLA` · `GROOT` 네 가지만 목록에 나옵니다.
- 학습은 정해진 간격마다 체크포인트를 남기므로 한 학습에서 카드가 여러 장 나옵니다. 가장 많이 학습한 것에 `· 최신` 이 붙고, 많이 학습한 것부터 위에 놓입니다. 보통 `· 최신` 부터 써 보고, 움직임이 이상하면 앞 체크포인트와 비교합니다.
- 목록이 비어 있으면 `로컬에서 학습된 모델을 찾을 수 없습니다.` 가 보입니다.

> **팁** 💡`TIP`
> <br>**다른 PC 에서 학습했다면** 학습한 PC 의 `~/.PhysicalLabs/outputs/train/` 아래 학습 폴더를 이 PC 의 같은 위치로 복사하면 로컬 모델 목록에 나타납니다. 같은 Hugging Face 계정으로 Hub 에 올렸다면 오른쪽 목록에서 골라도 됩니다.

### 2.2. ☁ HuggingFace Hub

[설정](/docs/physical-labs/settings)의 **API 키** › **HuggingFace Access Token** 에 토큰을 저장해 두면, 그 계정의 모델이 오른쪽에 나옵니다. 상태 줄은 `불러오는 중...` 에서 `계정: HueyWoo` 처럼 바뀝니다.

- 토큰이 없으면 `HuggingFace 토큰이 설정되지 않았습니다.` 가 보입니다.
- 이 목록에는 그 계정의 **모든 모델**이 나옵니다. 로봇 정책이 아닌 모델을 고르면 불러오는 단계에서 오류가 납니다.
- 카드 둘째 줄은 `AUTO` 입니다. 종류는 모델을 내려받은 뒤에 앱이 알아냅니다.
- 처음 실행할 때 모델을 내려받으므로 `모델 로딩 중…` 이 길어집니다. 한 번 받은 모델은 다음부터 왼쪽 로컬 목록에도 나옵니다.

> **경고** ⚠️ `WARN`
> <br>**비공개(private) 모델은 내려받지 못할 수 있습니다** 오른쪽 목록은 설정에 저장한 토큰으로 불러오지만, 추론 탭이 모델을 내려받을 때는 그 토큰이 쓰이지 않습니다. 그래서 비공개 저장소의 모델은 목록에 보여도 `모델 로딩 중…` 에서 오류로 멈출 수 있습니다. 같은 PC 에서 학습했다면 로컬 체크포인트를 고르고, 다른 PC 에서 학습했다면 위 팁처럼 학습 폴더를 복사하세요.

### 2.3. 모델 지우기

오른쪽 위 **모델 삭제** 를 누르면 삭제 모드가 됩니다. 지울 카드를 눌러 고르고 **삭제 (N)** 을 누르면 확인 창이 뜹니다. 그만두려면 **취소** 를 누릅니다.

| 고른 카드 | 지워지는 것 |
|---|---|
| 로컬 체크포인트 | 그 체크포인트 폴더를 디스크에서 지웁니다 (되돌릴 수 없음). 학습에 남은 체크포인트가 하나뿐일 때 그것을 지우면 그 학습 폴더 전체가 지워집니다. |
| 이 PC 에 받은 Hub 모델 | 이 컴퓨터의 사본만 지웁니다. Hub 저장소는 그대로입니다. |
| Hub 저장소 (오른쪽 목록) | Hugging Face Hub 에서 그 모델을 **영구히** 지웁니다. 다른 사람 · 다른 PC 도 더 이상 받을 수 없습니다. |

학습이 진행 중일 때는 로컬 모델을 지울 수 없습니다.

## 3. 실행 화면 준비하기 [앱]

### 3.1. 화면 구성

![추론 실행 화면 왼쪽 칸의 위쪽 — 로봇 배너, 모델 이름과 정책 종류, 지시문, FPS, 로봇 정보](/img/a_go/app-lekiwi-inference.webp)

*새 A-Go(`lekiwi01`)에서 ACT 모델을 고른 실행 화면의 왼쪽 칸입니다. 배너 글은 로봇 상태에 따라 다릅니다. LeKiwi 는 **로봇 정보** 의 `port` 가 비어 있고 `cameras` 가 `없음` 으로 보여도 정상입니다 — 카메라 영상은 로봇에서 `front` · `wrist` 로 옵니다.*

<!-- 그림 필요: 추론 실행 화면 오른쪽 (SO-101 a-ba, 추론 중) — Follower 3D 뷰 · 카메라 뷰 · 상태 줄(추론 중 · NN.N Hz · 경과 시간) · 로그 -->

왼쪽은 설정, 오른쪽은 모니터입니다.

| 칸 | 설명 |
|---|---|
| **← 뒤로** | 모델 선택 화면으로 돌아갑니다. |
| 모델 경로 · `정책: ACT` | 고른 모델과 종류입니다. Hub 모델은 `정책: AUTO` 로 보입니다. |
| **지시문 (Instruction)** | VLA 모델에 주는 작업 문장입니다 (3.2절). |
| **FPS** | 1초에 명령을 보내는 횟수입니다. 기본 25, 5~120 (LeKiwi 는 최대 30). |
| **로봇 정보** | 추론에 쓸 로봇 설정입니다 (`type` · `id` · `port` · `cameras`). |
| **명령 미리보기** | 지금 설정을 명령줄 모양으로 보여 주는 참고용 글입니다 (3.4절). |
| **정지하면 시작 자세로 복귀** | 켜져 있으면(기본) 정지할 때 팔을 추론을 시작한 자세로 천천히 되돌립니다 (5절). |
| **▶ 추론하기** · **■ 정지** | 시작과 정지입니다. |
| **Follower 3D 뷰** | 팔로워(로봇 본체)의 지금 자세입니다. |
| **카메라 뷰** | 로봇의 카메라 영상입니다. 카메라가 없으면 `등록된 카메라가 없습니다.` 가 보입니다. |
| 상태 줄 | `대기 중` · `추론 중` 같은 상태, 실제 명령 횟수 `NN.N Hz`, 경과 시간 `00:00:00` 입니다. |
| 로그 | `[시작]` · `[상태]` · `[연결]` · `[정지]` · `[오류]` 같은 머리말로 시작하는 진행 기록입니다. |

### 3.2. 지시문 (VLA 모델)

| 모델 | 지시문 | 칸 아래 안내 |
|---|---|---|
| ACT | 없어도 됩니다 | `ACT 모델은 지시문 없이도 동작합니다. (선택사항)` |
| SmolVLA · X-VLA · GR00T | 필요합니다 | `이 모델은 지시문이 필요합니다.` |
| Hub 모델 (종류를 아직 모름) | 모델에 따라 다릅니다 | `모델 타입을 자동 감지합니다. 지시문을 입력하면 VLA 모델에 전달됩니다.` |

지시문은 할 일을 설명하는 문장 한 줄입니다 (예: `Pick up the red pen and place it in the pencil case`). 정책은 데이터를 모을 때 적은 태스크 설명으로 배웠으므로 그 문장을 그대로 쓰는 것이 좋습니다. VLA 모델이나 Hub 모델(종류를 아직 모름)인데 칸을 비우고 시작하면 `지시문 없음` 창이 한 번 더 묻습니다.

### 3.3. FPS

정책은 데이터를 모은 속도(FPS)에 맞춰 한 걸음씩 동작을 배웠습니다. 그래서 FPS 는 보통 **데이터를 모은 FPS 와 같게** 맞춥니다. [데이터 수집](/docs/physical-labs/data-record)의 기본값은 30 이고 이 칸의 기본값은 25 이니, 시작 전에 확인하고 바꾸세요.

LeKiwi 는 30 까지만 고를 수 있습니다. 로봇이 보내는 관측이 1초에 30번이라, 더 높여도 같은 관측으로 계산을 되풀이할 뿐 빨라지지 않습니다.

*같은 화면 왼쪽 칸의 아래쪽입니다.*

> **정보** ℹ️ `INFO`

## 4. 추론 시작하기

### 4.1. [로봇] 작업 자리 준비

시작하기 전에 로봇 쪽부터 정리합니다.

- 팔이 닿는 범위에서 사람 · 손 · 케이블 · 깨지기 쉬운 물건을 치웁니다.
- 물체 · 배치 · 조명 · 카메라 각도를 데이터를 모을 때와 같게 맞춥니다.
- 팔을 대략 작업 시작 자세(데이터를 모을 때 에피소드를 시작한 자세)에 둡니다.

### 4.2. [앱] 시작 전 검사

**▶ 추론하기** 를 누르면 앱이 아래 순서로 확인합니다. 1~5 는 하나라도 걸리면 창을 띄우고 시작하지 않습니다. 6 · 7 은 묻는 창이라 **Yes** 를 눌러야 이어 갑니다.

| 순서 | 확인하는 것 | 걸리면 | 할 일 |
|---|---|---|---|
| 1 | 모델 | `모델 경로를 선택하세요.` · `로컬 모델 경로를 찾을 수 없습니다:` | 모델을 다시 고릅니다 |
| 2 | 로봇 등록 | `로봇 설정 탭에서 로봇을 먼저 등록하세요.` | [로봇 설정](/docs/physical-labs/robot-settings) |
| 3 | 로봇 준비 | `로봇 준비 안 됨` 창 — SO-101 · SO-102 는 `로봇 설정 탭에서 follower 포트를 먼저 저장하세요.`, LeKiwi 는 화면 위 로봇 상태 줄이 알려 주는 이유 (예: `로봇이 꺼져 있습니다.`) | follower 포트 저장 / 로봇 켜기 (6절) |
| 4 | 정책과 로봇 | `정책과 로봇이 맞지 않습니다` 창 | 4.3절 |
| 5 | 라이브러리 | `lerobot 미설치` 창 | 탭을 다시 열어 설치 카드에서 설치하거나 **설정** › **기능 패키지** 에서 설치 |
| 6 | 지시문 | `지시문 없음` 창 (VLA · Hub 모델인데 칸이 비었을 때) | 지시문을 쓰거나, 그대로 하려면 **Yes** |
| 7 | 마지막 확인 | `자율 동작 시작` 경고 창 | 4.4절 |

### 4.3. [앱] 정책과 로봇이 맞는지 — 호환 검사

정책을 불러오는 데는 길면 수십 초가 걸립니다. 그 뒤에 어긋남이 드러나면 원인을 찾기 어려우므로, 앱은 불러오기 **전에** 모델 폴더의 설정을 읽어 확실히 맞지 않는 경우를 막습니다.

| 비교하는 것 | 맞지 않을 때 보이는 글 | 할 일 |
|---|---|---|
| 관절 수 (SO-101 6 · SO-102 7 · LeKiwi 9) | `이 정책은 관절 9개짜리 로봇용으로 학습됐습니다. 이 로봇(so101_follower)은 6개입니다. …` | 이 로봇으로 모은 데이터셋으로 학습한 정책을 고릅니다 |
| 상태 차원 | `이 정책은 상태 N차원을 입력으로 받습니다. …` | 위와 같습니다 |
| 카메라 이름 | `이 정책은 다음 카메라 영상을 요구합니다: front, wrist … 이(가) 없어 추론을 시작할 수 없습니다.` | 로봇 카메라 이름을 데이터를 모을 때와 같게 맞춥니다 |

- **SO-101 · SO-102** 의 카메라 이름은 [로봇 설정](/docs/physical-labs/robot-settings)의 카메라 줄에 적은 이름입니다. 데이터를 모은 뒤 이름을 바꾸면, 그 데이터로 학습한 정책은 시작되지 않습니다.
- **LeKiwi** 는 카메라 이름이 `front` · `wrist` 로 정해져 있습니다.
- SmolVLA · X-VLA 는 쓰는 카메라 가운데 하나만 맞아도 시작합니다. 하나도 없으면 `정책이 쓰는 카메라가 하나도 없어 추론을 시작할 수 없습니다.` 가 뜹니다.
- 사전학습 모델에서 파인튜닝한 SmolVLA · X-VLA 는 학습 때 맞춘 카메라 이름 짝이 모델에 함께 저장되고, 추론에도 그대로 쓰입니다. 따로 할 일은 없습니다.
- 정책이 쓰지 않는 카메라가 더 있으면 막지 않고 로그에 `[알림] 정책이 사용하지 않는 카메라가 있습니다: … (영상만 표시됩니다)` 를 남깁니다.

> **경고** ⚠️ `WARN`
> <br>**Hub 모델은 이 검사를 건너뜁니다** 오른쪽 Hub 목록의 모델과 로컬 목록의 `<계정>/<모델 이름>` 카드(이 PC 에 받은 Hub 모델)는 앱이 설정을 미리 읽지 않아 검사 없이 넘어갑니다. 관절이나 카메라가 맞지 않으면 모델을 다 불러온 뒤 `추론 오류` 로 멈춥니다. 확실하지 않으면 이 PC 의 학습 체크포인트를 쓰세요.

### 4.4. [앱] `자율 동작 시작` 경고

마지막으로 경고 창이 뜹니다. 창에 적힌 내용은 이렇습니다.

- 지금부터 학습된 정책이 스스로 로봇 팔을 움직입니다. 리더암을 놓아도 멈추지 않습니다.
- 시작하는 순간 팔이 정책이 예측한 자세로 즉시 이동합니다.
- 로봇 주변에 사람 · 물건이 없는지 확인하세요.
- 팔을 대략 작업 시작 자세에 두고 시작하세요.
- 이상하면 즉시 [■ 정지] 를 누르세요.

<!-- 그림 필요: `자율 동작 시작` 경고 창 — 위 다섯 줄과 Yes / No 버튼 (기본 선택 No) -->

기본 선택은 **No** 입니다. 주변을 확인했으면 **Yes** 를 눌러 시작합니다.

### 4.5. [앱] 시작된 뒤 화면

상태 줄이 `연결 중…` → `모델 로딩 중…` → `로봇 연결 중…` → `추론 중` 으로 바뀌고 (LeKiwi 는 중간에 `카메라 확인 중…`), 로그에 `[연결] 모델·로봇 연결 완료` 가 찍힙니다.

| 보이는 것 | 뜻 |
|---|---|
| `모델 로딩 중…` 이 오래 걸림 | 정책을 불러오는 중입니다. 큰 모델일수록 오래 걸리고, Hub 모델을 처음 쓸 때는 내려받기까지 해서 더 걸립니다. |
| `NN.N Hz` | 실제로 1초에 명령을 보낸 횟수입니다. **FPS** 에 가까우면 정상입니다. 크게 낮으면 이 PC 가 정책 계산을 따라가지 못하는 것입니다. |
| `추론 오류` 창 | 실행 중 오류가 나면 창이 뜨고 추론이 저절로 멈춥니다. 이때는 시작 자세로 돌아가지 않습니다. |

추론에는 **에피소드 수나 시간 제한이 없습니다.** **■ 정지** 를 누를 때까지 계속 돌고, 추론 장면을 데이터셋으로 녹화하는 기능도 없습니다. 정책이 얼마나 잘하는지 재려면 같은 배치에서 정해 둔 횟수만큼 시작 · 정지를 되풀이하며 성공 여부를 직접 기록하세요.

## 5. 멈추기 — 두 단계 정지 [앱]

**■ 정지** 는 두 단계로 동작합니다 (**정지하면 시작 자세로 복귀** 가 켜져 있을 때).

| 누르는 때 | 일어나는 일 | 화면 |
|---|---|---|
| **■ 정지** 첫 번째 | 정책을 멈추고, 팔을 **추론을 시작한 순간의 자세**로 천천히 되돌립니다 (초당 약 45°, 0.5~5초). | 상태 `시작 자세로 복귀 중…`, 버튼이 **■ 즉시 정지** 로 바뀜, 로그 `[정지] 시작 자세로 복귀합니다 — 다시 누르면 즉시 정지` |
| 복귀 중 **■ 즉시 정지** | 복귀를 끊고 그 자리에서 바로 멈춥니다. | 로그 `[정지] 즉시 정지 — 복귀를 중단합니다` |

<!-- 그림 필요: 정지 중 화면 — 상태 줄 `시작 자세로 복귀 중…` 과 `■ 즉시 정지` 로 바뀐 버튼 -->

- **정지하면 시작 자세로 복귀** 를 끄면 첫 번째 **■ 정지** 에서 바로 멈춥니다.
- 다음 경우에는 복귀 없이 바로 멈춥니다: 다른 탭으로 이동(`탭 이동` 확인 창), 사이드바 메뉴(홈 · 로봇 창고 · 설정 등)로 이동(묻지 않고 멈춤), **← 뒤로**(`추론이 진행 중입니다. 중단하고 돌아가시겠습니까?`), 앱 종료, 오류.
- 다 멈추면 로그에 `[종료] 정지됨 (경과 N초)` 가 찍히고 상태가 `대기 중` 으로 돌아갑니다.

> **경고** ⚠️ `WARN`
> <br>**SO-101 · SO-102 는 추론이 끝나면 팔로워의 힘이 풀려 처지거나 떨어집니다** 추론이 끝나며 로봇 연결을 끊을 때 모터 토크도 꺼지기 때문입니다. 첫 번째 **■ 정지** 는 시작 자세로 돌아온 뒤에, 즉시 정지 · 탭 이동 · 사이드바 이동 · **← 뒤로** · 오류로 멈추면 그 자리에서 바로 힘이 풀립니다. 시작 자세가 팔이 편히 놓이는 자세(접은 자세나 책상에 닿은 자세)가 아니라면, 멈출 때 편 팔을 받칠 준비를 하세요.

## 6. LeKiwi 로 추론할 때

LeKiwi 도 같은 화면으로 추론합니다. 팔 로봇과 다른 점만 모았습니다.

| 항목 | LeKiwi 에서는 |
|---|---|
| 준비 | follower · 리더암 포트는 필요 없습니다. [로봇 설정](/docs/physical-labs/robot-settings)에 로봇 주소를 저장해 둡니다. |
| 로봇 켜기 | 실행 화면 위 로봇 상태 줄(배너)에서 켭니다. 새 A-Go 는 **▶ 로봇 켜기**, 예전 SD 이미지 로봇은 **▶ 호스트 실행** 입니다. |
| 바퀴 | **늘 멈춰 있습니다.** 정책이 바퀴 값을 내도 앱이 0 으로 바꿔 보내고 팔만 움직입니다. 로그에 `[로봇] <로봇 주소> (원격 · 바퀴 정지 고정)` 이 찍힙니다. |
| 카메라 | `front` · `wrist` 두 대로 정해져 있습니다. |
| FPS | 최대 30 입니다. |
| 비상 정지 | 새 A-Go 는 배너에 **⛔ 비상 정지** 가 있습니다. 바퀴를 세우고 바퀴 · 팔 토크를 끄므로 **편 팔이 떨어집니다.** |

- 새 A-Go 는 웹 화면과 앱 가운데 한 곳만 로봇을 조작합니다. 웹 화면이 조작 권한을 쥐고 있으면 앱의 추론이 막히니(`웹 화면이 조작 중입니다`), 웹에서 권한을 놓은 뒤 시작하세요. 자세한 것은 [대시보드와 조작 권한](/docs/a-go/web-dashboard)에 있습니다.
- 노트북을 로봇 AP 에 붙이면 인터넷이 없어 Hub 목록을 불러오거나 새 모델을 내려받을 수 없습니다. 이때는 로컬 모델을 쓰세요. 앱은 켤 때 인터넷이 필요하므로, 인터넷이 될 때 앱을 먼저 켜 두고 와이파이를 바꿉니다 ([네트워크 (AP · 공유기)](/docs/a-go/lekiwi-wifi-static-ip)).

> **정보** ℹ️ `INFO`
> <br>**새 A-Go 의 추론은 아직 확인 중입니다** 새 SD 이미지(ROS 2) 로봇도 같은 화면에서 추론하도록 연결돼 있지만, 실제 로봇으로 정책을 돌려 보는 검증이 아직 끝나지 않았습니다. 로봇 켜기부터 추론까지의 흐름과 최신 안내는 [데이터 · 학습 · 추론](/docs/a-go/physical-labs-workflow)을 보세요.

## 7. 안전 수칙

| 언제 | 지킬 것 |
|---|---|
| 시작 전 | [4.1절](#41-로봇-작업-자리-준비)대로 주변을 비우고, 장면을 데이터를 모을 때와 같게 맞추고, 팔을 작업 시작 자세에 둡니다. 시작하는 순간 팔이 정책이 예측한 자세로 바로 움직이며, 앱이 그 사이를 부드럽게 이어 주지 않습니다. |
| 처음 쓰는 정책 | 덜 학습된 체크포인트일 수 있습니다. 짧게 돌려 보고 멈춰서 움직임을 확인합니다. |
| 실행 중 | 손을 **■ 정지** 가까이에 둡니다. 이상하면 바로 누르고, 되돌아가는 움직임도 위험해 보이면 한 번 더 눌러 즉시 멈춥니다. |
| 정지 뒤 | SO-101 · SO-102 는 팔로워의 힘이 풀립니다. 편 팔은 받칠 준비를 합니다 (5절). |
| 앱이 응답하지 않을 때 | **■ 정지** 가 듣지 않으면 로봇 전원을 끕니다. 전원이 끊기면 팔이 떨어지므로 받친 채 끕니다. |
| LeKiwi | 바퀴는 멈춰 있어도 팔은 움직입니다. **⛔ 비상 정지** 는 팔 힘까지 빼서 편 팔이 떨어집니다. |

## 8. 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 로컬 목록에 `로컬에서 학습된 모델을 찾을 수 없습니다.` | 학습이 체크포인트를 남길 만큼 진행됐는지 [훈련](/docs/physical-labs/training) 탭에서 확인합니다. 목록에는 ACT · SmolVLA · X-VLA · GR00T 만 나옵니다. 다른 PC 에서 학습했다면 2.1절 팁처럼 학습 폴더를 복사합니다. |
| Hub 칸에 `HuggingFace 토큰이 설정되지 않았습니다.` | [설정](/docs/physical-labs/settings) › **일반** › **API 키** 에 토큰을 저장합니다. |
| Hub 칸에 `Hub 조회 실패: …` | 인터넷 연결과 토큰을 확인합니다. 로봇 AP 에 붙어 있으면 인터넷이 없습니다. |
| `로봇 준비 안 됨` — `follower 포트를 먼저 저장하세요` | [로봇 설정](/docs/physical-labs/robot-settings)에서 follower 포트를 고르고 **로봇 저장** 을 누릅니다. |
| `로봇 준비 안 됨` — `로봇이 꺼져 있습니다.` (LeKiwi) | 화면 위 배너의 **▶ 로봇 켜기** 를 누르고, 배너 앞의 점이 초록으로 바뀐 뒤 다시 시작합니다. |
| `로봇 준비 안 됨` — `비상 정지가 걸려 있습니다.` (LeKiwi) | 주변을 확인하고 배너의 **비상 정지 풀기** 를 누릅니다. |
| `정책과 로봇이 맞지 않습니다` — 관절 수가 다름 | 다른 기종으로 모은 데이터셋으로 학습한 정책입니다. 이 로봇으로 모은 데이터셋으로 다시 학습합니다. |
| `정책과 로봇이 맞지 않습니다` — 카메라가 없음 | 로봇 설정의 카메라 이름을 데이터를 모을 때와 같게 맞춥니다. |
| `추론 오류` — `팔로워 보정 정보가 없습니다.` (SO-101 · SO-102) | [칼리브레이션](/docs/physical-labs/calibration)에서 팔로워를 보정합니다. |
| SmolVLA · X-VLA · GR00T 가 `모델 로딩 중…` 에서 오류로 멈춘다 | 이 모델들은 추가 라이브러리가 필요한데, 추론 탭은 이것을 따로 설치하지 않습니다. [훈련](/docs/physical-labs/training) 탭 › **새 학습** 에서 같은 모델 카드를 한 번 눌러 설치를 마친 뒤 다시 시도합니다. |
| Hub 모델이 `모델 로딩 중…` 에서 오류로 멈춘다 | 비공개 저장소이거나(2.2절), 로봇 정책이 아닌 모델이거나, 인터넷이 끊긴 경우입니다. |
| `NN.N Hz` 가 FPS 보다 크게 낮다 | 이 PC 가 정책 계산을 따라가지 못합니다. 앱을 처음 설치하면 PyTorch 가 CPU 버전이라, NVIDIA GPU 가 있다면 [훈련](/docs/physical-labs/training) 탭 › **환경 진단** 에서 GPU 버전 PyTorch 를 설치했는지 확인합니다. 학습처럼 무거운 작업을 함께 돌리고 있다면 멈추고 다시 봅니다. |
| `로봇에서 카메라 영상을 받지 못했습니다` (LeKiwi) | 로봇이 켜져 있는지, 카메라 두 대가 꽂혀 있는지 확인합니다 — [카메라 연결](/docs/a-go/setup-cameraport) |
| `웹 화면이 조작 중입니다` (새 A-Go) | 웹 화면에서 조작 권한을 놓습니다 — [대시보드와 조작 권한](/docs/a-go/web-dashboard) |
| `lerobot 미설치` | 탭을 다시 열어 설치 카드에서 설치하거나, **설정** › **기능 패키지** 에서 설치합니다 — [기능 패키지 설치](/docs/physical-labs/feature-packs) |

LeKiwi 로봇 쪽 문제는 [A-Go 문제 해결](/docs/a-go/troubleshooting), 앱 전체의 문제는 [문제 해결](/docs/physical-labs/troubleshooting)에 더 있습니다.

## 9. 정리

- 추론은 학습한 정책이 스스로 로봇 팔을 움직이는 모드입니다. 리더암이 필요 없고, **■ 정지** 를 누를 때까지 계속 움직입니다.
- 모델은 **로컬 모델**(이 PC 의 학습 결과 · 받아 둔 Hub 모델) 또는 **HuggingFace Hub**(토큰 필요)에서 고릅니다. 비공개 Hub 모델은 내려받지 못할 수 있습니다.
- 시작 전에 앱이 로봇 준비와 정책 호환(관절 수 · 카메라 이름)을 검사하고, `자율 동작 시작` 경고에서 **Yes** 를 눌러야 시작합니다.
- **FPS** 는 데이터를 모은 FPS 와 같게 맞추고, **명령 미리보기** 는 참고용으로만 봅니다.
- 정지는 두 단계입니다. 첫 번째는 시작 자세로 천천히 복귀, 복귀 중 한 번 더 누르면 즉시 정지합니다. SO-101 · SO-102 는 멈춘 뒤 팔로워의 힘이 풀립니다.
- LeKiwi 는 바퀴가 멈춰 있고 팔만 움직이며, FPS 는 30 까지입니다.
