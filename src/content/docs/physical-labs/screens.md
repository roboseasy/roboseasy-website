# 화면 둘러보기

로그인하면 Physical Labs 의 홈 화면이 나옵니다. 이 페이지에서는 홈 화면의 세 부분(위쪽 막대 · 사이드바 · 본문)이 하는 일과, 로봇을 만들어 작업 탭으로 들어가는 길을 안내합니다. 각 기능의 자세한 사용법은 해당 문서에서 다룹니다. 아직 로그인 전이라면 [설치와 첫 실행](/docs/physical-labs/install)을 먼저 보세요.

> 🎯 **학습 목표**
>
> - 홈 화면의 위쪽 막대 · 사이드바 · 본문이 하는 일을 구분할 수 있다.
> - 두 개의 **☰** 버튼(도구 메뉴 · 사이드바 접기)을 구분해 쓸 수 있다.
> - 새 로봇을 만들고, 로봇 작업 화면의 탭 7개로 들어갈 수 있다.
> - 탭에 붙는 표시(설치 아이콘 · 잠김)를 읽고, 설정과 화면 배율을 찾을 수 있다.

## 1. 홈 화면 한눈에

### 1.1. 세 부분

![Physical Labs 홈 화면 전체 — 위쪽 막대, 왼쪽 사이드바, 오른쪽 본문의 인사말](/img/physical_labs/home.webp)

*홈 화면입니다. 위쪽 막대 · 왼쪽 사이드바 · 오른쪽 본문으로 나뉩니다.*

| 부분 | 위치 | 하는 일 |
|---|---|---|
| **위쪽 막대** | 창 맨 위 | 도구 메뉴(**☰**)와 창 버튼(최소화 · 최대화 · 끄기) |
| **사이드바** | 왼쪽 | **모터 셋업** · **로봇 창고** · **데이터셋 창고** · **워크스페이스** 메뉴, 최근 로봇 목록, 맨 아래 계정 버튼 |
| **본문** | 오른쪽 | 고른 화면이 열리는 곳. 처음에는 "○○님, 오늘은 어떤 작업을 해볼까요?" 인사말이 보입니다 |

Physical Labs 창에는 운영체제의 제목 표시줄이 없습니다. 창을 옮기려면 위쪽 막대를 끌고, 위쪽 막대를 두 번 누를 때마다 최대화와 원래 크기를 오갑니다.

### 1.2. ☰ 버튼이 두 개입니다

모양이 같은 **☰** 버튼이 두 곳에 있어 헷갈리기 쉽습니다. 하는 일이 전혀 다릅니다.

| 버튼 | 위치 | 마우스를 올리면 | 누르면 |
|---|---|---|---|
| 도구 **☰** | 위쪽 막대 맨 왼쪽 (작은 ▾ 가 붙어 있음) | "도구" | 모터 · 팔 시험 도구 메뉴가 펼쳐집니다 (2.1절) |
| 사이드바 **☰** | 사이드바 맨 위, 💬 · 🏠 옆 | "사이드바 접기/펼치기" | 사이드바가 접혀 **☰** 와 계정 동그라미만 남습니다. 다시 누르면 펼쳐집니다 |

이 설명서에서는 둘을 '도구 메뉴(☰)' 와 '사이드바 접기(☰)' 로 나눠 부릅니다.

## 2. 위쪽 막대

### 2.1. 도구 메뉴 (☰)

위쪽 막대 맨 왼쪽의 **☰** 를 누르면 메뉴 세 개가 나옵니다. 로봇 작업 화면을 거치지 않고 모터나 팔을 바로 시험해 볼 수 있는 도구입니다.

![위쪽 막대의 도구 ☰ 를 눌러 펼친 메뉴 — 단일 모터 테스트 · SO-ARM 101 전체 테스트, 구분선 아래 End Effector Control](/img/physical_labs/menu-tools.webp)

*펼쳐진 도구 메뉴입니다. 메뉴 오른쪽에 보이는 사이드바 맨 위의 **☰** 와는 다른 버튼입니다.*

| 메뉴 | 하는 일 | 자세히 |
|---|---|---|
| **단일 모터 테스트** | 모터 한 대를 스캔 · 핑하고, ID 를 바꾸고, 상태를 보며 움직여 봅니다. **모터 셋업** 의 **단일 모터 셋업** 탭과 같은 화면입니다 | [모터 셋업](/docs/physical-labs/motor-setup) |
| **SO-ARM 101 전체 테스트** | 팔의 모터 6개를 한꺼번에 연결해 슬라이더로 하나씩 움직여 봅니다 | [모터 셋업](/docs/physical-labs/motor-setup) |
| **End Effector Control** | 로봇 작업 화면의 **엔드이펙터** 탭과 같은 조종 화면을 창 전체로 엽니다. 로봇 제어 패키지가 없으면 설치 창이 먼저 뜹니다 | [엔드이펙터](/docs/physical-labs/end-effector) |

도구 화면은 사이드바를 가리고 창 전체를 씁니다. 홈으로 돌아올 때는 오른쪽 위의 **◀ 뒤로**(End Effector Control 은 **← 뒤로**)를 누르세요. SO-ARM 101 전체 테스트의 빨간 **Quit** 은 그 화면만 닫아 빈 화면이 남으니 누르지 마세요 (남았을 때는 8절).

![SO-ARM 101 전체 테스트 화면의 윗부분 — 연결 설정 칸과 오른쪽 위 뒤로 · Quit 버튼](/img/physical_labs/motor-setup-soarm101-test.webp)

*SO-ARM 101 전체 테스트 화면입니다. 홈으로 돌아올 때는 **◀ 뒤로** 를 누릅니다.*

![End Effector Control 화면의 윗부분 — 로봇 · 포트 고르기, 연결 · Sync 확인 버튼, Joint Control · XYZ Control · Teaching Control 탭](/img/physical_labs/eef-window.webp)

*End Effector Control 화면입니다. 오른쪽 위 **← 뒤로** 로 홈에 돌아옵니다.*

> **경고** ⚠️ `WARN`
> <br>**SO-ARM 101 전체 테스트의 슬라이더는 실제 모터를 바로 움직입니다** 슬라이더를 끌거나 누르면 그 모터의 힘이 켜지고 곧바로 그 위치로 움직입니다. 팔 주변에서 손과 물건을 치운 뒤 쓰세요. 자세한 주의는 [모터 셋업](/docs/physical-labs/motor-setup)에 있습니다.

> **팁** 💡`TIP`
> <br>**도구를 열기 전에 탭의 연결을 끊으세요** 도구 화면을 열어도 로봇 작업 탭에서 연결해 둔 팔은 그대로 연결되어 있습니다. 같은 팔을 도구로 열려면 먼저 탭에서 연결을 끊거나, 사이드바에서 다른 메뉴를 한 번 눌러 연결을 정리하세요 (3.4절).

### 2.2. 그 밖의 버튼

| 버튼 | 하는 일 |
|---|---|
| **▯** · **⌕** · **‹** · **›** (도구 ☰ 오른쪽) | 아직 동작하지 않는 자리입니다 |
| **—** (오른쪽 끝) | 창을 최소화합니다 |
| **▢** | 창을 최대화하거나 원래 크기로 돌립니다 |
| **✕** | 앱을 끕니다 |

**✕** 를 누르면 기능 패키지를 설치하는 중일 때는 **설치 진행 중** 창이 떠서 언제 끌지 묻고(기본은 **설치가 끝나면 종료**), 학습 중일 때는 **앱 종료 확인** 창이 뜹니다. 그 밖에는 묻지 않고 바로 꺼집니다. **텔레오퍼레이션 · 데이터 수집 · 추론 중이어도 묻지 않고** 로봇 연결을 끊으니(녹화 중이던 에피소드는 저장되지 않습니다), 그 화면에서 먼저 멈춘 뒤 끄세요. 설치 중에 끌 때의 선택지는 [기능 패키지 설치](/docs/physical-labs/feature-packs)에서 설명합니다.

> **경고** ⚠️ `WARN`

## 4. 로봇 만들기

### 4.1. 로봇 창고

사이드바 **로봇 창고** 를 누르면 저장한 로봇이 카드로 보입니다. 카드의 굵은 글자는 로봇 이름(robot id), 아래 작은 글자는 기종입니다. 카드를 누르면 그 로봇의 작업 화면(5절)이 열립니다.

![로봇 창고 화면 — 제목 로봇, lekiwi01 · Lekiwi 카드 한 장, 오른쪽 위 + 로봇 추가 · − 로봇 삭제 버튼](/img/physical_labs/robots.webp)

*로봇 창고입니다. 오른쪽 위 **+ 로봇 추가** 로 새 로봇을 만듭니다.*

로봇이 하나도 없으면 "아직 등록된 로봇이 없습니다. ‘로봇 추가’ 를 눌러 등록하세요." 가 보입니다.

### 4.2. [앱] 새 로봇 만들기

1. 사이드바 **로봇 창고** → 오른쪽 위 **+ 로봇 추가** 를 누릅니다.
2. **새 로봇 생성** 창에서 기종 카드를 누릅니다. 흐린 카드(**준비 중**)는 아직 고를 수 없습니다.
3. 그 기종의 빈 로봇으로 작업 화면이 열립니다. 제목은 기종 이름이고, 첫 탭은 **로봇 설정** 입니다.
4. 이름과 포트를 채우고 **로봇 저장** 을 누릅니다. 저장해야 로봇 창고에 카드가 생깁니다. 채우는 방법은 [로봇 설정](/docs/physical-labs/robot-settings)에 있습니다.

![새 로봇 생성 창 — SO-101 · SO-102 · Lekiwi 카드와, 준비 중인 reBot · Dual SO-101 · Dual SO-102 카드](/img/physical_labs/new-robot-dialog.webp)

*기종을 고르는 **새 로봇 생성** 창입니다. 오른쪽 아래 **취소** 로 닫습니다.*

| 카드 | 언제 고르나요 |
|---|---|
| **SO-101** | A-Ba(SO-ARM101) 같은 6축 팔. 팔로워 팔 · 리더 팔 · 카메라를 PC 에 USB 로 꽂습니다 |
| **SO-102** | 로보시지 7축 팔. 연결 방식은 SO-101 과 같습니다 |
| **Lekiwi** | A-Go(LeKiwi). 리더암만 PC 에 꽂고, 로봇에는 네트워크로 붙습니다 → [Physical Labs 연결](/docs/a-go/physical-labs-setup) |

기종마다 쓸 수 있는 탭은 [소개](/docs/physical-labs)의 지원 로봇 표에 정리해 두었습니다.

> **경고** ⚠️ `WARN`
> <br>**로봇 창고의 − 로봇 삭제는 보정 파일까지 지웁니다** **− 로봇 삭제** 를 누르면 카드마다 체크 동그라미가 생깁니다. 고른 뒤 **선택 삭제 (N)** → 확인 창의 **Yes** → 관리자 비밀번호를 넣으면 지웁니다. 이때 로봇 설정과 함께 USB 포트 고정 규칙, 이 PC 의 칼리브레이션 파일도 지워집니다 (LeKiwi 는 리더암 보정만 이 PC 에 있습니다). 지운 보정은 다시 해야 하니 신중히 고르세요.

## 5. 로봇 작업 화면

### 5.1. 탭 7개

로봇 카드를 누르면 맨 위에 로봇 이름이, 그 아래에 탭 7개가 보입니다. 로봇 작업 화면에 들어올 때마다 첫 탭 **로봇 설정** 부터 열립니다.

![SO-101 로봇 a-ba 의 작업 화면 — 제목 a-ba 아래에 로봇 설정 · 칼리브레이션 · 엔드이펙터 · 텔레오퍼레이션 · 데이터 · 훈련 · 추론 탭](/img/physical_labs/robot-settings.webp)

*로봇 작업 화면입니다. 왼쪽 탭부터 차례로 진행합니다.*

| 탭 | 하는 일 | 처음 열 때 설치할 것 | 자세히 |
|---|---|---|---|
| **로봇 설정** | 로봇 이름 · USB 포트 · 카메라를 정하고 저장합니다. SO-101 · SO-102 는 모터 ID 셋업도 여기 있습니다 | 없음 | [로봇 설정](/docs/physical-labs/robot-settings) |
| **칼리브레이션** | 팔로워 · 리더 팔을 보정합니다 | 로봇 제어 패키지 | [칼리브레이션](/docs/physical-labs/calibration) |
| **엔드이펙터** | 화면에서 팔을 직접 움직이고 자세를 가르칩니다 | 로봇 제어 패키지 | [엔드이펙터](/docs/physical-labs/end-effector) |
| **텔레오퍼레이션** | 리더 팔로 팔로워 팔을 움직입니다 | 로봇 제어 · 데이터 패키지 | [텔레오퍼레이션](/docs/physical-labs/teleoperation) |
| **데이터** | 하위 탭 **수집** · **편집** — 데이터셋을 녹화하고 고칩니다 | 로봇 제어 · 데이터 패키지 | [데이터 수집](/docs/physical-labs/data-record) |
| **훈련** | 하위 탭 **환경 진단** · **새 학습** · **학습 재개** — 모델을 학습합니다 | 로봇 제어 · 데이터 · 학습 패키지 | [훈련](/docs/physical-labs/training) |
| **추론** | 학습한 모델로 로봇을 움직입니다 | 로봇 제어 · 데이터 패키지 | [추론](/docs/physical-labs/inference) |

탭은 처음 열 때 화면을 만듭니다. 그래서 탭을 처음 누르면 "○○ 준비 중입니다 / 처음 열 때만 시간이 걸립니다" 창이 잠깐 뜹니다. 두 번째부터는 바로 열립니다.

### 5.2. 탭에 붙는 표시

| 표시 | 뜻 | 할 일 |
|---|---|---|
| 탭 이름 옆에 연보라 동그라미 안 아래 화살표 | 그 탭을 쓰려면 기능 패키지를 더 설치해야 합니다. 마우스를 올리면 "처음 열 때 추가 설치가 필요합니다 (로봇 제어 패키지 · 데이터 패키지)" 처럼 필요한 패키지가 보입니다 | 탭을 열고 설치 카드의 **설치하기** 를 누릅니다 → [기능 패키지 설치](/docs/physical-labs/feature-packs) |
| 회색으로 흐려져 눌리지 않는 탭 | 이 기종에서는 아직 준비 중인 탭입니다. 마우스를 올리면 "SO-102 기종은 이 기능이 아직 준비 중입니다." 가 보입니다 | 없음 (지금은 SO-102 의 **엔드이펙터** 탭만 해당) |
| 표시 없음 | 바로 쓸 수 있습니다 | — |

### 5.3. 기종에 따라 달라지는 곳

| 기종 | 달라지는 곳 |
|---|---|
| **SO-101** | 탭 7개를 모두 씁니다 |
| **SO-102** | **엔드이펙터** 탭이 잠겨 있습니다 |
| **Lekiwi** | **로봇 설정** 탭의 포트 칸이 **Leader Arm (USB-PC 직결)** · **Lekiwi (원격)** · **Lekiwi (카메라)** 로 나뉘고, 로봇 주소 · **연결 확인** 이 생깁니다 (모터 ID 셋업 대신 안내 카드). **연결 확인** 으로 새 A-Go(ROS 2 로봇)임이 확인되면 **▶ 로봇 켜기** 도 생깁니다. 새 A-Go 에서는 **텔레오퍼레이션** · **데이터** · **추론** 화면 위에 로봇 상태 줄과 **▶ 로봇 켜기**(켜져 있으면 **■ 로봇 끄기**) · **⛔ 비상 정지** 버튼이 붙습니다. 비상 정지는 바퀴를 세우고 팔의 힘도 빼므로, 편 팔이 떨어집니다. **엔드이펙터** 탭은 열어도 "이 로봇(ROS2 LeKiwi)에서는 아직 지원하지 않습니다." 가 뜹니다. 자세한 것은 [Physical Labs 연결](/docs/a-go/physical-labs-setup) · [데이터 · 학습 · 추론](/docs/a-go/physical-labs-workflow)에 있습니다 |

### 5.4. 탭을 옮길 때

- 로봇과 연결하는 탭은 **한 번에 하나**입니다. 다른 탭으로 옮기면 떠나는 탭의 연결이 끊깁니다.
- 텔레오퍼레이션 · 데이터 수집 · 추론 · 보정이 진행 중일 때 다른 탭을 누르면 **탭 이동** 창이 뜹니다. "진행 중인 작업이 있습니다. 다른 탭으로 이동하면 작업이 중지되고 로봇 연결이 해제됩니다." 라는 안내와 함께 **Yes** · **No** 를 묻습니다. **No**(기본)를 누르면 원래 탭에 남습니다.
- 이 확인 창은 탭끼리 옮길 때만 뜹니다. 사이드바로 옮기면 묻지 않고 끊깁니다 (3.4절).

## 6. 설정 들어가는 곳

사이드바 맨 아래 계정 버튼 → **⚙ 설정** 을 누르면 설정 화면이 열립니다. 왼쪽에 칸 세 개가 있습니다.

| 칸 | 들어 있는 것 |
|---|---|
| **일반** | 프로필(이름 표시), **화면 배율**, **API 키**(HuggingFace Access Token · Wandb API Key — Wandb 키는 아직 학습에 넘어가지 않습니다) |
| **기능 패키지** | 기능 패키지마다 설치 상태, **모든 기능 한 번에 설치**, 지금 쓰는 PyTorch(CPU · GPU) |
| **계정** | **로그아웃**(이 PC 의 로그인만 지웁니다) · **계정 삭제**(아직 동작하지 않습니다) |

각 칸의 사용법은 [설정](/docs/physical-labs/settings)에 있습니다.

## 7. 화면 배율과 작은 화면

### 7.1. 화면 크기에 따른 자동 배율

앱은 모니터 크기에 비례해 글씨와 여백을 자동으로 맞춥니다. 화면이 작아도 글씨 크기는 줄지 않고, 대신 여백이 줄어듭니다. 그래도 넘치는 화면은 **스크롤**로 봅니다. 1366×768 노트북이나 1920×1080 화면에 150% 배율을 쓰는 PC 처럼 작은 화면에서 아래쪽 버튼이 보이지 않으면, 그 화면을 아래로 스크롤해 보세요.

앱을 켜면 창이 화면의 약 70% 크기로 가운데에 열립니다 (작은 화면일수록 더 크게 열립니다).

### 7.2. [앱] 직접 바꾸기

1. 계정 버튼 → **⚙ 설정** → **일반** 으로 갑니다.
2. **화면 배율** 에서 값을 고릅니다: `80%` · `90%` · `100% (권장)` · `125%` · `150%` · `175%` · `200%`.
3. **저장** 을 누르면 앱이 스스로 다시 켜지며 새 배율이 적용됩니다 (**저장** 은 값을 바꿔야 눌립니다).

| 상황 | 결과 |
|---|---|
| 기능 패키지를 설치하는 중 | 앱이 다시 켜지지 않고 저장만 됩니다. 다음에 켤 때 적용됩니다 |
| 학습 중 | 학습을 멈출지 먼저 묻습니다. **No** 를 고르면 저장만 되고 다음에 켤 때 적용됩니다 |
| 창을 다른 모니터로 옮김 | 글씨 · 여백 배율은 그대로입니다. 자동 배율은 앱을 켤 때 **주 모니터** 크기로 정해집니다 |

> **경고** ⚠️ `WARN`
> <br>**인터넷이 없을 때는 화면 배율을 바꾸지 마세요** 앱은 다시 켜질 때도 구글 로그인을 확인하므로 인터넷이 필요합니다. 노트북이 로봇 AP 처럼 인터넷이 없는 와이파이에 붙어 있을 때 저장하면, 다시 켜진 앱이 로그인 화면에서 멈춥니다. 인터넷이 되는 곳에서 바꾸세요.

## 8. 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 도구 **☰** 를 눌렀는데 사이드바가 접힌다 | 사이드바 맨 위의 **☰** 를 누른 것입니다. 위쪽 막대 맨 왼쪽(작은 ▾ 가 붙은 것)의 **☰** 를 누르세요 |
| 사이드바가 좁아져 메뉴가 안 보인다 | 사이드바가 접힌 상태입니다. 사이드바 맨 위 **☰** 를 다시 누르세요 |
| 도구 화면에서 홈으로 못 돌아간다 | 오른쪽 위 **◀ 뒤로**(End Effector Control 은 **← 뒤로**)를 누르세요 |
| **Quit** 을 눌렀더니 빈 화면만 남았다 | **Quit** 은 SO-ARM 101 전체 테스트 화면만 닫습니다. 도구 메뉴(**☰**) › **단일 모터 테스트** 를 연 뒤 **◀ 뒤로** 를 누르면 홈으로 돌아옵니다 |
| 로봇을 만들었는데 로봇 창고에 카드가 없다 | **로봇 설정** 탭에서 **로봇 저장** 까지 마쳤는지 확인하세요. 저장 전의 로봇은 카드로 보이지 않고, 저장할 때 뜨는 관리자 비밀번호 창을 취소하면 저장되지 않습니다. Ubuntu 에서는 USB 포트 고정 규칙이 하나라도 있으면 규칙이 있는 로봇만 카드로 보입니다. **최근 로봇** 에는 있는데 카드가 없다면 그 로봇을 열어 팔을 꽂은 채 **로봇 저장** 을 다시 하세요 → [로봇 설정](/docs/physical-labs/robot-settings) |
| 탭이 회색이라 눌리지 않는다 | 이 기종에서 아직 준비 중인 탭입니다 (5.2절) |
| 탭을 열었더니 "추가 설치가 필요합니다" 카드가 뜬다 | 정상입니다. **설치하기** 를 누르세요 → [기능 패키지 설치](/docs/physical-labs/feature-packs) |
| 텔레오퍼레이션 중에 사이드바 메뉴를 눌렀더니 팔이 멈추고 힘이 빠졌다 | 사이드바로 옮기면 연결이 끊기고 팔의 토크가 꺼집니다 (3.4절). 팔을 받친 채 그 탭으로 돌아가 다시 연결하세요 |
| **언어** · **도움받기** 를 눌러도 "준비 중" 만 뜬다 | 아직 준비 중인 메뉴입니다 |
| 화면 아래쪽 버튼이 보이지 않는다 | 그 화면을 아래로 스크롤하세요. 그래도 답답하면 **화면 배율** 을 낮춰 보세요 (7.2절) |

그 밖의 문제는 [문제 해결](/docs/physical-labs/troubleshooting)에 모았습니다.

## 9. 정리

- 홈 화면은 **위쪽 막대 · 사이드바 · 본문** 으로 나뉩니다.
- **☰** 는 두 개입니다. 위쪽 막대 맨 왼쪽은 **도구 메뉴**, 사이드바 맨 위는 **사이드바 접기** 입니다.
- 로봇은 **로봇 창고** → **+ 로봇 추가** → 기종 카드 → **로봇 저장** 순서로 만듭니다.
- 로봇 작업 화면에는 탭 7개가 있고, 아래 화살표 아이콘은 추가 설치, 회색 탭은 준비 중을 뜻합니다.
- 사이드바로 화면을 옮기면 **확인 없이** 로봇 연결이 끊깁니다 (SO-101 · SO-102 는 팔의 힘도 빠집니다). 탭끼리 옮길 때만 확인 창이 뜨고, **✕** 는 설치 · 학습 중일 때만 묻습니다.
- 설정은 계정 버튼 → **⚙ 설정** 에 있고, 화면 배율을 바꾸면 앱이 다시 켜집니다 (인터넷 필요).
