# 모터 셋업

로봇 팔의 STS3215 모터들은 통신선 하나에 줄줄이 이어져 있습니다. 앱은 모터마다 붙은 번호(ID)로 모터를 하나하나 구분합니다. 새 모터는 보통 모두 같은 번호로 나오기 때문에, 팔을 조립하기 전에 관절마다 다른 번호를 붙여야 합니다. 이 페이지에서는 **ID 셋업 마법사**로 모터에 번호를 붙이는 방법과, **단일 모터 셋업** · **SO-ARM 101 전체 테스트**로 모터를 점검하는 방법을 다룹니다.

> 🎯 **학습 목표**
>
> - 모터 ID 가 무엇이고, 왜 모터를 한 대씩 연결해서 정하는지 설명할 수 있다.
> - ID 셋업 마법사로 SO-101(모터 6개) · SO-102(모터 7개)에 ID 를 순서대로 붙일 수 있다.
> - 단일 모터 셋업에서 모터 한 대를 찾아 상태를 보고, 움직여 보고, ID 를 바꿀 수 있다.
> - SO-ARM 101 전체 테스트로 조립한 팔의 모터가 모두 응답하는지 확인할 수 있다.
> - 포트 · 권한 · 응답 없음 문제를 스스로 확인할 수 있다.

## 1. 모터 셋업이 하는 일

### 1.1. 모터 ID 란?

팔의 모터들은 한 줄로 이어진 통신선(버스)을 함께 씁니다. 앱은 명령마다 받을 모터의 번호(ID)를 붙여 보내고, 그 번호를 가진 모터가 명령을 받습니다. 그래서 **한 버스 안에서는 모든 모터의 번호가 달라야** 합니다.

같은 번호의 모터가 두 대 있으면 앱은 둘을 구분하지 못합니다. 그 번호로 보낸 명령을 두 모터가 함께 받습니다. 새 STS3215 모터는 보통 ID 1 로 나오므로, 새 모터를 여러 대 한꺼번에 이어 둔 채로는 번호를 따로 붙일 수 없습니다. 그래서 ID 셋업은 **모터를 한 대씩 연결하며** 진행합니다.

Physical Labs 가 쓰는 관절 번호는 다음과 같습니다. 화면에도 이 이름이 그대로 나옵니다.

| ID | SO-101 (`soarm-101`, 6개) | SO-102 (`soarm-102`, 7개) |
|---|---|---|
| 1 | `Base (회전)` | `Base (회전)` |
| 2 | `Shoulder (어깨)` | `Shoulder (어깨)` |
| 3 | `Elbow (팔꿈치)` | `Elbow (팔꿈치)` |
| 4 | `Wrist Flex (손목 상하)` | `Wrist Flex (손목 상하)` |
| 5 | `Wrist Roll (손목 회전)` | `Wrist Yaw (손목 좌우)` |
| 6 | `Gripper (그리퍼)` | `Wrist Roll (손목 회전)` |
| 7 | 없음 | `Gripper (그리퍼)` |

LeKiwi 표(`lekiwi-101`)는 SO-101 팔 1~6번 뒤에 바퀴 3개를 붙입니다: `ID 7 — Left Wheel (왼쪽 바퀴)` · `ID 8 — Back Wheel (뒤 바퀴)` · `ID 9 — Right Wheel (오른쪽 바퀴)`. `lekiwi-102` 는 SO-102 팔 1~7번 뒤에 같은 바퀴 3개를 8 · 9 · 10번으로 붙입니다.

> **경고** ⚠️ `WARN`
> <br>**SO-102 는 5번부터 관절이 다릅니다** SO-102 는 손목을 좌우로 꺾는 관절(`Wrist Yaw`)이 5번으로 들어가, 손목 회전이 6번, 그리퍼가 7번으로 밀립니다. SO-102 모터를 **soarm-101 모터 셋업** 탭으로 셋업하면 5 · 6번이 엉뚱한 관절에 붙고 7번이 빠집니다. SO-102 는 반드시 **soarm-102 모터 셋업** 탭을 쓰세요.

> **정보** ℹ️ `INFO`
> <br>**앱은 찾은 번호를 지정해서 바꿉니다** 모든 모터에 한꺼번에 보내는 방식(브로드캐스트)은 쓰지 않습니다. 그래도 같은 번호의 모터가 여러 대 이어져 있으면 함께 바뀔 수 있으니, 번호를 바꿀 때는 버스에 모터를 한 대만 연결합니다.

### 1.2. 언제 하나요?

| 상황 | 할 일 |
|---|---|
| 새 모터로 팔을 조립하기 전 | **ID 셋업 마법사**로 모터를 한 대씩 셋업합니다 (3절). 모터를 팔에 달기 **전에** 합니다 |
| 모터 한 대를 새것으로 바꿀 때 | 새 모터를 팔에 잇기 전에, 마법사에서 그 관절 단계만 다시 합니다 (3.7절) |
| 모터 한 대가 살아 있는지, 잘 도는지 보고 싶을 때 | **단일 모터 셋업** (4절) |
| 조립한 팔의 모터가 모두 응답하는지 보고 싶을 때 | **SO-ARM 101 전체 테스트** (5절) |
| 이미 ID 가 정해진 채 조립된 팔 | SO-ARM 101 전체 테스트로 번호가 모두 대답하는지만 보고 [로봇 설정](/docs/physical-labs/robot-settings)으로 넘어갑니다 |
| 조립돼 움직이는 A-Go(LeKiwi) 로봇 | 로봇 쪽 모터는 할 일이 없습니다. PC 에 꽂는 리더암을 새로 조립할 때만 **soarm-101 모터 셋업** 탭을 씁니다 |

### 1.3. 준비물

| 준비물 | 설명 |
|---|---|
| PC 와 Physical Labs | 이 문서는 Ubuntu 24.04 + Physical Labs 0.1.9 기준입니다 ([설치와 첫 실행](/docs/physical-labs/install)). 모터 셋업은 기본 구성에 들어 있어 기능 패키지를 따로 설치하지 않아도 됩니다 |
| 모터 컨트롤러 보드 | 모터 버스를 USB 로 PC 에 이어 주는 보드입니다. USB 케이블로 PC 에 꽂습니다 |
| 보드 전원 | 모터는 USB 가 아니라 보드에 꽂은 전원으로 움직입니다. 전원이 꺼져 있으면 스캔에 모터가 하나도 나오지 않습니다 |
| STS3215 모터 · 모터 케이블 | ID 셋업 마법사는 한 번에 한 대만 보드에 연결합니다 |
| 시리얼 포트 권한 (우분투) | 설치할 때 사용자를 `dialout` 그룹에 넣습니다. 설치한 뒤 **한 번 로그아웃했다가 다시 로그인**해야 적용됩니다 |

> **정보** ℹ️ `INFO`
> <br>**Windows 판(0.1.7)도 화면과 순서는 같습니다** 모터 셋업의 탭 · 버튼 · 순서는 이 문서와 같습니다. 포트가 `COM3` 같은 이름으로 보이고, 우분투 전용인 권한 안내 창(`시리얼 포트 권한 문제`)은 나오지 않습니다. 다만 Windows 판은 SO-102 를 지원하지 않습니다. 그 판의 **soarm-102 모터 셋업** 탭은 관절 표가 예전 것(4번 `Forearm Roll (팔뚝 회전)`)이라 지금의 SO-102 와 맞지 않으니, SO-102 는 우분투 판으로 셋업하세요.

*연결 전에는 **모터 스캔** · **ID 1 할당** 이 흐리게 잠겨 있고, 맨 아래 상태 줄에 `포트를 선택하고 연결하세요` 가 보입니다.*

**lekiwi 모터 셋업** 은 로봇을 조립하는 단계에서 모터 보드를 PC 의 USB 에 꽂아 쓰는 탭입니다. 완성된 LeKiwi 의 팔 · 바퀴 모터는 로봇 안의 Raspberry Pi 에 연결되어 있어 이 화면으로 다루지 않습니다. 이 탭은 번호와 가운데 정렬만 하고, 바퀴 모터를 속도 모드로 바꾸지 않습니다. A-Go(ROS 2) 로봇은 바퀴 모터가 속도 모드가 아니면 바퀴 토크를 켜지 않습니다(웹 화면 `바퀴 토크를 켜지 못했습니다: …`, 로봇 로그 `… not velocity mode (1)`). 그래서 A-Go 를 부품부터 조립하거나 바퀴 모터를 새것으로 바꿀 때는 RoboSEasy 에 문의하세요.

> **팁** 💡`TIP`
> <br>**포트는 지금 보이는 탭 하나만 씁니다** 다른 탭 · 사이드바 메뉴로 옮기거나 **◀ 뒤로** 로 나가면 연결이 저절로 끊깁니다. 이때 버튼 글자가 **연결 해제** 로 남아 있을 수 있는데, 실제로는 끊긴 상태입니다. 돌아와서 그 버튼을 한 번 누르면 다시 연결됩니다.

## 3. ID 셋업 마법사

**soarm-101 모터 셋업** · **soarm-102 모터 셋업** · **lekiwi-101** · **lekiwi-102** 탭은 모두 같은 ID 셋업 마법사입니다. 표의 1번 관절부터 차례로 모터를 한 대씩 연결해 번호를 붙입니다. 번호를 붙인 모터는 가운데 위치로 돌려 보며 제대로 대답하는지 확인합니다. 아래는 SO-101(6개)을 예로 듭니다.

### 3.1. 시작하기 전에 꼭 지킬 것

> **경고** ⚠️ `WARN`
> <br>**모터는 한 번에 한 대만, 번호를 붙인 모터는 실제로 돕니다**
>
> - 버스(보드)에는 **지금 셋업할 모터 한 대만** 연결합니다.
> - 앞 단계에서 끝낸 모터는 반드시 빼 둡니다. 남겨 두면 새 모터와 번호가 겹칠 수 있고(둘 다 ID 1), 번호가 같은 두 모터는 마법사가 구분하지 못해 경고 없이 함께 바뀔 수 있습니다.
> - 번호를 붙이면 마법사가 그 모터를 **가운데 위치(2048)로 실제로 돌립니다.** 모터 축에 걸리는 것이 없게 하고, 도는 동안 손을 대지 마세요.
> - 이미 팔에 조립된 모터라면 그 관절이 움직입니다. 주변을 비우고 팔을 받쳐 두세요.
> - 모터가 도는 동안에는 전원과 USB 케이블을 빼지 않습니다.

### 3.2. 화면 구성

![ID 셋업 마법사 — 포트 줄, Step 1/6: ID 1 할당 안내, 모터 스캔 · ID 1 할당 버튼, ID 1~6 단계 목록](/img/physical_labs/robot-settings-motor.webp)

*연결 전의 마법사입니다. 그림은 로봇 설정 탭 `모터` 칸에 들어 있는 같은 마법사이고, 모터 셋업 탭에서는 위에 보라색 머리줄, 아래에 상태 줄이 더 있습니다.*

| 칸 | 하는 일 |
|---|---|
| 머리줄 (탭 이름 · **◀ 뒤로**) | **◀ 뒤로** 는 연결을 끊고 모터 셋업 카드 화면으로 돌아갑니다 |
| **포트:** · **새로고침** · **연결** · 점 | 보드의 포트를 고르고 연결합니다. 점이 빨강이면 끊김, 초록이면 연결됨입니다 |
| `Step 1/6: ID 1 할당` 과 안내 글 | 지금 할 단계와 연결할 모터(`'Base (회전)' 모터 1대만 버스에 연결한 후 …`)를 알려 줍니다 |
| **1. 모터 스캔:** · **🔍 모터 스캔** · 목록 | 버스의 모터를 찾고, 찾은 번호를 목록(`ID: 1`)에 보여 줍니다 |
| **✨ ID 1 할당** | 찾은 모터에 이 단계의 번호를 붙이고 가운데로 돌립니다. 스캔해야 켜집니다 |
| **📊 상태 모니터** | 스캔한 뒤 나타나 `위치` · `속도` · `온도 (°C)` · `전압 (V)` · `전류 (mA)` · `부하 (%)` 를 보여 줍니다 |
| 단계 목록 | `ID 1 — Base (회전)` 처럼 한 줄에 한 관절. 상태는 `대기`(회색) · `진행 중`(주황) · `완료`(초록)입니다. 실패한 단계는 다른 단계로 옮기면 실패 이유(빨강)로 남습니다 |
| 상태 줄 (맨 아래) | `포트를 선택하고 연결하세요` 같은 안내와 경고를 보여 줍니다 |

### 3.3. [PC] 보드 연결 → [앱] 포트 연결

1. **[로봇]** 모터 컨트롤러 보드에 전원을 넣습니다. 모터는 아직 연결하지 않아도 됩니다.
2. **[PC]** 보드를 USB 케이블로 PC 에 꽂습니다.
3. **[앱]** **새로고침** 을 누르고 **포트:** 목록에서 보드의 포트를 고릅니다. 우분투에서는 `/dev/ttyACM0` 같은 이름으로 보입니다.
4. **[앱]** **연결** 을 누릅니다. 점이 초록으로 바뀌고, 상태 줄에 `<포트> 연결됨 — 모터를 1대 연결하고 '모터 스캔' 버튼을 누르세요` 가 나옵니다.

우분투에서 **연결** 을 눌렀을 때 `시리얼 포트 권한 문제` 창이 뜨면 6.1절을 보세요.

> **팁** 💡`TIP`
> <br>**어느 포트가 보드인지 모르겠다면** 보드 USB 를 뺀 채 **새로고침** 을 한 번 누르고, 꽂은 뒤 한 번 더 누르세요. 새로 생긴 항목이 보드입니다. 보드를 하나만 꽂아 두면 헷갈릴 일이 없습니다.

연결을 끊었다가 다시 연결하면 단계 목록이 처음(Step 1)으로 돌아갑니다. 이미 끝낸 모터가 있다면 이어서 할 단계의 줄을 눌러 옮겨 가세요 (3.7절).

### 3.4. [로봇] 첫 모터 연결 → [앱] 모터 스캔

1. **[로봇]** 단계 목록 첫 줄의 관절(SO-101 은 `Base (회전)`)에 쓸 모터 **한 대만** 보드에 연결합니다.
2. **[앱]** **🔍 모터 스캔** 을 누릅니다. `모터 스캔 중...` 창이 잠깐 떴다가 닫힙니다.
3. 모터를 찾으면 목록에 `ID: 1` 처럼 번호가 나오고, **📊 상태 모니터** 가 켜집니다. 상태 줄에는 `스캔 완료: ID 1 발견 — ID 1로 할당하세요` 가 나옵니다.

스캔은 표의 가장 큰 번호보다 하나 더 큰 번호까지 찾습니다. 번호가 하나 밀린 모터도 찾을 수 있게 한 칸 더 보는 것입니다. 그보다 큰 번호의 모터는 보이지 않습니다.

| 탭 | 스캔하는 ID |
|---|---|
| soarm-101 | 1~7 |
| soarm-102 | 1~8 |
| lekiwi-101 | 1~10 |
| lekiwi-102 | 1~11 |

> **경고** ⚠️ `WARN`
> <br>**상태 줄에 `⚠ 모터 N대 감지됨` 이 나오면 멈추세요** 버스에 모터가 두 대 이상 연결되어 있다는 뜻입니다. 마법사는 경고만 하고 할당 버튼을 막지 않습니다. 지금 셋업할 모터 한 대만 남기고 **🔍 모터 스캔** 을 다시 누르세요.

### 3.5. [앱] ID 할당 → 가운데 정렬

1. **[앱]** **✨ ID 1 할당** 을 누르면 확인 창이 뜹니다.

확인 창은 찾은 모터의 번호에 따라 둘 중 하나가 나옵니다.

| 창 제목 | 내용 | 뜻 |
|---|---|---|
| `ID 확인` | `모터가 이미 ID 1입니다.` / `이 모터를 'Base (회전)'로 확정하시겠습니까?` | 찾은 모터가 이미 이 단계의 번호입니다. 새 모터의 첫 단계는 보통 이 창이 뜹니다 |
| `ID 변경` | `모터 ID를 변경하시겠습니까?` / `현재 ID: 1 → 새 ID: 2 (Shoulder (어깨))` | 찾은 모터의 번호를 이 단계의 번호로 바꿉니다 |

2. **[앱]** **Yes** 를 누릅니다. 마법사가 번호를 쓰고, 모터가 새 번호로 대답하는지 확인합니다. 바로 대답하지 않으면 몇 번 더 시도합니다. 확인이 끝날 때까지 보이는 **↺ 단계 초기화** 를 누르면 이 단계를 처음 상태로 되돌립니다 (그 뒤 할당 버튼 글자는 `연결 확인 & ID 할당` 으로 바뀌지만 하는 일은 같습니다).
3. 모터가 대답하면 `중앙 정렬 진행 중` 창이 뜨고 모터가 **가운데(2048)로 돕니다**. 창에 `현재 위치` · `목표: 2048` · `오차` 가 나오다가 `완료!` 로 바뀝니다. 6초 안에 가운데에 닿지 못하면 실패로 처리합니다 (6.2절).

<!-- 그림 필요: 스캔 뒤 상태 모니터가 켜진 마법사와 그 위에 뜬 ID 변경 확인 창 (현재 ID: 1 → 새 ID: 2 (Shoulder (어깨))) -->

<!-- 그림 필요: 중앙 정렬 진행 중 창 — 진행 막대와 "현재 위치 / 목표: 2048 / 오차" 글자 -->

> **정보** ℹ️ `INFO`
> <br>**왜 가운데(2048)로 돌릴까요?** STS3215 는 한 바퀴를 0~4095 로 나눠 위치를 읽고, 2048 은 그 가운데입니다. 모터를 가운데에 맞춘 채 조립해야 나중에 [칼리브레이션](/docs/physical-labs/calibration)이 기준 자세를 기록할 수 있습니다. 가운데 정렬을 거치지 않은 모터로 조립하면 칼리브레이션에서 `보정 실패` 가 날 수 있습니다.

### 3.6. [로봇] 다음 모터로 → 끝까지 되풀이

한 단계가 끝나면 `Step 1 완료` 창이 다음 할 일을 알려 줍니다. `다음 단계: ID 2 (Shoulder (어깨))` · `현재 모터를 분리하고 다음 모터를 연결한 뒤 '모터 스캔' 버튼을 누르세요.` 같은 글이 나옵니다.

1. **[앱]** **OK** 로 창을 닫습니다. 끝낸 줄은 `완료`(초록)로 바뀌고 마지막 위치(`위치:` 2048 근처 값)가 적힙니다.
2. **[로봇]** 방금 끝낸 모터를 보드에서 빼고, 다음 관절에 쓸 모터를 연결합니다. 끝낸 모터에 번호를 적어 두면 조립할 때 헷갈리지 않습니다.
3. **[앱]** **🔍 모터 스캔** → **✨ ID 2 할당** → **Yes** 순서로 같은 일을 합니다. 새 모터는 보통 `ID 변경` 창(`현재 ID: 1 → 새 ID: 2`)이 뜹니다.
4. 마지막 관절(SO-101 은 `ID 6 — Gripper (그리퍼)`)까지 되풀이합니다.

<!-- 그림 필요: Step 1 완료 안내 창과 그 뒤의 단계 목록 (ID 1 줄이 초록 완료 · 위치 값, ID 2 줄이 주황 진행 중) -->

모두 끝나면 제목이 `모든 모터 ID 셋업 완료!` 로 바뀌고, `완료` 창(`모든 모터의 ID가 성공적으로 할당되었습니다!`)이 뜹니다. 단계 목록의 모든 줄이 `완료` 인지 눈으로 한 번 더 확인하세요.

> **성공** ✨ `SUCCESS`
> <br>**이제 조립할 차례입니다** 번호를 붙인 모터를 관절 순서대로 팔에 조립하세요. 가운데로 맞춘 모터 축은 손으로 돌리지 않은 채 조립합니다. 조립 방법은 [A-Ba(SO-ARM101) 문서](/docs/a-ba)를 따릅니다. 조립을 마치면 [로봇 설정](/docs/physical-labs/robot-settings)에서 팔을 등록하고 [칼리브레이션](/docs/physical-labs/calibration)을 합니다.

### 3.7. 한 단계만 다시 하기

단계 목록의 줄을 누르면 그 단계로 옮겨 갑니다(툴팁 `클릭하여 ID n 단계로 이동`). 스캔 · 할당 · 가운데 정렬이 도는 중에는 옮겨 가지 않고 `진행 중` 창이 뜹니다.

**모터 한 대를 새것으로 바꿀 때**는 새 모터를 팔의 버스에 잇기 전에 따로 셋업합니다. 새 모터는 보통 ID 1 이라, 팔에 그대로 이으면 1번 모터와 번호가 겹칩니다.

1. **[로봇]** 새 모터 **한 대만** 보드에 연결합니다.
2. **[앱]** 단계 목록에서 그 관절의 줄을 누릅니다 (예: `ID 3 — Elbow (팔꿈치)`).
3. **[앱]** **🔍 모터 스캔** → **✨ ID 3 할당** → **Yes**. 가운데 정렬까지 끝나면 관절을 기역자 자세([칼리브레이션](/docs/physical-labs/calibration)의 기준 자세)에 맞춰 팔에 조립합니다.

**조립한 팔의 모터를 다시 가운데로 맞출 때**(예: 칼리브레이션이 그 모터를 다시 셋업하라고 할 때)는 그 모터를 팔에서 풀어 따로 셋업합니다. 가운데 정렬은 모터를 2048 로 돌릴 뿐 모터를 단 각도는 바꾸지 못합니다. 팔에 단 채로 돌리면 문제는 그대로 남고, 관절이 끝에 부딪혀 부품이 상할 수 있습니다.

1. **[로봇]** 그 관절의 모터 혼을 팔 부품에서 풀거나 모터를 떼어 내 축이 아무것에도 걸리지 않게 하고, 그 모터 **한 대만** 보드에 연결합니다.
2. **[앱]** 단계 목록에서 그 관절의 줄(예: `ID 2 — Shoulder (어깨)`)을 누르고 **🔍 모터 스캔** → **✨ ID 2 할당** 을 누릅니다. 번호가 이미 맞으면 `ID 확인`(`모터가 이미 ID 2입니다.`) 창이 뜹니다. **Yes** 를 누르면 모터가 가운데로 돕니다.
3. **[로봇]** 그 관절을 기역자 자세에 맞춘 채 모터 혼을 다시 고정합니다.

> **경고** ⚠️ `WARN`
> <br>**이때 `ID 변경` 창이 뜨면 No 를 누르세요** 연결한 모터가 그 관절의 번호가 아니라는 뜻입니다. 그대로 바꾸면 팔에 같은 번호의 모터가 두 대가 됩니다. 이 창은 **Yes** 가 기본이라 Enter 를 누르면 바로 바뀌니, 마우스로 **No** 를 누르세요.

### 3.8. 로봇 설정 탭 안의 마법사

SO-101 · SO-102 로봇의 **로봇 설정** 탭 맨 아래 **모터** 칸에도 같은 마법사가 들어 있습니다. 로봇 기종에 맞춰 SO-101 은 6단계, SO-102 는 7단계로 바뀝니다. 모터 셋업 탭과 다른 점은 셋입니다.

- 머리줄과 맨 아래 상태 줄이 없습니다. 그래서 `⚠ 모터 N대 감지됨` 경고도 보이지 않습니다. 스캔 목록에 번호가 둘 이상 나오면 한 대만 남기고 다시 스캔하세요.
- 저장한 로봇이면 팔로워 포트가 미리 골라져 있습니다. 리더 팔을 셋업할 때는 포트를 바꿔 고르세요.
- 다른 탭이나 사이드바 메뉴로 옮겨도 연결이 끊기지 않습니다. 셋업을 마치면 **연결 해제** 를 누른 뒤 칼리브레이션 같은 다른 탭으로 가세요. 연결된 채로 두면 두 화면이 같은 포트를 함께 써 모터 응답이 엉킬 수 있습니다.

A-Go(LeKiwi) 로봇의 **로봇 설정** › **모터** 칸에는 마법사 대신 안내 카드가 보입니다. 팔 · 바퀴 모터가 로봇 안의 Raspberry Pi 에 연결되어 있기 때문입니다. 로봇 팔의 보정은 [A-Go 캘리브레이션](/docs/a-go/start-calibration)을 보세요.

### 4.2. [앱] 모터 찾기 · 핑 · 상태 보기

1. **[로봇]** 볼 모터를 보드에 연결하고 보드 전원을 넣습니다. **[PC]** 보드를 USB 로 PC 에 꽂습니다.
2. **[앱]** **포트:** 를 고르고 **🔌 연결** 을 누릅니다. 로그에 `연결 성공: <포트>` 가 나옵니다.
3. **[앱]** **🔍 모터 스캔** 을 누릅니다. 이 화면은 **ID 1~7** 만 찾습니다. 로그에 `스캔 완료: N개 모터 발견 [...]` 가 나오고, 첫 모터가 저절로 골라집니다.
4. **[앱]** **📡 핑 테스트** 로 골라 둔 모터가 대답하는지 봅니다. 로그에 `핑 ID 1: 응답 있음 ✓` 또는 `응답 없음 ✗` 가 나옵니다.
5. **[앱]** **📊 모니터링 시작** 을 누르면 상태 모니터의 값이 0.2초마다 바뀝니다.

### 4.3. [앱] 움직여 보기

**▶ 이동** 은 모터를 실제로 돌리고, **⚡ 토크 OFF** 는 모터의 힘을 풉니다. 조립된 팔의 모터라면 관절이 움직이거나 처지니 팔을 받쳐 두세요.

1. **위치 (0~4095):** 막대나 숫자 칸으로 목표 위치를 정합니다. 2048 이 가운데입니다.
2. **속도 (0~3400):** 로 빠르기를 정합니다. 처음에는 기본값 1000 그대로 두세요.
3. **⚡ 토크 ON** 을 누르면 모터가 힘을 줘 지금 자세를 버팁니다. 버튼 글자가 **⚡ 토크 OFF** 로 바뀌고, 다시 누르면 힘이 풀립니다.
4. **▶ 이동** 을 누르면 모터가 목표 위치로 돕니다. 막대만 움직여서는 돌지 않습니다.

### 4.4. [앱] ID 직접 바꾸기

1. **스캔된 모터:** 에서 바꿀 모터를 고릅니다. **선택된 모터** 에 `ID: 1` 처럼 보입니다.
2. **새 ID:** 에 새 번호를 넣습니다.
3. 아래 두 버튼 중 하나를 누르고, 확인 창에서 **Yes** 를 누릅니다. 확인 창은 **No** 가 기본으로 골라져 있어 Enter 만 누르면 바뀌지 않습니다.

| 버튼 | 확인 창 | 끝난 뒤 |
|---|---|---|
| **✏️ ID 변경** | `ID 변경` — `…ID 변경 후, 모터 재스캔이 필요합니다.` | 번호만 바꿉니다. 로그에 `ID 변경 성공: 1 → 3` 과 `모터 재스캔을 권장합니다.` 가 나오니 **🔍 모터 스캔** 을 다시 누르세요 |
| **💾 ID 저장** | `ID 변경 및 저장` — `…변경 후 자동으로 모터를 재셋업합니다.` | 번호를 바꾸고 **스캔된 모터:** 목록의 번호도 새 번호로 고칩니다. 다시 스캔하지 않고 이어서 쓸 수 있습니다 |

> **경고** ⚠️ `WARN`
> <br>**새 번호는 1~7 안에서 고르세요** **새 ID:** 칸은 0~253 까지 받지만, 이 화면의 스캔은 1~7 만, 마법사의 스캔은 많아야 11 까지만 찾습니다. 그보다 큰 번호나 0 으로 바꾼 모터는 이 앱으로 다시 찾지 못해 번호를 되돌릴 수 없습니다. 번호를 바꿀 때는 버스에 그 모터 한 대만 연결하세요.

> **팁** 💡`TIP`
> <br>**조립할 새 모터라면 가운데로 맞춰 두세요** 이 화면에서 번호를 바꾸면 마법사와 달리 모터를 가운데로 돌리지 않습니다. 새 모터는 마법사의 그 단계로 셋업하는 편이 간단합니다(3.7절). 이 화면으로 했다면 **위치** 를 `2048` 로 두고 **⚡ 토크 ON** → **▶ 이동** 을 누른 뒤, **📊 모니터링 시작** 으로 상태 모니터의 `위치` 가 2048 근처인지 확인하세요.

## 5. 도구 메뉴(☰)와 SO-ARM 101 전체 테스트

### 5.1. [앱] 도구 메뉴(☰)의 옛 도구들

위쪽 막대 맨 왼쪽의 **☰**(툴팁 `도구`)를 누르면 예전부터 있던 시험 도구 세 개가 나옵니다. 사이드바 맨 위의 **☰** 는 사이드바를 접는 버튼이니 헷갈리지 마세요 ([화면 둘러보기](/docs/physical-labs/screens)).

| 메뉴 | 여는 화면 | 같은 일을 하는 새 화면 |
|---|---|---|
| **단일 모터 테스트** | 단일 모터 셋업 (4절) | **모터 셋업** › **단일 모터 셋업** 탭 |
| **SO-ARM 101 전체 테스트** | 팔의 모든 모터를 슬라이더로 보고 움직이는 화면 (5.2절) | 로봇의 **칼리브레이션** 탭 **연결 설정** 칸 |
| **End Effector Control** | 엔드이펙터 조종 창. 로봇 제어 패키지가 없으면 설치 창이 먼저 뜹니다 | 로봇의 [엔드이펙터](/docs/physical-labs/end-effector) 탭 |

도구 화면은 창 전체를 씁니다. 홈으로 돌아올 때는 오른쪽 위의 **◀ 뒤로**(End Effector Control 은 **← 뒤로**)를 누릅니다.

> **팁** 💡`TIP`
> <br>**도구를 열기 전에 지금 화면의 연결을 끊으세요** 도구 화면이 열려도 원래 보던 탭의 연결은 끊기지 않습니다. 같은 포트를 두 화면이 함께 쓰면 모터 응답이 엉킬 수 있으니, 먼저 **연결 해제** 를 누른 뒤 도구를 여세요.

### 5.2. [앱] SO-ARM 101 전체 테스트 연결

![SO-ARM 101 전체 테스트 화면의 윗부분 — 포트, ID 목록 1,2,3,4,5,6, 연결 버튼, 오른쪽 위 뒤로 · Quit](/img/physical_labs/motor-setup-soarm101-test.webp)

*연결하기 전의 SO-ARM 101 전체 테스트입니다. 연결하면 아래에 모터마다 한 줄씩 나타납니다.*

1. **[PC]** 조립한 팔의 보드를 USB 로 PC 에 꽂고, **[로봇]** 보드 전원을 넣습니다.
2. **[앱]** 도구 메뉴(**☰**) › **SO-ARM 101 전체 테스트** 를 엽니다.
3. **[앱]** **포트:** 를 고릅니다. **ID 목록:** 은 처음에 `1,2,3,4,5,6` 입니다. SO-102 라면 `1,2,3,4,5,6,7` 로 고쳐 적습니다.
4. **[앱]** **🔌 연결** 을 누릅니다. 아래 **모니터링 및 제어** 칸에 `모터 ID: 1` 부터 한 줄씩 생기고, 줄마다 슬라이더와 `현재 값:` 이 0.1초마다 실제 위치로 바뀝니다.

모든 줄의 `현재 값:` 에 숫자가 나오면 그 모터들이 모두 대답하는 것입니다. `현재 값: 오류` 인 줄은 그 번호의 모터가 대답하지 않는 것입니다.

### 5.3. [앱] 슬라이더로 움직이기

> **경고** ⚠️ `WARN`
> <br>**슬라이더를 움직이면 그 모터가 곧바로 돕니다** 슬라이더를 움직이는 순간 그 모터의 토크가 켜지고, 슬라이더 위치로 바로 움직입니다. 이 화면에는 충돌을 감지해 멈추는 기능이 없습니다. 팔 주변에서 손과 물건을 치우고, 슬라이더는 조금씩 움직이세요.

슬라이더 하나가 모터 하나입니다. 줄의 번호는 1.1절의 관절 번호와 같습니다(SO-101 은 `모터 ID: 1` 이 Base, `모터 ID: 6` 이 그리퍼). 손을 떼면 슬라이더는 다시 실제 위치를 따라갑니다.

### 5.4. [앱] 끝내기

- **🔌 연결 해제** 를 누르면 **모든 모터의 토크를 끄고** 연결을 끊습니다. 조립한 팔은 힘이 빠져 처질 수 있으니, 누르기 전에 팔을 손으로 받치세요. 연결된 채로 **◀ 뒤로** · **Quit** 을 눌러도 똑같이 토크가 꺼집니다.
- 홈으로 돌아갈 때는 **◀ 뒤로** 를 누릅니다. 빨간 **Quit** 은 이 화면만 닫아 빈 화면이 남을 수 있으니 누르지 마세요.

## 6. 문제 해결

### 6.1. [앱] 시리얼 포트 권한 (우분투)

**연결** 을 눌렀는데 아래 창이 뜨면, 지금 사용자 계정에 시리얼 포트 권한이 아직 없는 것입니다. 설치한 뒤 로그아웃 · 로그인을 하지 않았을 때 흔히 뜹니다.

![시리얼 포트 권한 문제 창 — 자동 설정 탭, 자동 설정 실행 버튼, 아래 다시 연결 시도 · 닫기 버튼](/img/physical_labs/serial-permission-dialog.webp)

*우분투에서 권한이 없을 때 뜨는 `시리얼 포트 권한 문제` 창입니다.*

1. **[앱]** **자동 설정 실행** 을 누르고 관리자(시스템) 비밀번호를 넣습니다.
2. **[앱]** **다시 연결 시도** 를 누릅니다. 지금은 임시 권한으로 바로 연결됩니다.
3. **[PC]** 다음부터 이 창이 뜨지 않게 하려면 한 번 로그아웃했다가 다시 로그인합니다.

터미널에서 직접 하려면 같은 창의 **수동 안내** 탭에 나오는 명령을 차례로 실행합니다. 자세한 것은 [문제 해결](/docs/physical-labs/troubleshooting)에 있습니다.

### 6.2. 증상별 확인

| 증상 | 확인할 것 |
|---|---|
| **포트:** 목록이 `포트 없음` 이거나 비어 있다 | 보드 USB 가 PC 에 꽂혀 있는지 보고 **새로고침** 을 누릅니다. 다른 USB 케이블이나 다른 USB 구멍으로도 꽂아 봅니다 |
| `포트가 이미 다른 프로세스에서 사용 중입니다.` | 같은 포트를 쓰는 다른 시리얼 프로그램을 닫고 다시 연결합니다 |
| 다른 탭 · 메뉴에 다녀온 뒤 `먼저 포트에 연결하세요.` 가 뜨거나 스캔이 되지 않는다 | 화면을 옮기면 연결이 저절로 끊깁니다. 버튼이 **연결 해제** 로 보여도 끊긴 상태이니, 그 버튼을 한 번 눌러 다시 연결합니다. 마법사는 다시 연결하면 1단계부터 시작하므로 이어서 할 단계의 줄을 누릅니다 |
| `모터 없음` — `모터를 찾을 수 없습니다.` (단일 모터 셋업은 로그에 `스캔 완료: 0개 모터 발견 []`) | 보드 전원이 켜져 있는지, 모터 케이블이 양쪽 끝까지 꽂혔는지 봅니다. 모터 번호가 스캔 범위 밖이면 보이지 않습니다 (3.4절 · 4.2절). 앱은 1,000,000 bps 로만 통신하므로, 다른 도구로 통신 속도를 바꾼 모터도 보이지 않습니다 |
| 상태 줄에 `⚠ 모터 N대 감지됨 [1, 2] — 1대만 연결한 뒤 재스캔 권장` | 버스에 모터가 두 대 이상입니다. 한 대만 남기고 다시 스캔합니다 |
| `ID n 단계 실패 — 위치 미도달` | 6초 안에 2048 에 닿지 못했습니다. 모터 축에 걸린 것이 없는지, 전원과 케이블을 봅니다 |
| `ID n 단계 실패 — 통신 실패` | 모터가 대답하지 않았습니다. USB 케이블, 모터 전원, 모터 연결을 봅니다 |
| `ID n 단계 실패 — 움직임 없음` | 토크는 켜졌는데 돌지 않습니다. 전원이 충분한지, 밖에서 막혀 있지 않은지 봅니다 |
| 단계가 실패한 뒤 어떻게 하나 | 실패하면 그 모터의 토크가 꺼지고 마법사가 멈춥니다. 원인을 고친 뒤 같은 단계에서 **🔍 모터 스캔** 부터 다시 합니다 |
| 번호를 바꾼 모터가 스캔에 안 보인다 | 새 번호가 스캔 범위 밖인지 봅니다. 단일 모터 셋업은 1~7 만 찾습니다 (4.4절) |
| SO-ARM 101 전체 테스트에서 `연결 오류` 와 `홈 포즈 캡처에 실패했습니다.` | **ID 목록:** 에 적은 모터 중 대답하지 않는 것이 있습니다. 창 아래에 적힌 ID 의 배선 · 전원을 보거나, ID 목록을 실제로 연결한 모터에 맞게 고칩니다 |
| **Quit** 을 눌러 빈 화면만 남았다 | 도구 메뉴(**☰**) › **단일 모터 테스트** 를 연 뒤 **◀ 뒤로** 를 누르면 홈으로 돌아옵니다 |
| 칼리브레이션에서 `보정 실패` 와 함께 `모터 ID 셋업 시 중앙 정렬을 거치지 않은 로봇에서 발생할 수 있습니다.` | 메시지에 적힌 번호의 모터를 팔에서 풀어 마법사로 다시 셋업(가운데 정렬 포함)하고, 다시 조립한 뒤 보정합니다 (3.7절). [칼리브레이션](/docs/physical-labs/calibration)도 함께 보세요 |

## 7. 정리

- 모터 ID 는 버스에서 모터를 구분하는 번호입니다. 한 버스 안에서 겹치면 안 됩니다.
- ID 셋업 마법사는 1번 관절부터 모터를 **한 대씩** 연결해 번호를 붙이고, 붙인 모터를 **가운데(2048)로 실제로 돌려** 확인합니다. 조립은 그다음입니다.
- SO-102 는 5번이 손목 좌우라서 반드시 **soarm-102 모터 셋업** 탭을 씁니다.
- 단일 모터 셋업은 모터 한 대의 점검 · 이동 · 번호 바꾸기용이고, 스캔은 ID 1~7 만 봅니다. 새 번호도 1~7 안에서 고릅니다.
- SO-ARM 101 전체 테스트는 슬라이더가 곧바로 모터를 움직이고, 충돌 감지가 없습니다. 끝낼 때는 팔을 받치고 **🔌 연결 해제** → **◀ 뒤로** 순서로 나옵니다.
