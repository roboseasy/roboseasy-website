# A-Go(LeKiwi) 캘리브레이션

팔을 움직이기 전에 꼭 거쳐야 하는 단계가 **캘리브레이션(보정)** 입니다. 새 A-Go 는 로봇 팔(팔로워)의 보정을 로봇이 직접 하고, 사용자는 **웹 화면** 이나 **Physical Labs** 에서 버튼을 눌러 단계를 진행합니다. 팔로워를 보정한 뒤에는 **접은 자세** 를 꼭 저장하고, 노트북에 꽂는 리더암(SO-101)도 따로 보정합니다.

> 🎯 **학습 목표**
>
> - 캘리브레이션이 왜 필요하고 언제 다시 해야 하는지 설명할 수 있다.
> - 웹 화면 또는 Physical Labs 로 팔로워 팔을 새로 보정할 수 있다.
> - 보정이 끝난 뒤 접은 자세를 저장하고, 저장하지 않으면 무엇이 막히는지 안다.
> - 리더암을 PC 에이전트(웹 화면) 또는 Physical Labs 로 보정할 수 있다.
> - 보정 파일이 어디에 있는지 알고, 모터와 맞는 파일을 골라 쓸 수 있다.

## 1. 캘리브레이션이란

### 1.1. 왜 필요한가

팔에 쓰인 서보 모터는 관절 위치를 **0~4095 의 정수(tick)** 로 알려 줍니다. 같은 자세라도 모터마다, 조립 상태마다 숫자가 다릅니다. 캘리브레이션은 관절마다 기준이 되는 자세와 움직일 수 있는 범위를 재서, tick 을 모든 팔에 공통인 각도로 바꾸는 표를 만드는 일입니다.

| 기록하는 것 | 뜻 | 쓰임 |
|---|---|---|
| 가운데 자세 | 관절마다 움직일 수 있는 범위의 한가운데 | 각도 0 의 기준 |
| 최소 · 최대 | 관절을 양 끝까지 움직였을 때의 tick | 움직일 수 있는 범위 · 안전 한계 |

이 표가 리더암과 팔로워 양쪽에 있어야 리더의 "어깨 30도" 가 팔로워의 "어깨 30도" 로 전해집니다. 결과는 lerobot 형식의 JSON 파일로 저장되고, 같은 값이 모터 안(EEPROM)에도 쓰입니다.

새 A-Go 에서는 보정이 더 중요합니다.

- 로봇은 보정 파일이 모터 안의 값과 맞는지 대조합니다. 파일이 없거나 맞지 않으면 팔을 움직이지 않습니다.
- 팔로워 보정이 없으면 로봇이 Physical Labs 로 관측(관절 값 · 카메라 영상)을 보내지 않습니다. 그래서 텔레오퍼레이션 · 데이터 수집 · 추론이 연결되지 않습니다. 웹 화면의 팔 원격 조작도 이 보정을 씁니다.

### 1.2. 언제 하나

| 상황 | 할 일 |
|---|---|
| 새로 구운 SD 카드로 처음 켰을 때 | SD 카드 이미지에는 보정이 들어 있지 않습니다. 팔로워 새로 보정 → 접은 자세 저장 |
| SD 카드만 다시 구웠고 팔은 그대로일 때 | 모터에는 마지막 보정이 남아 있습니다. 웹 화면의 **모터 값으로 파일 만들기** 로 파일을 되살릴 수 있습니다 (3.4절) |
| 리더암을 처음 쓰거나 다른 노트북으로 옮겼을 때 | 리더 보정 (리더 보정은 노트북에 저장됩니다) |
| 팔을 다시 조립했거나 모터를 바꿨을 때 | 그 팔을 새로 보정 |
| 보정 파일이 `모터와 다름` 으로 보일 때 | 목록에서 `모터와 맞음` 인 파일을 골라 쓰기. 없으면 새로 보정 |
| 팔로워가 리더보다 늘 몇 도 틀어진 채 따라올 때 | 두 팔을 같은 가운데 자세로 다시 보정 |

> **경고** ⚠️ `WARN`
> <br>**새로 보정하면 예전 데이터셋과 값이 달라질 수 있습니다** 같은 자세라도 보정할 때마다 관절 값이 조금씩 달라집니다. 이미 모은 데이터셋이 있다면 꼭 필요할 때만 새로 보정하고, 보정 전후의 데이터를 섞어 학습할 때 주의하세요. 웹 화면에도 같은 경고가 뜹니다.

### 1.3. 어디서 하나 — 웹 화면과 Physical Labs

팔로워 보정은 웹 화면과 Physical Labs 어느 쪽에서 해도 로봇의 같은 프로그램이 돌고, 결과도 로봇 안의 같은 곳에 저장됩니다. 다만 할 수 있는 일이 조금 다릅니다.

| 할 일 | [웹 화면] **캘리브레이션** | [앱] Physical Labs **칼리브레이션** 탭 |
|---|---|---|
| 팔로워 새로 보정 | ✅ 이름을 직접 정함 (새 이름만) | ✅ 이름은 로봇 이름으로 자동 |
| 보정 파일 목록 · 모터와 맞는지 보기 · 고르기 | ✅ | ✖ (지금 쓰는 보정 이름만 보임) |
| 모터 값으로 파일 만들기 | ✅ | ✖ |
| 끝나지 않은 보정 되돌리기 | ✅ **복원** | ✖ |
| 접은 자세 저장 | ✅ | ✅ |
| 팔을 접은 자세로 접고 힘 빼기 | ✖ (로봇을 끌 때만 자동으로 접습니다. 조작 화면의 **팔 힘 빼기** 는 접지 않고 힘만 뺍니다) | ✅ **🔓 토크 해제 (직접 교시)** |
| 리더암 보정 | ✅ PC 에이전트가 필요 (리눅스 노트북) | ✅ 노트북 USB 로 바로 |

로봇을 조작하는 곳은 한 번에 한 곳뿐입니다. 웹 화면이 조작 권한을 쥐고 있으면 앱의 보정이 막히고, 앱이 텔레오퍼레이션 · 데이터 수집 · 추론을 하는 동안에는 웹 화면의 보정이 막힙니다. 조작 권한은 [대시보드와 조작 권한](/docs/a-go/web-dashboard)에서 자세히 다룹니다.

> **정보** ℹ️ `INFO`
> <br>**Windows 노트북이라면** 웹 화면의 팔로워 보정과 접은 자세 저장은 어느 운영체제의 브라우저에서나 됩니다. 리더암 보정은 PC 에이전트(리눅스 전용)나 Physical Labs Ubuntu 판이 필요합니다. Windows 판 Physical Labs 의 최신 판(0.1.7)은 새 A-Go(ROS 2 로봇)를 지원하지 않습니다.

### 1.4. 가운데 자세

보정의 첫 단계에서 팔을 **모든 관절이 움직일 수 있는 범위의 한가운데** 에 둡니다. 웹 화면은 관절마다 이렇게 안내합니다.

| 관절 | 가운데 |
|---|---|
| 어깨 회전 | 왼쪽 끝과 오른쪽 끝의 가운데 |
| 어깨 들기 | 앞쪽 끝과 뒤쪽 끝의 가운데 |
| 팔꿈치 | 다 편 것과 다 접은 것의 가운데 |
| 손목 굽힘 | 위쪽 끝과 아래쪽 끝의 가운데 |
| 손목 회전 | 돌아가는 범위의 가운데 |
| 그리퍼 | 반쯤 연 자세 |

맞추고 나면 위팔은 위로 서고, 아래팔과 그리퍼는 앞으로 수평하게 뻗은 기역자(ㄱ) 모양이 됩니다. Physical Labs 는 3D 화면에 이 자세를 보여 줍니다.

![SO-101 리더암을 손으로 받쳐 관절을 가운데(기역자) 자세로 둔 모습](/img/a_go/start-calibration-06.webp)
*리더암을 가운데 자세로 둔 모습. 팔로워 팔도 같은 모양으로 맞춥니다.*

> **팁** 💡`TIP`
> <br>**리더와 팔로워는 같은 자세로 보정하세요** 두 팔의 가운데 자세가 서로 다르면 텔레오퍼레이션에서 팔로워가 리더보다 늘 몇 도 틀어진 채 따라옵니다.

## 2. 시작 전에 확인할 것

| 확인할 것 | 왜 · 어떻게 |
|---|---|
| 로봇 기능이 켜져 있다 | 모터 값을 읽어 파일과 맞춰 보고 접은 자세를 저장하려면 필요합니다. 웹 **대시보드** 의 **로봇 켜기** 또는 앱의 **▶ 로봇 켜기** |
| 팔 힘이 빠져 있다 (팔 토크 꺼짐) | 팔 원격 조작이나 텔레오퍼레이션을 끝내도 팔은 힘을 준 채 그 자리에 남습니다. 웹은 조작 화면의 **팔 힘 빼기**, 앱은 **🔓 토크 해제 (직접 교시)** |
| 지도 작성 · 자율 주행이 꺼져 있다 | 켜져 있으면 보정을 시작하지 않습니다 |
| 로봇을 조작하는 곳이 한 곳뿐이다 | 웹 화면과 앱이 서로 막습니다 (1.3절) |
| 팔 주변이 비어 있고, 손으로 받칠 수 있다 | 보정하는 동안 팔 힘이 풀립니다 |

> **경고** ⚠️ `WARN`
> <br>**보정하는 동안 팔은 힘이 풀립니다** 들려 있던 팔은 자기 무게로 떨어질 수 있습니다. 한 손으로 팔을 받칠 준비를 하고 시작하세요. 보정하는 동안에는 로봇 기능(카메라 · 바퀴 · 라이다)도 잠시 꺼집니다. 시작할 때 켜져 있었다면 끝난 뒤 다시 켜집니다.

## 3. [웹 화면] 팔로워 보정

### 3.1. 캘리브레이션 화면 열기

1. **[웹 화면]** 브라우저로 `http://lekiwi01.local:8080` (또는 `http://<로봇 IP>:8080`, AP 모드면 `http://192.168.4.1:8080`) 을 엽니다.
2. 왼쪽 메뉴에서 **캘리브레이션** 을 누릅니다. 휴대폰처럼 좁은 화면에서는 아래 탭의 **보정** 입니다.
3. 위쪽 막대의 **조작 권한 받기** 를 누릅니다. 화면은 권한 없이도 보이지만, 버튼은 조작 권한이 있어야 눌립니다.

![웹 캘리브레이션 화면: 왼쪽 팔로워 판에 지금 쓰는 보정과 보정 파일 목록, 오른쪽 리더 판에 PC 에이전트 실행 안내](/img/a_go/web-calibration.webp)
*왼쪽이 팔로워(로봇 팔), 오른쪽이 리더(노트북의 리더암)입니다. 이 로봇은 접은 자세를 아직 저장하지 않아 노란 안내가 떠 있습니다.*

팔로워 판에서 보이는 것은 다음과 같습니다.

| 칸 | 보이는 것 |
|---|---|
| **지금 쓰는 보정** | 로봇이 지금 쓰는 보정 이름 |
| **모터와** | `모터와 맞음` · `모터와 다름` · `확인 전` (로봇 기능이 꺼져 모터 값을 아직 못 읽었을 때) |
| **보정 파일** | 로봇에 있는 보정 파일 목록. 파일마다 `지금 씀`, 모터와 맞는지, 저장한 시각 |
| 버튼 | **이 보정 쓰기** · **모터 값으로 파일 만들기** · **접은 자세 저장** |
| **새로 보정** | 4단계 `준비` → `가운데` → `범위` → `끝내기` |

버튼이 흐릴 때는 바로 아래 줄에 이유가 나옵니다 (예: `이 보정 쓰기: 이미 쓰는 보정입니다`).

### 3.2. 모터와 맞는 파일 고르기

보정 파일이 여러 개면 `모터와 맞음` 인 파일을 골라 쓸 수 있습니다. 다시 보정하지 않아도 됩니다.

1. **[웹 화면]** **보정 파일** 목록에서 `모터와 맞음` 인 파일을 누릅니다.
2. **이 보정 쓰기** 를 누르면 확인 창 `팔로워 보정을 바꿀까요?` 가 뜹니다. "로봇 기능(카메라 · 바퀴 · 라이다)을 다시 켜는 동안 잠깐 꺼집니다" 를 읽고 **이 보정 쓰기** 를 누릅니다.
3. 로봇 기능이 잠깐 꺼졌다 켜진 뒤 **지금 쓰는 보정** 이 그 파일로 바뀝니다.

`모터와 다름` 인 파일을 고르면 **이 보정 쓰기** 가 `모터와 다르거나 읽을 수 없는 파일입니다. 모터와 맞는 파일을 고르세요` 로 막힙니다. 로봇 기능이 꺼져 있으면 맞는지 알 수 없어 `모터 보정 값을 받지 못해 맞는지 볼 수 없습니다 (로봇 기능을 켜세요)` 가 나옵니다.

### 3.3. 새로 보정

1. **[웹 화면]** **보정 이름** 칸에 새 이름을 적습니다. 영문 · 숫자 · `_` · `-` 로 40자까지 쓸 수 있고, 이미 있는 이름은 받지 않습니다 (`이미 있는 이름입니다. 다른 이름을 쓰세요`). 예를 들어 처음에는 `lekiwi01`, 다음에는 `lekiwi01_1028` 처럼 날짜를 붙입니다.
2. **새로 보정 시작** → 확인 창 `팔로워를 새로 보정할까요?` → **새로 보정 시작**. 로봇 기능이 꺼지고 `준비하는 중입니다 (버스를 여는 중)…` 이 보입니다.
3. **[로봇]** `가운데` 단계에서 `팔을 모든 관절 범위의 가운데로 옮긴 뒤 ‘제로-포지션 위치 시키기’를 누르세요.` 가 나옵니다. 팔을 받친 채 1.4절의 가운데 자세로 맞추고 **제로-포지션 위치 시키기** 를 누릅니다.
4. **[로봇]** `범위` 단계에서 `모든 관절을 한 번씩 끝까지 천천히 움직이세요 (손목 회전 제외). 다 했으면 ‘끝내기’를 누르세요.` 가 나옵니다. 어깨 회전 → 어깨 들기 → 팔꿈치 → 손목 굽힘 → 그리퍼 순서로 하나씩 양 끝까지 움직입니다. 관절마다 막대와 `지금 N · 최소 N · 최대 N` 이 늘어나는 것이 보입니다.
5. **[웹 화면]** 다 움직였으면 **끝내기** 를 누릅니다. `모터에 쓰고 파일로 저장하는 중입니다…` 다음에 `<이름> 보정을 저장했습니다` 와 함께 접은 자세를 지웠다는 안내가 나옵니다.
6. 로봇 기능이 다시 켜지고 (시작할 때 켜져 있었다면), **지금 쓰는 보정** 이 새 이름으로 바뀝니다. 이어서 [5. 접은 자세 저장](#5-접은-자세-저장)을 합니다.

손목 회전과 바퀴 3개는 한 바퀴를 도는 모터라 범위를 재지 않습니다 (`한 바퀴 (0~4095, 재지 않음)`). 어느 단계에서든 **취소** 를 누르면 `취소했습니다` 로 끝나고, **제로-포지션 위치 시키기** 로 모터에 쓴 값도 되돌립니다. 조작 권한이 끝나거나(창을 닫는 등) 비상 정지를 눌러도 보정은 취소됩니다.

*새로 보정의 `준비` 단계. 이름을 적어야 **새로 보정 시작** 이 켜집니다. 오른쪽 리더 판도 같은 4단계입니다.*

### 3.4. 모터 값으로 파일 만들기

모터 안(EEPROM)에는 마지막으로 보정한 값이 남아 있습니다. SD 카드를 다시 구웠거나 파일을 지워 **파일만 없어진 경우**, 팔을 다시 보정하지 않고 그 값으로 파일을 만들 수 있습니다. 팔은 움직이지 않습니다.

1. **[웹 화면]** 로봇 기능을 켠 상태에서 **모터 값으로 파일 만들기** 를 누릅니다.
2. **새 파일 이름 (영문 · 숫자 · _ · -, 40자까지)** 칸에 **지금 쓰는 보정** 과 다른 새 이름(예: `lekiwi01_motor`)을 적고 **파일 만들기** 를 누릅니다. 이미 있는 이름은 받지 않습니다.
3. 목록에 새 파일이 `모터와 맞음` 으로 생기면, 골라서 **이 보정 쓰기** 를 누릅니다 (3.2절).

**지금 쓰는 보정** 의 파일이 없어졌다면 그 이름 그대로 만들 수도 있습니다. 이때는 **이 보정 쓰기** 가 `이미 쓰는 보정입니다` 로 막히므로, 로봇 기능을 한 번 껐다 켜면 로봇이 그 파일을 읽습니다. 로봇 기능이 꺼져 있으면 `모터 보정 값을 받지 못했습니다 (로봇 기능 · 팔 쓰기를 켜세요)` 가 나옵니다. 접은 자세는 따로 저장해야 합니다.

### 3.5. 복원 — 새로 보정이 끝나지 않았을 때

새로 보정 도중에 전원이 꺼지거나 보정 프로그램이 멈추면, 모터 값이 반쯤 쓰인 채 남을 수 있습니다. 그러면 팔로워 판 위쪽에 빨간 상자 `지난 새로 보정이 끝나지 않았습니다` 와 **복원** 버튼이 나옵니다.

1. **[웹 화면]** **복원** → 확인 창 `예전 보정 값으로 복원할까요?` → **복원**.
2. 로봇 기능이 잠시 꺼지고, `예전 보정 값을 복원했습니다` 가 나오면 끝입니다. 실패하면 `복원하지 못했습니다` 가 나옵니다.

복원하기 전에는 다른 보정 작업을 받지 않습니다 (`지난 새로 보정이 끝나지 않았습니다. 먼저 ‘복원’을 누르세요`). Physical Labs 에는 복원이 없으니 웹 화면에서 합니다.

## 5. 접은 자세 저장

### 5.1. 접은 자세란

**접은 자세** 는 팔을 보관할 때처럼 접어 둔 자세입니다. 팔에 힘이 들어간 채로 로봇을 끄면(웹 화면 · 앱), 또는 앱에서 보정 · 토크 해제를 시작하면, 로봇이 먼저 팔을 이 자세로 접은 뒤 힘을 뺍니다. 그래서 편 팔이 떨어지지 않습니다.

- SD 카드 이미지에는 접은 자세가 없습니다. 팔로워를 처음 보정한 뒤 바로 저장합니다.
- 팔로워를 새로 보정하면 접은 자세가 지워집니다. 가운데가 바뀌어 예전 값이 다른 자세를 가리키기 때문입니다.
- 접은 자세가 없으면, 팔에 힘이 들어간 채로 로봇을 끌 때 로봇이 끄기를 멈추고 묻습니다. 웹 화면은 `팔을 접지 못했습니다. 그래도 끌까요?` (**그래도 끄기**), 앱은 `로봇 끄기` 창(**팔 힘 빼고 끄기**)입니다. 이때 힘을 빼면 편 팔과 잡은 물건이 떨어지니 팔을 손으로 받쳐야 합니다.

저장하려면 다음 조건이 필요합니다.

| 조건 | 맞지 않으면 |
|---|---|
| 로봇 기능이 켜져 있다 | `팔 모터 6개의 지금 위치를 받지 못했습니다 (lekiwi/motor/states)` |
| 팔 힘이 빠져 있다 | `팔 토크가 켜져 있습니다. …` 로 거절 |
| 지도 작성 · 자율 주행이 꺼져 있고, 보정 중이 아니다 | 웹은 버튼이 흐리고 이유가 보입니다. 앱은 `지도 작성 · 자율 주행 · 자동 주행 중에는 할 수 없습니다` 같은 이유가 창으로 뜹니다 |

> **팁** 💡`TIP`
> <br>**보정 직후가 저장하기 좋은 때입니다** 보정이 끝나도 팔은 힘이 빠진 채로 남습니다. 팔을 손으로 접은 자세로 옮긴 뒤 바로 저장하면 됩니다. 접은 자세로 접은 뒤 로봇이 힘을 빼므로, 힘이 빠져도 넘어지지 않고 그 자리에 머무는 자세를 고르세요.

### 5.2. [앱] 접은 자세 저장

1. **[앱]** 로봇 기능이 켜져 있는지 봅니다. 꺼져 있으면 **로봇 설정** 이나 **텔레오퍼레이션** 탭의 **▶ 로봇 켜기** 를 누릅니다.
2. 팔에 힘이 들어가 있을 수 있으면 **🔓 토크 해제 (직접 교시)** → 확인 창 `토크 해제` → **Yes**. 접은 자세가 아직 없으면 `팔을 접지 못했습니다` 창이 뜹니다 — 팔을 받치고 **Yes** 를 누르면 접지 않고 힘을 뺍니다.
3. **[로봇]** 팔을 손으로 접은 자세로 옮겨 둡니다.
4. **[앱]** **📌 접은 자세 저장** → 확인 창 `접은 자세 저장` → **Yes**.
5. `✓ 접은 자세를 저장했습니다: [...] (다음에 로봇 기능을 켤 때 적용됩니다)` 가 나오고, 상태 줄이 `접은 자세: ✔ 저장됨` 으로 바뀝니다.

### 5.3. [웹 화면] 접은 자세 저장

웹 화면에는 팔을 접어 주는 버튼이 없습니다. 팔에 힘이 들어가 있으면 조작 화면의 **팔 힘 빼기** 로 힘을 빼는데, 이 버튼은 팔을 접지 않고 바로 힘을 빼므로 편 팔이 떨어집니다. 먼저 팔을 손으로 받치세요.

![웹 조작 화면 텔레오퍼레이션 칸의 리더암 · 팔 부분: 리더암 연결, 팔 시작 · 팔 힘 빼기 버튼과 팔로워 상태 줄](/img/a_go/web-drive-teleop-arm.webp)
*조작 화면 › **텔레오퍼레이션** 칸의 `리더암` · `팔` 부분. 맨 아래 줄은 팔로워 상태입니다 (이 그림은 `대기` · `팔 토크가 꺼져 있습니다`). 팔 힘은 칸 제목 오른쪽의 `팔 토크 켜짐` · `팔 토크 꺼짐` 배지로도 봅니다.*

1. **[웹 화면]** 조작 권한을 받고, 대시보드에서 로봇이 `실행 중` 인지 봅니다.
2. 팔에 힘이 들어가 있으면 **조작** 화면의 **팔 힘 빼기** → 확인 창 `팔 힘을 뺄까요?` → **팔 힘 빼기** (팔을 받친 채로).
3. **[로봇]** 팔을 손으로 접은 자세로 옮겨 둡니다.
4. **[웹 화면]** **캘리브레이션** › 팔로워 판의 **접은 자세 저장** → 확인 창 `지금 자세를 접은 자세로 저장할까요?` → **접은 자세 저장**.
5. 판에 `저장된 접은 자세 (tick): …` 줄이 생기고 노란 안내가 사라집니다.

### 5.4. 저장한 자세 적용하기

저장한 접은 자세는 **다음에 로봇 기능을 켤 때** 적용됩니다. 저장한 뒤 로봇 기능을 한 번 껐다 켜세요. 웹은 대시보드의 **로봇 끄기** → **로봇 켜기**, 앱은 **■ 로봇 끄기** → **▶ 로봇 켜기** 입니다. 저장할 때 팔 힘이 빠져 있었으므로, 이때는 팔을 접을 필요 없이 바로 꺼집니다.

> **성공** ✨ `SUCCESS`
> <br>**팔로워 준비 끝** 앱은 `접은 자세: ✔ 저장됨`, 웹 화면은 `저장된 접은 자세 (tick): …` 가 보이면 됩니다. 이제 텔레오퍼레이션이 끝난 뒤 로봇을 끄면 팔이 접은 자세로 접히고 힘이 빠집니다.

## 6. 리더암 보정

리더암(SO-101)은 노트북에 USB 로 꽂아 씁니다. 리더 보정 파일은 노트북에 저장되므로, SD 카드를 다시 구워도 그대로 남습니다.

### 6.1. [웹 화면] PC 에이전트로 보정

웹 화면은 노트북에서 도는 **PC 에이전트** 를 거쳐 리더암을 보정합니다. PC 에이전트는 리눅스 노트북에서만 돌고, 처음 한 번 설치가 필요합니다 ([PC 에이전트 (리더암)](/docs/a-go/pc-agent)).

1. **[PC]** 리더암 USB 를 노트북에 꽂고, 터미널에서 PC 에이전트를 실행합니다. `<로봇 주소>` 에는 `lekiwi01.local` 이나 로봇 IP 를 넣습니다. 웹 화면의 리더 판에도 실행 명령과 **복사** 버튼이 있지만, 로봇의 판에 따라 폴더가 다른 명령이 보일 수 있습니다. `cd ~/lekiwi_pc_agent` 로 시작하지 않으면 아래 명령을 쓰세요.

```bash
# 우분투
cd ~/lekiwi_pc_agent && conda run --no-capture-output -n lerobot060 python -m lekiwi_pc_agent --robot <로봇 주소>
```

2. **[웹 화면]** **캘리브레이션** 에서 조작 권한을 받습니다. 리더 판의 실행 안내가 사라지고 노트북의 보정 파일 목록이 보이면 연결된 것입니다.
3. **모터와 맞춰 보기** 를 누릅니다. 파일마다 `모터와 맞음` · `모터와 다름` 이 붙습니다. 모터 값을 읽기만 합니다.
4. 맞는 파일이 있으면 골라서 **이 보정 쓰기** 를 누릅니다. 알림 `조작 화면의 리더 보정 기본값을 <이름> 로 했습니다 (이 브라우저)` 가 나옵니다.
5. 맞는 파일이 없으면 **모터 값으로 파일 만들기** 나 **새로 보정** 을 합니다. 새로 보정은 팔로워와 같은 4단계(**새로 보정 시작** → **제로-포지션 위치 시키기** → 범위 재기 → **끝내기**)입니다. 리더는 같은 이름으로 다시 보정해도 되고, 예전 파일은 `<이름>.json.bak-<날짜시각>` 으로 남습니다.

리더의 **이 보정 쓰기** 는 로봇에 저장되지 않고 **그 브라우저** 의 조작 화면 기본값만 바꿉니다. 다른 브라우저나 기기에서는 기본값이 다시 `leader` 입니다. 팔 원격 조작 중에는 리더 보정을 받지 않으니, 조작 화면에서 **멈춤** 을 먼저 누르세요. 보정을 시작하면 PC 에이전트가 연결해 두었던 리더암 연결을 먼저 끊습니다.

### 6.2. [앱] Physical Labs 로 보정

1. **[PC]** 리더암 USB 를 노트북에 꽂습니다. 리더 포트는 **로봇 설정** 의 `1. Leader Arm (USB-PC 직결)` 에서 골라 저장해 둔 것이어야 합니다.
2. **[앱]** **칼리브레이션** 탭의 왼쪽 목록에서 **leader arm** 을 고릅니다.
3. **[PC]** 리더암을 3D 화면과 같은 가운데(기역자) 자세로 두고, **[앱]** `연결 설정` 칸의 **🔌 연결** 을 누릅니다.
4. **[앱]** 자세를 받친 채 **🛠 보정 시작** → **측정 시작** → 관절마다 양 끝까지 움직이기 → 빨간 **측정 종료** → `보정 완료`. 같은 이름의 파일이 있으면 먼저 `재보정 확인` 창이 묻고, **Yes** 를 누르면 그 파일을 덮어씁니다 (PC 에이전트와 달리 예전 파일이 남지 않습니다).

보정 이름은 **로봇 설정** 의 `teleop id` (예: `leader`) 입니다. teleop id 가 정확히 `leader` 면 이 탭 아래 **저장된 캘리브레이션** 칸은 `저장된 캘리브레이션 없음` 으로 보이지만, 파일은 `보정 완료` 창에 나온 경로에 저장되고 다른 탭은 정상으로 씁니다. 단계마다 무엇이 보이는지는 [Physical Labs 칼리브레이션](/docs/physical-labs/calibration)에서 SO-101 팔과 같이 설명합니다.

> **팁** 💡`TIP`
> <br>**리더암 포트는 한 번에 한 프로그램만 씁니다** PC 에이전트가 리더 포트를 연 동안에는 그 포트를 혼자 쥐고 있어 Physical Labs 가 리더암을 열지 못합니다 (`Device or resource busy`). 앱으로 리더를 쓰기 전에는 PC 에이전트 터미널에서 Ctrl+C 로 끄세요. 두 프로그램은 노트북의 같은 폴더에 리더 보정 파일을 둡니다 (7절).

## 7. 보정 파일은 어디에 있나

| 무엇 | 어디 | 메모 |
|---|---|---|
| 팔로워 보정 파일 | **[로봇]** `~/.cache/huggingface/lerobot/calibration/robots/lekiwi/<이름>.json` | 새로 보정은 늘 새 이름으로 만들어, 예전 파일이 남습니다 |
| 지금 쓰는 보정 이름 · 접은 자세 | **[로봇]** `~/lekiwi_ws/arm_profile.yaml` | 웹 화면 · 앱이 쓰는 파일입니다. 손으로 고치지 마세요 |
| 리더 보정 파일 | **[PC]** `~/.cache/huggingface/lerobot/calibration/teleoperators/so_leader/<이름>.json` | Physical Labs 와 PC 에이전트가 같은 폴더를 씁니다 |

로봇 안의 파일 목록은 웹 화면에서 보는 것이 가장 쉽습니다. 터미널로 보려면 Pi 에 SSH 로 접속합니다 (계정 `roboseasy`, 비밀번호는 스페이스 한 번).

```bash
# 우분투
ssh roboseasy@lekiwi01.local 'ls -l ~/.cache/huggingface/lerobot/calibration/robots/lekiwi/'
```

- 앱 **로봇 설정** 의 `robot id` 는 로봇 안의 보정 이름과 따로입니다. 앱은 로봇이 지금 쓰는 보정 이름을 로봇에서 읽어 옵니다.
- SD 카드를 새로 구우면 로봇 쪽 보정 파일과 접은 자세가 지워집니다. 팔 모터를 바꾸지 않았다면 웹 화면의 **모터 값으로 파일 만들기** 로 되살리고 (3.4절), 접은 자세는 다시 저장합니다 ([SD 카드 굽기](/docs/a-go/lekiwi-sd-card)).

## 8. 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 웹 화면 버튼이 모두 흐리고 `먼저 조작 권한을 받으세요` | 위쪽 막대의 **조작 권한 받기** |
| `다른 화면(<IP> · <브라우저>)이 조작 중입니다` | 다른 브라우저나 앱이 조작 권한을 쥐고 있습니다. 그쪽에서 **권한 놓기** 를 누르거나 창을 닫습니다 (신호가 2초 끊기면 넘겨받을 수 있습니다) |
| 웹 화면에서 `PC(ZMQ, <IP>)가 조작 중입니다` | Physical Labs 가 텔레오퍼레이션 · 데이터 수집 · 추론 중입니다. 앱에서 멈춥니다 |
| 앱에서 `텔레옵 · 데이터 수집 · 추론을 먼저 멈추세요 (PC 가 로봇을 조작 중입니다)` | 앱의 다른 탭 작업을 멈추고 2초쯤 뒤 다시 누릅니다 |
| `팔 토크가 켜져 있습니다. 조작 화면에서 먼저 ‘팔 힘 빼기’를 누르세요` | 팔을 받치고 조작 화면의 **팔 힘 빼기**. 앱은 **🔓 토크 해제 (직접 교시)** |
| `팔 원격 조작 중입니다. 조작 화면에서 먼저 ‘멈춤’과 ‘팔 힘 빼기’를 누르세요` | 조작 화면에서 **멈춤** → **팔 힘 빼기** |
| `지도 작성 · 자율 주행을 먼저 끄세요` | 지도 작성 · 자율 주행을 끕니다 |
| 파일이 모두 `확인 전` · `모터 보정 값을 받지 못해 맞는지 볼 수 없습니다 (로봇 기능을 켜세요)` | 로봇 기능을 켭니다 |
| `이미 있는 이름입니다. 다른 이름을 쓰세요` | 팔로워 새로 보정은 새 이름만 받습니다 |
| `움직이지 않은 관절이 있습니다: …` · 앱 `저장하지 못했습니다 — 모든 관절을 끝까지 움직였는지 확인한 뒤 다시 [측정 종료]를 누르세요.` | 그 관절을 끝까지 움직이고 **끝내기** (앱은 **측정 종료**) 를 다시 누릅니다 |
| 빨간 상자 `지난 새로 보정이 끝나지 않았습니다` | 웹 화면의 **복원** (3.5절). 앱에는 없습니다 |
| 앱에서 `팔을 접지 못했습니다` 창 | 접은 자세가 아직 없습니다. 팔을 받치고 **Yes** → 끝난 뒤 접은 자세를 저장합니다 |
| `팔 모터 6개의 지금 위치를 받지 못했습니다 (lekiwi/motor/states)` | 로봇 기능이 꺼져 있습니다. 켠 뒤 다시 저장합니다 |
| 로봇을 끌 때 `팔을 접지 못했습니다. 그래도 끌까요?` · 앱 `로봇 끄기` 창 | 접은 자세가 없습니다. 팔을 받치고 **그래도 끄기** (앱은 **팔 힘 빼고 끄기**) → 다음에 켰을 때 접은 자세를 저장합니다 |
| 앱 텔레오퍼레이션 · 데이터 수집에서 `팔로워 보정이 필요합니다.` | 팔로워를 보정하거나, 웹 화면에서 `모터와 맞음` 인 파일을 골라 씁니다 |
| 웹 조작 화면의 팔로워 상태 `보정 파일이 없습니다: <경로>` · 앱 상태 줄 `팔로워: 보정 파일 <이름>.json 이 없습니다` | 새로 구운 카드처럼 보정 파일이 없습니다. 팔로워를 새로 보정하거나, **모터 값으로 파일 만들기** 를 합니다 (3.4절) |
| 웹 조작 화면의 팔로워 상태 `보정 파일이 이 로봇의 모터와 다릅니다 (…)` · 앱 상태 줄 `팔로워: <이름>.json 이 모터와 다릅니다` | 다른 로봇의 파일이거나 보정 뒤 모터 값이 바뀌었습니다. 웹 화면에서 `모터와 맞음` 인 파일을 고르거나 새로 보정합니다 |
| 앱 연결 줄이 빨강 `로봇 게이트웨이(<IP>:8080)에 연결하지 못했습니다: …` | 로봇 전원 · 네트워크 · 주소를 확인합니다. 주소를 바꿨다면 **로봇 설정** 에서 **로봇 저장** 을 눌러야 이 탭이 새 주소를 씁니다 |
| 리더 판에 `PC 에이전트가 연결되지 않았습니다 (PC에서 실행 명령을 실행하세요)` | 노트북 터미널에서 PC 에이전트를 실행하고, `--robot` 주소가 맞는지 봅니다 |
| PC 에이전트 터미널에 `보정: 팔 토크가 켜져 있습니다 (…). 먼저 팔 힘을 빼세요` | 조작 화면에서 **리더암 연결** 을 했다가 **리더암 끊기** 를 하면 리더 힘이 빠집니다 |
| PC 에이전트 터미널에 `보정: 어느 리더 포트인지 모릅니다` | 노트북에 시리얼 장치가 여러 개입니다. 조작 화면에서 리더 포트를 골라 **리더암 연결** 을 한 번 합니다 |
| `Device or resource busy` · `다른 프로그램이 포트를 쓰고 있습니다` | 리더 포트를 다른 프로그램(PC 에이전트 · Physical Labs)이 쓰고 있습니다. 한쪽을 끕니다 |
| 팔로워가 리더보다 늘 몇 도 틀어진 채 따라옴 | 두 팔을 같은 가운데 자세로 다시 보정합니다 (1.4절) |

그 밖의 문제는 [문제 해결](/docs/a-go/troubleshooting)을 보세요.

## 9. 정리

- 캘리브레이션은 관절마다 **가운데 자세와 최소 · 최대 범위** 를 재서 tick 을 각도로 바꾸는 표를 만드는 일입니다. 새 A-Go 는 보정 파일이 모터와 맞아야 팔을 움직입니다.
- 새로 구운 SD 카드에는 보정이 없습니다. **팔로워 보정 → 접은 자세 저장 → 리더 보정** 순서로 합니다.
- 팔로워는 웹 화면 **캘리브레이션** 이나 Physical Labs **칼리브레이션** 탭에서 보정합니다. 파일 고르기 · 모터 값으로 파일 만들기 · 복원은 웹 화면에만 있습니다.
- 새로 보정하면 접은 자세가 지워집니다. 팔 힘을 뺀 채 접은 자세로 두고 다시 저장한 뒤, 로봇 기능을 한 번 껐다 켭니다.
- 리더암은 PC 에이전트(웹 화면)나 Physical Labs 로 보정하고, 파일은 노트북에 남습니다.
