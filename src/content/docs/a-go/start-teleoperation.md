# 웹 화면에서 조작하기 (바퀴 · 팔)

웹 화면의 **조작** 화면에서는 카메라 영상을 보면서 키보드로 LeKiwi의 바퀴를 몰고, 노트북에 꽂은 리더암으로 로봇 팔을 움직입니다. 바퀴는 브라우저만 있으면 되고, 팔은 노트북에서 [PC 에이전트](/docs/a-go/pc-agent)를 켜 두어야 합니다. 바퀴와 팔은 한 화면에서 동시에 조작할 수 있습니다. 조작하는 모습을 데이터로 모으거나 학습한 모델로 로봇을 움직이려면 Physical Labs 앱을 씁니다(8절).

> 🎯 **학습 목표**
>
> - 조작 화면의 카메라 · 레이더 · 속도 · 키 패드 · 텔레오퍼레이션 칸이 무엇을 보여 주는지 설명할 수 있다.
> - 조작 권한을 받고 **조작 켜기**로 바퀴 토크를 켠 뒤, 키보드로 바퀴를 몰 수 있다.
> - 속도 단계를 `R` / `F` 로 바꾸고, 화면에 적힌 속도 상한을 읽을 수 있다.
> - PC 에이전트와 리더암으로 팔을 움직이고, **멈춤** · **팔 힘 빼기** · **비상 정지**의 차이를 설명할 수 있다.
> - 로봇이 스스로 멈추는 경우를 알고, 화면의 이유 글로 문제를 찾을 수 있다.

## 1. 시작하기 전에

### 1.1. 준비물

| 준비물 | 설명 |
|---|---|
| 웹 화면을 연 브라우저 | 노트북 · 휴대폰 어느 것이든 됩니다. 여는 방법은 [처음 접속하기](/docs/a-go/first-connection)에 있습니다 |
| 조작 권한 · 로봇 켜기 | 위쪽 막대의 **조작 권한 받기** → 대시보드의 **로봇 켜기** 로 로봇이 `실행 중` 이어야 합니다. 카메라를 보려면 **카메라 포함** 을 켠 채로 켭니다 ([대시보드와 조작 권한](/docs/a-go/web-dashboard)) |
| 바퀴를 띄울 받침 | 처음 몰 때는 상자 같은 받침에 올려 바퀴가 바닥에 닿지 않게 합니다 |
| 넓은 바닥 | 주변에 사람 · 케이블 · 깨지기 쉬운 물건이 없어야 합니다 |
| (팔) SO-101 리더암 + 리눅스 노트북 | 리더암을 노트북 USB 에 꽂고 [PC 에이전트](/docs/a-go/pc-agent)를 실행합니다 |
| (팔) 보정 파일 | 로봇 팔(팔로워)과 리더암 모두 [캘리브레이션](/docs/a-go/start-calibration)에서 `모터와 맞음` 인 보정이 있어야 합니다 |

### 1.2. 안전 수칙

> **경고** ⚠️ `WARN`
> <br>**바퀴와 팔은 실제로 움직입니다** 조작하는 동안 로봇의 주 전원 스위치에 손이 닿는 사람이 옆에 있어야 합니다. 비상 정지는 와이파이로 보내는 명령이라 와이파이가 끊기면 로봇에 닿지 않습니다. 그때도 로봇은 스스로 멈추지만(6절), 마지막 수단은 언제나 주 전원입니다.

- 처음 몰 때는 바퀴를 띄운 채로 방향부터 확인합니다(3.4절).
- 속도는 처음 단계(5) 그대로 몰아 보고 조금씩 올립니다.
- 팔을 편 채로 **팔 힘 빼기** 나 **비상 정지** 를 누르면 팔이 떨어집니다. 팔 아래를 비우고, 손으로 받칠 준비를 합니다.
- 조작하는 브라우저 창은 늘 앞에 둡니다.

## 2. [웹 화면] 조작 화면 둘러보기

왼쪽 메뉴(폭이 좁은 화면은 아래 탭바)에서 **조작** 을 누릅니다. 주소 끝이 `#/drive` 로 바뀝니다.

![웹 조작 화면 — 왼쪽에 전방 카메라와 작은 손목 카메라, 오른쪽에 조작 버튼 · 키 패드 · 속도 단계](/img/a_go/web-drive.webp)

*조작 권한을 받았지만 아직 바퀴 토크를 켜지 않은 모습입니다. 오른쪽 아래로 텔레오퍼레이션 칸이 이어집니다.*

| 칸 | 보여 주는 것 |
|---|---|
| **전방 카메라** (크게) | 로봇 앞을 보는 카메라. 왼쪽 아래에 `전방 카메라 13 fps` 처럼 지금 받는 초당 장수가 나옵니다 |
| **손목 카메라** (작게) | 팔 끝(그리퍼)에 달린 카메라 |
| **카메라 바꾸기** | 큰 화면과 작은 화면을 서로 바꿉니다. 화면 배치만 바꾸며, 어느 카메라가 전방인지는 바꾸지 않습니다 |
| **조작 권한 받기** / **조작 권한 놓기** | 이 화면이 로봇을 움직일 권한을 받거나 놓습니다. 위쪽 막대의 버튼과 같습니다 |
| **조작 켜기** / **조작 끄기** | 바퀴 토크를 켜고 끕니다. 팔 토크와는 따로입니다 |
| 노란 안내 띠 | 지금 왜 움직일 수 없는지 알려 줍니다 (예: `‘조작 켜기’를 눌러야 바퀴가 움직입니다`) |
| 키 패드 | `Q` `W` `E` / `A` `S` `D` / **정지**. 키보드와 같은 배치이고, 마우스나 손가락으로 누르고 있는 동안 움직입니다 |
| **속도 단계** | 지금 단계와 속도 (예: `0.06 m/s · 20°/s`). 슬라이더나 `R` / `F` 키로 바꿉니다 |
| 레이더 (아래 왼쪽) | 라이다가 본 로봇 둘레 3 m 의 점. 위쪽(`앞`)이 로봇 앞입니다. 스캔이 오지 않으면 `스캔 없음` |
| **지금 내보내는 속도** | 로봇에 보내고 있는 `앞뒤 vx` · `좌우 vy` · `회전 wz` 와 `상태` (`움직이는 중` / `정지`) |
| **텔레오퍼레이션** (오른쪽 아래) | 리더암으로 팔을 움직이는 칸 (5절) |

![레이더와 지금 내보내는 속도 칸](/img/a_go/web-drive-speed.webp)

*레이더의 빨간 점이 라이다가 본 벽과 물건입니다. 오른쪽 칸 맨 아래에 이 화면에서 낼 수 있는 최고 속도가 적혀 있습니다(4절).*

> **정보** ℹ️ `INFO`
> <br>**웹 화면의 영상은 미리보기입니다** 카메라 한 대당 초당 15장까지만 보내므로 실제 카메라(초당 30장)보다 덜 부드럽게 보입니다. 카메라 칸이 `신호 없음` 이면 로봇을 **카메라 포함** 없이 켰을 수 있습니다. 대시보드에서 **로봇 끄기** → **카메라 포함** 확인 → **로봇 켜기** 를 합니다. 전방과 손목이 뒤바뀌어 보이면 [카메라 연결](/docs/a-go/setup-cameraport)을 봅니다.

## 3. [웹 화면] 바퀴 몰기

### 3.1. 조작 권한 받기

조작 권한이 없으면 키 패드가 흐리게 보이고 노란 띠에 `먼저 조작 권한을 받으세요` 가 나옵니다. 키 패드 위의 **조작 권한 받기** (또는 위쪽 막대의 같은 버튼)을 누릅니다. 위쪽 막대가 `내가 조작 중` 으로 바뀌면 됩니다.

![조작 권한이 없을 때의 키 패드 — 보라색 조작 권한 받기 버튼과 흐린 키](/img/a_go/web-drive-no-lease.webp)

*권한은 한 번에 한 화면만 가집니다. 다른 화면이 쥐고 있으면 위쪽 막대에 `<IP> · <브라우저> 조작 중` 이 보이고, 그 화면이 놓을 때까지 받을 수 없습니다.*

다른 화면이 권한을 쥐고 있으면 그 화면에서 **권한 놓기** 를 누르거나 그 화면을 닫습니다(신호가 2초 끊기면 넘겨받을 수 있습니다). 권한 규칙은 [대시보드와 조작 권한](/docs/a-go/web-dashboard)에 정리되어 있습니다.

### 3.2. 조작 켜기

1. **조작 켜기** 를 누릅니다.
2. 확인 창 `조작을 켤까요?` 가 뜹니다. `바퀴 토크를 켭니다. 바퀴가 움직입니다. 주변에 사람 · 케이블이 없고, 처음에는 바퀴를 띄웠는지 확인하세요.` 를 읽고 주변을 확인한 뒤, 창 안의 **조작 켜기** 를 누릅니다.
3. 버튼이 `조작 켜는 중…` 으로 바뀌었다가 알림 `바퀴 토크를 켰습니다` 가 뜹니다. 위쪽 막대가 `바퀴 토크 켜짐` 으로 바뀌고 노란 안내 띠가 사라집니다.

<!-- 그림 필요: 웹 조작 화면 · 확인 창 '조작을 켤까요?' (창 안 빨간 비상 정지 버튼이 보이게) -->

확인 창이 떠 있는 동안에는 위쪽 막대를 누를 수 없지만, 창 안에도 빨간 **비상 정지** 가 있습니다. 급할 때는 창 안의 버튼을 누릅니다.

### 3.3. 키로 몰기

| 키 | 동작 |
|---|---|
| `W` / `S` | 앞 · 뒤 |
| `A` / `D` | 왼쪽 · 오른쪽 (몸을 돌리지 않고 옆으로) |
| `Q` / `E` | 제자리 회전 (`Q` 왼쪽, `E` 오른쪽) |
| `Space` | 정지 |
| `R` / `F` | 속도 단계 한 칸 올림 / 내림 |
| `Esc` | 조작 끄기 (바퀴 토크 끔) |

- **누르고 있는 동안만** 움직입니다. 키를 모두 떼면 바로 멈춥니다.
- 여러 키를 함께 누르면 합쳐집니다. 예를 들어 `W` 와 `Q` 를 함께 누르면 앞으로 가면서 왼쪽으로 돕니다.
- `Space` 를 누르면 누르고 있던 키를 모두 놓은 것으로 보고 멈춥니다. 다시 움직이려면 키를 새로 누릅니다.
- 한글 입력 상태여도 됩니다.
- 글자를 치는 칸이나 고르기 칸에 커서가 있으면 키를 조작으로 쓰지 않습니다. 화면의 빈 곳을 한 번 누른 뒤 다시 누릅니다.
- `Ctrl` · `Alt` · `Cmd` 와 함께 누른 키는 무시합니다.
- 휴대폰 · 태블릿에서는 화면의 키 패드를 손가락으로 누르고 있는 동안 움직입니다. 마우스가 있는 컴퓨터에서는 속도 단계 아래에 키 안내도 함께 보입니다.
- 게임패드 · 조이스틱은 지원하지 않습니다.

### 3.4. [로봇] 처음에는 바퀴를 띄우고 방향 확인

받침 위에 바퀴를 띄운 채로 `W` · `A` · `Q` 를 하나씩 짧게 눌러 봅니다. 바퀴가 그 방향으로 도는지 보고, **지금 내보내는 속도** 칸의 숫자도 함께 봅니다. `W` 는 `앞뒤 vx`, `A` 는 `좌우 vy`, `Q` 는 `회전 wz` 가 양수(+)가 됩니다.

바퀴가 예상과 다르게 돌면 바로 키를 떼고 `Esc` 로 조작을 끈 뒤 [문제 해결](/docs/a-go/troubleshooting)을 봅니다. 방향이 맞으면 바닥에 내려놓고 시작 단계 그대로 조금씩 움직여 봅니다.

### 3.5. 조작 끄기 · 권한 놓기

다 쓰면 **조작 끄기** (`Esc`)를 누릅니다. 알림 `바퀴 토크를 껐습니다` 가 뜨고 위쪽 막대가 `바퀴 토크 꺼짐` 으로 바뀝니다. 다른 화면이나 Physical Labs 가 로봇을 쓸 수 있도록 **조작 권한 놓기** 도 누릅니다. 권한을 놓으면 이 권한으로 켠 바퀴 토크도 함께 꺼집니다.

## 4. 속도 단계와 상한

속도 단계는 0 부터 22 까지 있고, 처음에는 **단계 5** (`0.06 m/s · 20°/s`)에서 시작합니다. `R` / `F` 를 한 번 누를 때마다 한 칸씩 바뀝니다(꾹 눌러도 한 칸입니다). 슬라이더를 끌어도 됩니다.

| 단계 | 앞뒤 · 옆 속도 | 회전 속도 | 메모 |
|---|---|---|---|
| 0 | 0.01 m/s | 3°/s | 가장 느림 |
| 5 | 0.06 m/s | 20°/s | 시작 값 |
| 9 | 0.10 m/s | 33°/s | 상한을 못 읽었을 때(`기본값`)의 최고 단계 |
| 10 | 0.11 m/s | 37°/s | 지도 작성 화면 패드의 최고 단계 |
| 15 | 0.16 m/s | 53°/s | |
| 19 | 0.20 m/s | 66°/s | |
| 22 | 0.23 m/s | 88°/s | 조작 화면의 최고 단계 |

**지금 내보내는 속도** 칸 맨 아래에 이 화면의 상한이 나옵니다.

| 화면 글자 | 뜻 |
|---|---|
| `상한 0.23 m/s · 옆 0.23 m/s · 88°/s (베이스 컨트롤러 설정)` | 로봇의 바퀴 제어 설정에서 읽은 상한입니다. 단계 22 까지 고를 수 있습니다 |
| `… (기본값)` | 아직 로봇 설정을 읽지 못해 낮은 상한(0.10 m/s · 33°/s)을 씁니다. 로봇이 꺼져 있을 때 이렇게 보이며, 단계 9 까지만 고를 수 있습니다 |

[지도 작성 · 자율 주행](/docs/a-go/web-mapping-navigation) 화면의 작은 패드는 지도를 망치지 않도록 더 낮은 상한(단계 10, 0.11 m/s)을 씁니다.

> **팁** 💡`TIP`
> <br>처음에는 시작 값 그대로 몰아 보고, 익숙해지면 `R` 로 한 칸씩 올립니다. 좁은 곳을 지나거나 팔을 편 채로 움직일 때는 다시 낮춥니다.

## 5. 팔 조작 — 텔레오퍼레이션 칸

조작 화면 오른쪽 아래의 **텔레오퍼레이션** 칸에서는 노트북에 꽂은 SO-101 리더암을 움직이는 대로 로봇 팔이 따라 움직입니다. 바퀴는 키보드, 팔은 리더암으로 함께 쓸 수 있습니다. 칸 제목 오른쪽에 팔 토크 상태(`팔 토크 켜짐` / `팔 토크 꺼짐`)가 보입니다.

### 5.1. 칸 구성

| 부분 | 하는 일 |
|---|---|
| **PC 에이전트** | 노트북의 PC 에이전트가 붙었는지(`연결됨` / `연결 안 됨`)와 그 PC 의 이름 · IP. 붙지 않았으면 받기 · 실행 명령과 **복사** 버튼이 나옵니다. 붙으면 **이 PC 쓰기** 로 그 PC 의 리더암을 쓰도록 허락합니다 |
| **리더암** | **포트** 와 **보정** 을 고르고 **리더암 연결** / **리더암 끊기**. 연결되면 `보정 leader · 30.0 Hz` 처럼 보이고, 팔 시작 뒤에는 끝에 `· 팔로 보내는 중` 이 붙습니다 |
| **팔** | **팔 시작** · **멈춤** · **팔 힘 빼기** 와 팔 상태 (`대기` · `맞추는 중` · `따라가는 중` · `접는 중` · `접음` · `오류`) |
| 관절 표 | 관절마다 리더 · 팔로워 각도와 차이 (5.3절) |

![텔레오퍼레이션 칸의 리더암 · 팔 부분 — PC 에이전트가 아직 붙지 않은 상태](/img/a_go/web-drive-teleop-arm.webp)

*PC 에이전트가 붙기 전에는 **리더암 연결** · **팔 시작** 버튼이 흐리고, 이유 글이 `PC 에이전트가 연결되지 않았습니다 (PC에서 실행 명령을 실행하세요)` 로 나옵니다.*

### 5.2. 팔 움직이기

1. **[PC]** 노트북에 리더암을 꽂고 PC 에이전트를 실행합니다. 설치 · 실행 방법은 [PC 에이전트 (리더암)](/docs/a-go/pc-agent)에 있고, **PC 에이전트** 칸의 **복사** 버튼으로 이 로봇 주소가 들어간 명령을 바로 복사할 수도 있습니다. 붙으면 칸이 `연결됨` 이 되고 알림 `PC 에이전트가 연결되었습니다 (<PC 이름> · <IP>)` 가 뜹니다.
2. **[웹 화면]** **이 PC 쓰기** 를 누릅니다. `허락 전` 이 `이 PC 씀` 으로 바뀝니다.
3. **[웹 화면]** **포트** 에서 리더암 포트(예: `/dev/ttyACM0 · usb-1a86_…`)를, **보정** 에서 리더 보정 파일(보통 `leader`)을 고르고 **리더암 연결** 을 누릅니다. 상태가 `연결 중` → `연결됨` 으로 바뀝니다.
4. **[로봇]** 팔 주변을 비우고, 리더암을 로봇 팔과 비슷한 자세로 듭니다.
5. **[웹 화면]** **팔 시작** 을 누릅니다. 확인 창 `팔을 시작할까요?` 에 `팔 토크를 켜고 리더암을 따라 움직입니다. 자세 차이가 크면 2초 동안 천천히 맞춥니다. 팔 주변을 비우세요.` 가 나옵니다. 창 안의 **팔 시작** 을 누릅니다.
6. 버튼이 `팔 켜는 중…` 으로 바뀌었다가 알림 `팔 원격 조작을 시작했습니다 (팔 토크 켬)` 이 뜹니다. 팔 상태가 `맞추는 중` → `따라가는 중` 으로 바뀌면 리더암을 움직이는 대로 팔이 따라옵니다.
7. 바퀴도 함께 몰려면 **조작 켜기** 를 누른 뒤 키보드를 씁니다(3절).

<!-- 그림 필요: 웹 조작 화면 · 텔레오퍼레이션 칸 — PC 에이전트 연결됨 · 이 PC 씀 · 리더암 연결됨 · 보정 leader · 30.0 Hz · 팔로 보내는 중 · 팔 따라가는 중 · 관절 표에 리더 · 팔로워 · 차이 값이 찬 상태 -->

> **팁** 💡`TIP`
> <br>**포트 · 보정은 리더암을 연결하기 전에 고릅니다** 연결한 뒤에는 바꿀 수 없으니, 바꾸려면 **리더암 끊기** 를 누른 뒤 다시 고릅니다. **보정** 의 기본값은 이 브라우저의 캘리브레이션 화면에서 **이 보정 쓰기** 로 고른 리더 보정 → `leader` → 목록의 첫 파일 순서로 정해집니다.

### 5.3. 관절 표 읽기

![관절 표 — 어깨 회전부터 그리퍼까지 리더 · 팔로워 · 차이](/img/a_go/web-drive-teleop-joints.webp)

*리더암이 아직 연결되지 않아 리더 · 차이 칸은 `—` 이고, 팔로워(로봇 팔) 각도만 보입니다.*

- 관절은 `어깨 회전` · `어깨 들기` · `팔꿈치` · `손목 굽힘` · `손목 회전` · `그리퍼` 여섯 개입니다.
- 각도는 도(°) 단위이고, 그리퍼는 0~100 입니다.
- **차이** 가 8 을 넘으면 노랗게 표시됩니다. 팔이 리더를 아직 따라가지 못했다는 뜻입니다. 시작 직후(`맞추는 중`)라면 잠시 기다리고, 계속 노랗다면 팔이 무언가에 걸리지 않았는지 봅니다.

### 5.4. 멈춤 · 팔 힘 빼기 · 비상 정지

| 버튼 | 팔은 어떻게 되나 | 언제 쓰나 |
|---|---|---|
| **멈춤** (팔 시작 뒤에 보임) | 리더를 그만 따라가고, **토크를 켠 채 그 자리** 에 멈춥니다 | 잠깐 쉬거나 리더암을 내려놓을 때 |
| **팔 힘 빼기** | 팔 원격 조작을 멈추고 팔 토크를 끕니다. **편 팔과 잡은 물건이 떨어집니다** | 팔을 손으로 받친 채 힘을 빼야 할 때. 확인 창 `팔 힘을 뺄까요?` 가 한 번 더 묻습니다 |
| **비상 정지** (위쪽 막대) | 바퀴를 세우고 **바퀴 · 팔 토크를 모두 끕니다. 편 팔이 떨어집니다** | 위험할 때. 조작 권한이 없는 화면에서도 누구나 누를 수 있습니다 |

> **경고** ⚠️ `WARN`
> <br>**비상 정지는 팔도 놓습니다** 팔을 편 채로 비상 정지를 누르면 팔과 그리퍼에 든 물건이 그대로 떨어집니다. 팔을 놓지 않고 멈추려면 **멈춤** 을 누르고, 팔을 편 채로 다룰 때는 팔 아래를 비워 둡니다.

웹 화면에는 팔을 접는 버튼이 따로 없습니다. 대시보드의 **로봇 끄기** 가 로봇을 끄기 전에 팔을 접은 자세로 접고 팔 토크를 끕니다. 이때 접은 자세가 저장돼 있어야 합니다([캘리브레이션](/docs/a-go/start-calibration)의 **접은 자세 저장**).

### 5.5. 팔 원격 조작이 저절로 멈추는 경우

| 일 | 팔 |
|---|---|
| 조작 권한이 끝남 (놓음 · 탭 닫음 · 신호 2초 끊김) | 토크를 켠 채 그 자리에 멈춥니다 (알림 `팔 원격 조작을 멈췄습니다 (조작 권한이 끝남). 팔은 토크를 켠 채 그 자리를 유지합니다`). PC 에이전트 허락도 함께 끝나므로, 권한을 다시 받은 뒤 **이 PC 쓰기** 부터 다시 합니다 |
| 리더 값이 0.5초 넘게 오지 않음 | 그 자리에 멈춥니다 (알림 `리더 값이 0.5초 넘게 오지 않아 팔 목표를 그쳤습니다 (팔은 그 자리를 유지합니다)`). 값이 다시 오면 이어서 따라갑니다 (자세 차이가 크면 다시 2초 동안 천천히 맞춥니다) |
| 허락한 PC 에이전트가 5초 넘게 끊김 | 그 자리에 멈춥니다. 에이전트가 다시 붙어도 **팔 시작** 을 다시 눌러야 움직입니다 |
| 비상 정지 | 팔 토크를 끕니다 (팔이 떨어집니다) |

조작 화면을 떠나 다른 메뉴로 가도 팔 원격 조작은 조작 권한이 있는 동안 이어집니다. 팔을 멈추려면 화면을 옮기기 전에 **멈춤** 을 누릅니다.

## 6. 로봇이 스스로 멈추는 경우

조작 화면에는 사람이 놓쳐도 로봇이 멈추도록 하는 장치가 여럿 있습니다.

| 상황 | 로봇 |
|---|---|
| 키 · 패드를 모두 뗌 | 바로 멈춥니다 |
| 창 밖을 누르거나 다른 탭 · 창으로 감 | 누르던 키를 모두 놓고 멈춥니다. 권한은 그대로입니다 |
| 조작 화면을 떠나 다른 메뉴로 감 | 바퀴는 멈춥니다. 팔 원격 조작은 이어집니다(5.5절) |
| 조작 명령이 0.3초 끊김 (와이파이가 느려짐 등) | 바퀴 속도를 0 으로 합니다 |
| 조작하던 탭을 닫거나 새로 고침 | 바로 권한이 끝나고, 멈추고, 이 권한으로 켠 바퀴 토크를 끕니다 |
| 화면의 생존 신호가 2초 끊김 (네트워크 끊김 · 브라우저 멈춤 · 휴대폰 화면 꺼짐) | 위와 같습니다. 다시 연결돼도 권한은 돌아오지 않으니 **조작 권한 받기** 부터 다시 합니다 |
| 조작 탭을 몇 분 넘게 뒤에 숨겨 둠 | 브라우저가 화면의 타이머를 늦춰 권한이 끝날 수 있습니다 (안전하게 멈춥니다) |
| 비상 정지 | 바퀴를 세우고 바퀴 · 팔 토크를 끕니다. 풀 때까지 걸린 채로 남습니다 |

### 6.1. 비상 정지 풀기

비상 정지가 걸리면 모든 화면 위에 빨간 띠 `비상 정지됨 (<누른 화면>). 다시 움직이려면 ‘조작 켜기’를 누르세요` 가 뜹니다.

<!-- 그림 필요: 웹 화면 위쪽 빨간 띠 '비상 정지됨 (…). 다시 움직이려면 ‘조작 켜기’를 누르세요' (바퀴를 띄운 안전한 상태에서) -->

1. 위험한 것이 없는지 확인합니다.
2. 조작 권한이 있는 화면에서 **조작 켜기** 를 누릅니다. 성공하면 비상 정지가 풀리고 바퀴 토크가 다시 켜집니다. 누른 지 1초 안에는 `비상 정지 직후입니다. 잠시 뒤 다시 누르세요` 로 거절되니 잠시 뒤 누릅니다.
3. 풀린 뒤에도 누르고 있던 키는 무시되므로 키를 새로 누릅니다.
4. 팔은 **팔 시작** 을 다시 눌러야 움직입니다. 비상 정지가 걸린 동안 **팔 시작** 은 `비상 정지가 걸려 있습니다. 먼저 ‘조작 켜기’로 푸세요` 로 거절됩니다. 권한을 놓았다 다시 받아도 비상 정지는 풀리지 않습니다.

## 7. 끝내기

1. **[웹 화면]** **멈춤** — 팔이 그 자리에 멈춥니다.
2. **[웹 화면]** **리더암 끊기**.
3. **[웹 화면]** **조작 끄기** (`Esc`).
4. **[웹 화면]** 팔을 정리합니다. 로봇을 끌 거라면 대시보드에서 **로봇 끄기** 를 누릅니다. 끄기 전에 팔을 접은 자세로 접고 팔 토크를 끕니다. 로봇을 켜 둘 거라면 팔을 손으로 받친 채 **팔 힘 빼기** 를 누릅니다.
5. **[웹 화면]** **조작 권한 놓기**.
6. **[PC]** PC 에이전트 터미널에서 `Ctrl+C` 를 누릅니다(`PC 에이전트를 끝냈습니다`).

> **경고** ⚠️ `WARN`
> <br>**접은 자세가 없으면 로봇 끄기가 거절됩니다** 팔 토크가 켜진 채로 **로봇 끄기** 를 누르면 먼저 팔을 접는데, 접은 자세가 저장돼 있지 않으면 확인 창 `팔을 접지 못했습니다. 그래도 끌까요?` 가 뜹니다. **그래도 끄기** 는 팔 힘을 빼고 끄므로 팔이 떨어집니다. 팔을 손으로 받치고 누르거나, 미리 [캘리브레이션](/docs/a-go/start-calibration)에서 **접은 자세 저장** 을 해 둡니다. 팔로워를 새로 보정하면 접은 자세가 지워지니 다시 저장합니다.

## 8. Physical Labs 로 조작하기

웹 화면은 브라우저만 있으면 바로 쓸 수 있지만, 조작하는 모습을 데이터로 남기지는 않습니다. 모방 학습용 데이터를 모으거나 학습한 모델로 로봇을 움직이려면 PC 앱 **Physical Labs** 의 **텔레오퍼레이션** · **데이터** · **추론** 탭을 씁니다. 앱은 노트북에 꽂은 리더암을 직접 읽으므로 PC 에이전트가 필요 없습니다.

| | 웹 화면 조작 | Physical Labs 텔레오퍼레이션 |
|---|---|---|
| 필요한 것 | 브라우저 (팔은 PC 에이전트) | Physical Labs (Ubuntu 0.1.9) |
| 바퀴 | 키보드 · 화면 패드 (휴대폰도 됨) | 키보드 `W`/`S` · `A`/`D` · `Q`/`E` · `R`/`F` |
| 팔 | 리더암 → PC 에이전트 → 로봇 | 리더암 → 앱 → 로봇 |
| 데이터 수집 · 추론 | 없음 | 있음 |
| 지도 작성 · 자율 주행 | 있음 | 없음 (앱에서 웹 화면을 열어 씁니다) |

![Physical Labs 텔레오퍼레이션 탭 아래쪽 — 바퀴 키 안내와 관절 그래프](/img/a_go/app-lekiwi-teleop-graph.webp)

*Physical Labs 의 LeKiwi 텔레오퍼레이션 탭(연결 전)입니다. 위쪽 줄에 바퀴 키 안내가 보입니다.*

> **정보** ℹ️ `INFO`
> <br>**웹 화면과 앱은 동시에 로봇을 움직이지 않습니다** 웹 화면이 조작 권한을 쥐고 있으면 앱의 연결이 `웹 화면이 조작 중입니다` 로 막힙니다. 앱으로 넘어가기 전에 웹에서 **조작 권한 놓기** 를 누릅니다. 반대로 앱이 조작하는 동안에는 웹 화면의 팔 시작 · 자율 주행 · 보정 · 네트워크 전환이 `PC(ZMQ, <IP>)가 조작 중입니다` 로, 바퀴는 `다른 프로그램이 cmd_vel 을 보내고 있습니다: …` 로 거절됩니다. 비상 정지는 언제나 됩니다. 같은 리더암을 PC 에이전트와 앱이 함께 쓸 수도 없으니, 앱을 쓰기 전에 PC 에이전트는 `Ctrl+C` 로 끕니다.

> **정보** ℹ️ `INFO`
> <br>**Windows 판 Physical Labs(0.1.7)는 새 A-Go 를 지원하지 않습니다** 앱으로 조작하려면 Ubuntu 판(0.1.9)을 씁니다. Windows 노트북으로도 웹 화면에서 바퀴를 몰 수는 있지만, PC 에이전트가 리눅스 전용이라 리더암으로 팔을 움직일 수는 없습니다.

앱을 로봇에 잇는 방법은 [Physical Labs 연결](/docs/a-go/physical-labs-setup), 데이터 수집부터 추론까지의 흐름은 [데이터 · 학습 · 추론](/docs/a-go/physical-labs-workflow), 앱의 텔레오퍼레이션 탭 전체 설명은 [Physical Labs 텔레오퍼레이션](/docs/physical-labs/teleoperation)에 있습니다.

## 9. 문제 해결

화면의 노란 띠나 이유 글에 나오는 문장으로 찾습니다.

| 증상 | 확인할 것 |
|---|---|
| `먼저 조작 권한을 받으세요` | **조작 권한 받기** 를 누릅니다 |
| `‘조작 켜기’를 눌러야 바퀴가 움직입니다` | **조작 켜기** 를 눌러 바퀴 토크를 켭니다 |
| `다른 화면(<IP> · <브라우저>)이 조작 중입니다` | 그 화면에서 **권한 놓기** 를 누르거나 그 화면을 닫습니다 |
| `베이스 컨트롤러가 없습니다. 먼저 로봇을 켜세요` · `lekiwi/motor/power 서비스가 없습니다. 먼저 로봇을 켜세요` | 대시보드에서 **로봇 켜기** 를 눌러 `실행 중` 이 될 때까지 기다립니다. 로봇이 켜져 있는데도 나오면 [센서 · 로그](/docs/a-go/web-sensors-logs)에서 로그를 봅니다 |
| `다른 프로그램이 cmd_vel 을 보내고 있습니다: …` | Physical Labs 가 조작 중이거나, 로봇 터미널에서 키보드 조작 프로그램이 돌고 있습니다. 그쪽을 끕니다 |
| `베이스 컨트롤러가 둘 이상입니다. 같은 ROS_DOMAIN_ID 에 다른 로봇이 있습니다` | 같은 공유기에 같은 ROS_DOMAIN_ID 를 쓰는 로봇이 또 있습니다. 로봇마다 ROS_DOMAIN_ID 를 다르게 합니다 ([문제 해결](/docs/a-go/troubleshooting) · [저장소와 구조](/docs/a-go/developer)) |
| `자율 주행 중에는 직접 조작할 수 없습니다` | [자율 주행](/docs/a-go/web-mapping-navigation)을 끈 뒤 조작합니다 |
| `비상 정지 직후입니다. 잠시 뒤 다시 누르세요` | 1초쯤 기다렸다 다시 누릅니다 |
| 모든 화면 위에 빨간 띠 `비상 정지됨 (…)` | 6.1절처럼 **조작 켜기** 로 풉니다 |
| 이유 글이 없는데 키를 눌러도 안 움직인다 | 글자 칸 · 고르기 칸에 커서가 있는지 봅니다. 화면의 빈 곳을 누른 뒤 다시 누릅니다. `Ctrl` · `Alt` 를 함께 누르고 있지 않은지도 봅니다. 비상 정지 · 조작 끄기 · `Space` 뒤라면 키를 모두 뗐다가 새로 누릅니다 |
| 카메라 칸이 `신호 없음` | 로봇을 **카메라 포함** 없이 켰을 수 있습니다. **로봇 끄기** → **카메라 포함** 확인 → **로봇 켜기**. 그래도 안 나오면 [카메라 연결](/docs/a-go/setup-cameraport) |
| 전방 · 손목 카메라가 뒤바뀌어 보인다 | **카메라 바꾸기** 는 화면 배치만 바꿉니다. [카메라 연결](/docs/a-go/setup-cameraport)대로 두 카메라 USB 를 서로 바꿔 꽂고 **로봇 끄기** → **로봇 켜기** 를 합니다 |
| 레이더가 `스캔 없음` | 로봇이 켜져 있는지 보고, [센서 · 로그](/docs/a-go/web-sensors-logs)에서 라이다를 확인합니다 |
| `PC 에이전트가 연결되지 않았습니다 (PC에서 실행 명령을 실행하세요)` | 노트북에서 PC 에이전트를 실행합니다 ([PC 에이전트](/docs/a-go/pc-agent)) |
| `먼저 ‘이 PC 쓰기’를 누르세요` · `먼저 ‘리더암 연결’을 누르세요` | 5.2절 순서대로 허락 → 리더암 연결을 먼저 합니다 |
| `리더암 포트가 없습니다. PC에 리더암 USB 를 꽂으세요` | 리더암 USB 와 전원을 확인합니다 |
| `리더암 보정 파일이 없습니다. PC에서 lerobot 으로 리더암을 보정하세요` | [캘리브레이션](/docs/a-go/start-calibration)의 리더 칸에서 보정 파일을 만듭니다 |
| `팔 노드가 없습니다 (로봇 · 팔을 켜세요)` | 대시보드에서 **로봇 켜기** 를 합니다 |
| `PC(ZMQ, <IP>)가 조작 중입니다` | Physical Labs 가 로봇을 조작하고 있습니다. 앱의 조작을 끝낸 뒤 다시 누릅니다 |
| 팔이 리더암과 다른 자세로 움직인다 | 팔로워 · 리더 보정이 맞는지 [캘리브레이션](/docs/a-go/start-calibration)에서 `모터와 맞음` 을 확인합니다 |
| 팔이 갑자기 힘이 빠져 떨어졌다 | 누군가 **비상 정지** 나 **팔 힘 빼기** 를 눌렀습니다. 알림에서 누른 화면을 확인합니다 |

더 많은 경우는 [문제 해결](/docs/a-go/troubleshooting)을 봅니다.

## 10. 정리

- **조작** 화면은 카메라 두 대 · 레이더 · 속도 · 키 패드 · 텔레오퍼레이션 칸으로 되어 있습니다.
- 바퀴는 **조작 권한 받기** → **조작 켜기** → `W` `A` `S` `D` `Q` `E` (누르는 동안만) → **조작 끄기** (`Esc`) → **조작 권한 놓기** 순서로 씁니다.
- 속도는 단계 5(0.06 m/s)에서 시작하고 `R` / `F` 로 바꿉니다. 조작 화면의 최고는 0.23 m/s · 88°/s 입니다.
- 팔은 PC 에이전트 → **이 PC 쓰기** → **리더암 연결** → **팔 시작** 으로 움직입니다. **멈춤** 은 팔을 그 자리에 두고, **팔 힘 빼기** 와 **비상 정지** 는 팔을 떨어뜨립니다.
- 데이터 수집 · 추론은 Physical Labs 로 하며, 웹 화면과 앱은 동시에 로봇을 움직이지 않습니다.
