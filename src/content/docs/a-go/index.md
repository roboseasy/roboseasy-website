# A-Go(LeKiwi) 소개

A-Go(LeKiwi)는 옴니휠 이동 베이스 위에 SO-101 로봇 팔을 올린 모바일 로봇입니다. 로봇 안의 라즈베리파이가 ROS 2 로 모터 · 카메라 · 라이다를 직접 다루고, 사람은 브라우저의 **웹 화면**이나 데스크탑 앱 **Physical Labs** 로 로봇을 씁니다. 이 페이지에서는 로봇의 구성과 소프트웨어 구조, 로봇을 쓰는 세 가지 길, 그리고 이 설명서를 읽는 순서를 안내합니다.

## 1. A-Go(LeKiwi)는 어떤 로봇인가요?

### 1.1. 부품 한눈에 보기

A-Go(LeKiwi)는 굴러다니는 몸체(이동 베이스), 물건을 집는 팔, 주변을 보는 센서, 그리고 이 모두를 다루는 작은 컴퓨터로 이루어져 있습니다. 모터 9개는 모두 한 줄의 통신선(버스)에 이어져 있고, 1~6번이 팔, 7~9번이 바퀴입니다.

| 부분 | 구성 | 하는 일 |
|---|---|---|
| 이동 베이스 | 옴니휠 3개 (모터 7~9번) | 앞뒤 · 좌우로 미끄러지듯 움직이고, 제자리에서 돕니다 |
| 팔 | SO-101 팔 (모터 1~6번, 6번이 그리퍼) | 물건을 집고 옮깁니다 |
| 카메라 | 전방(front) · 손목(wrist) 2대 | 로봇 앞쪽과 그리퍼 주변을 봅니다. 데이터 수집 · 추론에 쓰는 눈입니다 |
| 라이다 | 로봇 둘레의 거리를 재는 센서 | 지도 작성 · 자율 주행에 쓰고, 조작 화면에 주변 거리를 보여 줍니다 |
| IMU | 회전 · 기울기를 재는 센서 | 지도 작성을 돕습니다 |
| 두뇌 | Raspberry Pi 4 + microSD 카드 | 위 장치를 모두 직접 다룹니다. 소프트웨어는 카드 한 장에 다 들어 있습니다 |

로봇이 내보내는 관측은 LeRobot 의 LeKiwi 데이터셋과 같은 모양입니다. 팔 관절 6개와 몸체 이동 속도 3개(앞뒤 · 좌우 · 회전)를 합친 **9개 값**, 그리고 카메라 영상 2개가 초당 최대 30번 나옵니다. 그래서 Physical Labs 로 모은 데이터를 같은 앱의 훈련 탭에서 바로 학습할 수 있습니다.

### 1.2. 무엇이 바뀌었나요?

A-Go 의 소프트웨어는 2026년 10월에 **ROS 2 로봇**으로 바뀌었습니다 (SD 카드 이미지 `lekiwi1027`). 예전처럼 라즈베리파이에 들어가 프로그램을 직접 켜지 않고, 웹 화면이나 앱의 버튼으로 로봇을 켜고 씁니다.

| 항목 | 예전 | 지금 |
|---|---|---|
| 로봇 쪽 프로그램 | 라즈베리파이에서 LeRobot 호스트를 터미널로 직접 실행 | ROS 2 Jazzy 노드들이 모터 · 센서를 다루고, 웹 화면은 로봇을 켜면 저절로 뜹니다 |
| 로봇 기능 켜기 | SSH 로 들어가 스크립트 실행 | 웹 화면의 **로봇 켜기** 또는 Physical Labs 의 **▶ 로봇 켜기** |
| PC 준비 | LeRobot 을 직접 설치하고 명령어로 조작 · 기록 · 추론 | 브라우저 또는 Physical Labs 만 있으면 됩니다. PC 에 ROS 2 는 필요 없습니다 |
| 처음 연결 | 랜선으로 먼저 연결 | 로봇이 와이파이 `lekiwi01` 을 직접 띄웁니다 (AP 모드). 랜선도 됩니다 |
| 새로 생긴 것 | — | 지도 작성 · 자율 주행, 비상 정지, 조작 권한 |

> **정보** ℹ️ `INFO`
> <br>**예전 방식(라즈베리파이에서 LeRobot 호스트 실행)의 설명서는 이 설명서로 바뀌었습니다** 예전 이미지(`lekiwi1017` 등)로 쓰던 로봇을 새 방식으로 쓰려면 카드를 새 이미지로 다시 굽습니다. 다시 구우면 카드에 있던 보정 파일 · 와이파이 설정이 모두 지워집니다. 카메라를 꽂는 USB 포트도 예전 안내와 다르니 [카메라 연결](/docs/a-go/setup-cameraport)을 꼭 확인하세요.

## 2. 로봇과 PC 는 무엇을 하나요?

### 2.1. 로봇 안 (Raspberry Pi 4)

로봇의 라즈베리파이에는 Ubuntu 24.04 와 ROS 2 Jazzy 가 들어 있습니다. 하드웨어를 직접 다루는 프로그램은 모두 로봇 안에서 돕니다.

| 프로그램 | 하는 일 | 언제 켜지나 |
|---|---|---|
| 게이트웨이 (웹 화면) | 웹 화면을 보여 주고, 로봇 기능 켜고 끄기 · 조작 · 캘리브레이션 · 네트워크 설정을 받습니다. 주소는 `http://<로봇 주소>:8080` | 로봇 전원을 켜면 저절로 |
| 모터 드라이버 | 모터 9개가 이어진 버스를 여는 단 하나의 프로그램 | 로봇 기능을 켤 때 |
| 센서 · 카메라 | 라이다 · IMU · 전방 · 손목 카메라 | 로봇 기능을 켤 때 |
| 팔로워 팔 · 베이스 컨트롤러 | 팔이 리더암을 부드럽게 따라가게 하고, 바퀴 속도 상한(약 0.23 m/s)을 지킵니다 | 로봇 기능을 켤 때 |
| 데이터 노드 (`lekiwi_zmq_host`) | Physical Labs 와 관측(관절 · 카메라)과 명령을 주고받는 통로 (포트 5555 · 5556) | 로봇 기능을 켤 때 |
| 지도 작성 · 자율 주행 | 라이다로 지도를 만들고, 그 지도에서 목표까지 스스로 갑니다 (Cartographer · Nav2) | 웹 화면에서 켤 때 |

게이트웨이(웹 화면)는 로봇이 켜지면 혼자 뜨지만, 모터 · 센서 · 카메라를 쓰는 **로봇 기능**은 따로 켭니다. 웹 화면의 **로봇 켜기**나 Physical Labs 의 **▶ 로봇 켜기**를 누르면 위 표의 모터 드라이버부터 데이터 노드까지가 한꺼번에 켜집니다. 지도 작성 · 자율 주행은 그 뒤에 웹 화면에서 따로 켭니다.

*웹 화면의 대시보드. 위쪽 막대에 연결 상태 · 조작 권한 · 비상 정지가, 왼쪽에 화면 메뉴가, 가운데 `기능` 칸에 로봇 · 지도 작성 · 자율 주행 버튼이 있습니다.*

### 2.2. PC (노트북)

PC 에는 쓰는 방법에 따라 아래 가운데 필요한 것만 둡니다.

| 프로그램 | 하는 일 | 필요한 때 |
|---|---|---|
| 웹 브라우저 | 웹 화면을 엽니다. 설치할 것이 없습니다. 태블릿 · 휴대폰 브라우저로도 열 수 있습니다 | 언제나 |
| Physical Labs | 텔레오퍼레이션 · 데이터 수집 · 훈련 · 추론, 팔 보정, 카메라 미리보기 | 데이터를 모아 학습시키고 추론할 때 |
| PC 에이전트 | 노트북에 꽂은 리더암의 관절 값을 웹 화면으로 보내는 작은 프로그램 (Linux) | 웹 화면에서 리더암으로 팔을 움직이거나 리더암을 보정할 때만 |

### 2.3. 둘을 잇는 통로

PC 의 프로그램은 와이파이나 랜선으로 로봇의 두 입구에 붙습니다.

| 누가 | 로봇의 어디로 | 무엇을 |
|---|---|---|
| 웹 브라우저 | 게이트웨이 (포트 8080) | 화면 · 상태 · 버튼 명령 · 카메라 영상 |
| Physical Labs | 게이트웨이 (포트 8080) | 로봇 켜기 · 끄기, 팔로워 보정, 비상 정지, AP 전환, 카메라 미리보기 |
| Physical Labs | 데이터 노드 (포트 5555 · 5556) | 텔레오퍼레이션 · 데이터 수집 · 추론의 명령과 관측 |
| PC 에이전트 | 게이트웨이 (포트 8080) | 리더암 관절 값 (초당 30번) |

> **정보** ℹ️ `INFO`
> <br>**로봇을 움직이는 것은 한 번에 한 화면뿐입니다** 웹 화면에서 **조작 권한 받기**를 한 화면이 있으면 Physical Labs 의 텔레오퍼레이션 · 데이터 수집 · 추론이 `웹 화면이 조작 중입니다` 로 막힙니다. 반대로 Physical Labs 가 조작 중이면 웹의 팔 시작 · 자율 주행 · 보정 · 네트워크 전환이 `PC(ZMQ, <IP>)가 조작 중입니다` 로 거절됩니다. 자세한 규칙은 [대시보드와 조작 권한](/docs/a-go/web-dashboard)에 있습니다.

> **경고** ⚠️ `WARN`
> <br>**비상 정지를 누르면 팔의 힘도 빠집니다** 비상 정지는 바퀴를 세우고 바퀴 · 팔 토크를 끕니다. 편 팔과 잡은 물건이 떨어지니, 팔을 편 채 다룰 때는 팔 아래를 비워 두세요. 비상 정지는 웹 화면의 모든 메뉴와 Physical Labs 의 텔레오퍼레이션 · 데이터 · 추론 화면에서 누를 수 있습니다.

## 3. 어떻게 쓰나요? — 세 가지 길

목적에 따라 길을 고릅니다. 웹 화면과 Physical Labs 는 함께 쓰는 경우가 많습니다. 지도 작성 · 자율 주행은 웹 화면에만 있고, 데이터 수집 · 학습 · 추론은 Physical Labs 에만 있기 때문입니다.

| 길 | 이런 분께 | PC 준비 | 할 수 있는 것 |
|---|---|---|---|
| **웹 화면만** | 설치 없이 로봇을 바로 움직여 보고 싶을 때 | 브라우저 | 상태 보기, 로봇 켜기 · 끄기, 키보드 · 화면 패드로 바퀴 조작, 팔(팔로워) 보정, 지도 작성 · 자율 주행, 센서 · 로그, 네트워크 설정 |
| **Physical Labs** | 시범을 보여 데이터를 모으고 학습 · 추론하고 싶을 때 | Ubuntu 24.04 노트북, Physical Labs(.deb) 0.1.9, SO-101 리더암 | 리더암 + 키보드 텔레오퍼레이션, 데이터 수집, 훈련, 추론, 팔 보정 |
| **개발자 (ROS 2)** | 로봇 코드를 읽고 고치거나 ROS 2 로 직접 다루고 싶을 때 | SSH, (선택) PC 의 ROS 2 Jazzy · RViz | 노드 · 토픽 다루기, 코드 고쳐 로봇에 올리기 |

### 3.1. 웹 화면만 쓰기

브라우저 주소창에 로봇 주소와 `:8080` 을 넣으면 바로 열립니다. 바퀴는 키보드(W/S 앞뒤 · A/D 좌우 · Q/E 회전)나 화면 패드로 움직입니다. 리더암으로 팔을 움직이려면 노트북에서 [PC 에이전트](/docs/a-go/pc-agent)를 함께 실행합니다. 시작은 [처음 접속하기](/docs/a-go/first-connection)와 [대시보드와 조작 권한](/docs/a-go/web-dashboard)입니다.

### 3.2. Physical Labs 로 쓰기

Physical Labs 는 로봇 설정부터 데이터 수집 · 훈련 · 추론까지 한 앱에서 하는 데스크탑 앱입니다. 앱에 로봇을 추가한 뒤 **연결 확인**과 **▶ 로봇 켜기**를 하면, 텔레오퍼레이션 · 데이터 · 훈련 · 추론 탭에서 A-Go 를 씁니다. 학습에는 NVIDIA GPU 가 있는 PC 를 권합니다 ([훈련](/docs/physical-labs/training)).

앱 자체의 설명은 [Physical Labs 소개](/docs/physical-labs)와 [설치와 첫 실행](/docs/physical-labs/install)에, A-Go 를 붙이는 방법은 [Physical Labs 연결](/docs/a-go/physical-labs-setup)에 있습니다.

> **정보** ℹ️ `INFO`
> <br>**새 A-Go 는 Physical Labs Ubuntu(.deb) 판에서 쓸 수 있습니다** 이 설명서는 Ubuntu(.deb) 0.1.9 기준입니다. Windows 판(최신 0.1.7)은 새 A-Go(ROS 2) 연결을 지원하지 않습니다. Windows 에서는 브라우저로 웹 화면을 쓸 수 있지만, PC 에이전트도 Linux 전용이라 리더암으로 팔을 움직이려면 Linux(Ubuntu) 노트북이 필요합니다. 앱은 [다운로드 페이지](/programs)에서 받습니다.

> **팁** 💡`TIP`
> <br>**Physical Labs 는 켤 때 인터넷이 필요합니다** 앱이 시작할 때 구글 로그인을 확인하기 때문입니다. 노트북을 로봇의 AP(인터넷 없음)에 붙일 때는 인터넷이 될 때 앱을 먼저 켜 둔 뒤 와이파이를 바꾸세요. 켜 둔 앱은 그대로 계속 쓸 수 있습니다. 자세한 순서는 [Physical Labs 연결](/docs/a-go/physical-labs-setup)에 있습니다.

새 A-Go 에서 Physical Labs 의 **엔드이펙터** 탭과 **워크스페이스**(Yolo + Pick&Place)는 아직 지원하지 않습니다. 지도 작성 · 자율 주행은 앱에 없으므로 웹 화면에서 합니다.

### 3.3. 개발자 — ROS 2 로 직접 다루기

로봇 소프트웨어는 공개 저장소 4개로 나뉘어 있고, 그중 로봇 쪽 3개는 SD 카드 이미지에 들어 있습니다 (나머지 하나는 노트북에서 도는 PC 에이전트). SSH(`ssh roboseasy@<로봇 주소>`)로 들어가 `ros2` 명령으로 노드 · 토픽을 보고, PC 에서 고친 코드를 로봇에 올릴 수 있습니다. 저장소 지도 · 토픽 · 포트 · 배포 방법은 [저장소와 구조](/docs/a-go/developer)에 정리했습니다.

## 4. 처음이라면 이 순서로 읽으세요

1. **[PC]** [SD 카드 굽기](/docs/a-go/lekiwi-sd-card) — 카드를 새로 만들거나 복구할 때 봅니다. 받은 로봇에 카드가 이미 꽂혀 있다면 건너뜁니다.
2. **[로봇]** · **[웹 화면]** [처음 접속하기](/docs/a-go/first-connection) — 로봇을 켜고 와이파이 `lekiwi01` 에 붙어 웹 화면을 엽니다.
3. **[PC]** · **[웹 화면]** [유선 연결](/docs/a-go/lekiwi-wired-connection) · [네트워크 (AP · 공유기)](/docs/a-go/lekiwi-wifi-static-ip) — 랜선으로 붙거나, 로봇을 집 · 교실 공유기에 붙입니다.
4. **[로봇]** [카메라 연결](/docs/a-go/setup-cameraport) — 전방 · 손목 카메라가 제자리에 꽂혔는지 확인합니다.
5. **[웹 화면]** [대시보드와 조작 권한](/docs/a-go/web-dashboard) → [캘리브레이션](/docs/a-go/start-calibration) → [조작 (바퀴 · 팔)](/docs/a-go/start-teleoperation) — 로봇을 켜고, 팔을 보정한 뒤 바퀴와 팔을 움직여 봅니다. 웹에서 리더암을 쓰려면 [PC 에이전트 (리더암)](/docs/a-go/pc-agent)도 봅니다.
6. **[앱]** [Physical Labs 연결](/docs/a-go/physical-labs-setup) → [데이터 · 학습 · 추론](/docs/a-go/physical-labs-workflow) — 앱으로 시범 데이터를 모으고 학습시킵니다.

> **팁** 💡`TIP`
> <br>**팔과 Physical Labs 를 쓰기 전에 캘리브레이션부터 하세요** 새로 구운 카드에는 팔 보정 값이 들어 있지 않습니다. 보정이 없어도 웹 화면의 바퀴 조작은 되지만, 팔 조작과 Physical Labs 의 텔레오퍼레이션 · 데이터 수집 · 추론은 되지 않습니다 (보정이 없으면 로봇이 관측을 보내지 않습니다). 웹 화면의 `캘리브레이션` 화면이나 Physical Labs 의 `칼리브레이션` 탭에서 팔로워를 보정하고([캘리브레이션](/docs/a-go/start-calibration)), 이어서 **접은 자세 저장**도 해 두세요.

## 5. 이 설명서에서 쓰는 예시 값

명령과 화면 설명에 나오는 아래 값은 예시입니다. 내 로봇 · 내 환경에 맞게 바꿔 읽으세요.

| 항목 | 예시 값 | 설명 |
|---|---|---|
| 로봇 이름 (호스트 이름) | `lekiwi01` | 로봇 번호 1번. 번호가 N 이면 `lekiwiNN` (예: 7번은 `lekiwi07`) |
| 킷 번호 | `1` | 로봇 번호. 공유기 고정 IP 의 끝자리를 정합니다 |
| 처음 AP (로봇 와이파이) | 이름 `lekiwi01` · 비밀번호 `lekiwi01` | 이미지를 새로 구운 카드는 모든 로봇이 같습니다. 받은 로봇의 AP 이름이 다르면 그 이름을 씁니다 |
| AP 모드의 로봇 주소 | `192.168.4.1` | 웹 화면은 `http://192.168.4.1:8080` |
| 공유기 모드의 웹 주소 | `http://lekiwi01.local:8080` | 또는 `http://<로봇 IP>:8080` |
| 공유기 고정 IP | `192.168.0.201` | `192.168.0.(200 + 킷 번호)`. 공유기 대역이 `192.168.0.x` 일 때만 쓰고, 다른 대역에서는 자동 주소(DHCP)를 씁니다 |
| 로봇 계정 (SSH) | `roboseasy` | 비밀번호는 스페이스 한 번 |
| 리더암 보정 이름 | `leader` | 노트북에 꽂는 SO-101 리더암의 보정 이름. 이 설명서는 `leader` 를 씁니다 |
| PC 에이전트 conda 환경 | `lerobot060` | Python 3.12, `lerobot[feetech]==0.6.0` |
| Hugging Face 계정 | `HueyWoo` | 본인 계정 이름으로 바꿉니다 |
| Physical Labs | Ubuntu(.deb) 0.1.9 | 파일 `physical-labs_0.6.0-0.1.9_amd64.deb` |
| SD 카드 이미지 | `lekiwi1027.img.gz` | Ubuntu 24.04.4 · ROS 2 Jazzy · Raspberry Pi 4 용 |

## 6. 정리

- A-Go(LeKiwi)는 옴니휠 베이스 + SO-101 팔 + 전방 · 손목 카메라 + 라이다 · IMU 를 라즈베리파이 4 가 ROS 2 로 다루는 모바일 로봇입니다.
- 로봇을 켜면 게이트웨이(웹 화면, 포트 8080)가 저절로 뜨고, 모터 · 센서를 쓰는 로봇 기능은 **로봇 켜기**로 따로 켭니다.
- 웹 화면은 브라우저만으로 바퀴 조작 · 팔로워 보정 · 지도 작성 · 자율 주행을(리더암은 PC 에이전트와 함께), Physical Labs(Ubuntu 0.1.9)는 텔레오퍼레이션 · 데이터 수집 · 훈련 · 추론을 맡습니다.
- 로봇을 움직이는 것은 한 번에 한 화면뿐이고, 비상 정지는 팔의 힘도 뺍니다.

처음 시작한다면 카드부터 준비합니다. 받은 로봇에 카드가 이미 꽂혀 있다면 처음 접속하기로 바로 갑니다.
