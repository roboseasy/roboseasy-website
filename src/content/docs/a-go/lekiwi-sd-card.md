진행 순서는 다음과 같습니다.

1. [PC] 위의 이미지를 내려받습니다. (3절)
2. [PC] Raspberry Pi Imager로 이미지를 microSD 카드에 굽습니다. (4절)
3. [Pi] 구운 카드를 LeKiwi의 라즈베리파이에 꽂습니다. (5절)

LeKiwi의 두뇌인 라즈베리파이에는 PC와 달리 내장 저장장치가 없습니다. 운영체제부터 LeRobot, 모터와 카메라를 다루는 프로그램까지 모든 것이 **microSD 카드** 한 장에 들어 있고, 라즈베리파이는 이 카드로 부팅합니다. RoboSEasy는 LeKiwi에 필요한 소프트웨어를 미리 설치해 둔 **microSD 카드 이미지**를 제공합니다. 이 페이지에서는 이 이미지를 내려받아 카드에 굽고, 카드를 LeKiwi에 꽂는 것까지 안내합니다.

> 🎯 **학습 목표**
>
> - microSD 카드 이미지가 무엇이고, 왜 카드에 구워야 하는지 설명할 수 있다.
> - 이미지를 내려받고, SHA-256 해시로 파일이 온전한지 확인할 수 있다.
> - Raspberry Pi Imager로 이미지를 microSD 카드에 굽고, 굽기가 성공했는지 확인할 수 있다.
> - 카드를 LeKiwi의 라즈베리파이에 꽂고, 첫 부팅 때 지켜야 할 점을 설명할 수 있다.

## 1. 왜 이미지를 구워야 할까?

### 1.1. 이미지란?

**이미지**(image)는 카드 한 장의 내용을 통째로 파일 하나로 만든 것입니다. 운영체제, 설치된 프로그램, 설정 파일이 폴더 구조까지 들어 있어서, 이 파일을 다른 카드에 그대로 기록하면 똑같은 카드가 한 장 더 만들어집니다. 이렇게 기록하는 일을 **굽는다**(burn, flash)고 합니다.

일반 파일 복사와는 다릅니다. 이미지는 카드의 파티션 구조와 부팅 영역까지 포함하므로, 파일을 카드에 복사해 넣는 것이 아니라 **전용 도구로 카드에 기록**해야 합니다.

### 1.2. 이미지에 들어 있는 것

직접 설치하면 한 단계씩 시간이 걸리고 버전이 어긋나기 쉬운 것들이 이미 갖춰져 있습니다.

| 항목 | 내용 |
|---|---|
| 운영체제 | Ubuntu 24.04 LTS (라즈베리파이용 64비트) |
| 로그인 계정 | `roboseasy` (비밀번호: 스페이스 한 번) |
| LeRobot | 0.6.0 — 가상환경 `~/lerobot060_venv` (PyTorch 2.7.1 포함) |
| 호스트 실행 스크립트 | `~/start_lekiwi_host.sh`, `~/stop_lekiwi_host.sh` |
| 개체 초기화 스크립트 | `~/clone_init.sh` ([고정 IP · 무선 연결](/docs/a-go/lekiwi-wifi-static-ip)에서 사용) |

## 2. 준비물

| 준비물 | 설명 |
|---|---|
| **microSD 카드** | 16GB 이상(32GB 권장). Class 10 / U1 이상의 정품 카드를 사용합니다. 속도가 느리거나 정품이 아닌 카드는 굽는 도중 오류가 나거나 부팅이 불안정해지는 일이 잦습니다. microSD를 SD 어댑터에 끼워 쓴다면 어댑터의 잠금(LOCK) 스위치를 풀어 둡니다. |
| **카드 리더기** | PC에 microSD 카드를 꽂을 수 있는 USB 리더기 (노트북 내장 슬롯도 가능) |
| **PC** | 윈도우 10/11 또는 우분투. 내려받은 파일을 둘 여유 공간 약 4GB |
| **인터넷** | 약 3.1GB 파일을 내려받습니다 |

이미지는 빈 공간을 줄여 약 8.6GB로 만들어 두었습니다. 처음 부팅할 때 카드 전체 크기만큼 자동으로 늘어나므로, 16GB·32GB·64GB 어느 카드를 써도 됩니다.

> **경고** ⚠️ `WARN`
> <br>카드의 기존 내용이 모두 사라집니다. 보관할 파일이 있다면 먼저 다른 곳에 복사해 둡니다.

## 3. [PC] 이미지 내려받기

### 3.1. 내려받기

이 페이지 위쪽의 **lekiwi1017.img.gz 내려받기** 링크([바로가기](https://drive.google.com/file/d/1mw_a29DbTX2mdmw7uAhStiYnHgJCSA0u/view?usp=sharing))를 눌러 Google 드라이브를 엽니다. 파일 이름의 숫자는 이미지를 만든 날짜(10월 17일)입니다.

1. 드라이브 화면 오른쪽 위의 **다운로드(↓)** 아이콘을 누릅니다.
2. "파일이 너무 커서 바이러스 검사를 할 수 없습니다"라는 화면이 나오면, 이 파일은 RoboSEasy가 제공하는 이미지이므로 **무시하고 다운로드**(영어: Download anyway)를 누릅니다.
3. 브라우저의 다운로드 표시가 완료될 때까지 기다립니다. 인터넷 속도에 따라 수 분에서 수십 분 걸립니다. 파일은 보통 다운로드 폴더에 저장됩니다.

파일 크기는 약 3.1GB, 정확히는 3,355,957,538바이트입니다. 프로그램에 따라 3.1GB 또는 3.4GB로 보일 수 있는데, 1GB를 1,024MB로 세는지 1,000MB로 세는지의 차이입니다.

> **정보** ℹ️ `INFO`
> <br>**압축을 풀면 안 됩니다** 파일 확장자는 `.img.gz` 입니다. 아래에서 사용할 굽기 도구가 압축된 상태 그대로 읽어서 카드에 기록합니다.

### 3.2. 파일 확인 (권장)

3GB가 넘는 파일은 내려받는 도중 끊기거나 일부가 깨지는 일이 있습니다. 깨진 이미지로 카드를 만들면 부팅이 안 되거나 이상하게 동작하므로, 먼저 **SHA-256 해시**를 계산해 아래 값과 같은지 확인합니다. 해시는 파일 내용에서 계산한 지문과 같아서, 한 비트만 달라져도 전혀 다른 값이 나옵니다.

```text
08511a3fd485e04671b9c7c291677205df493e90aee4ce85cdeab4f2b75af1db  lekiwi1017.img.gz
```

#### 우분투

브라우저가 파일을 저장한 다운로드 폴더에서 아래 명령을 실행합니다. `성공`(영어 화면은 `OK`)이 나오면 정상입니다.

```bash
# 우분투
cd "$(xdg-user-dir DOWNLOAD)"
echo "08511a3fd485e04671b9c7c291677205df493e90aee4ce85cdeab4f2b75af1db  lekiwi1017.img.gz" | sha256sum -c
```

`xdg-user-dir DOWNLOAD` 는 다운로드 폴더의 위치를 찾아 줍니다. 한국어로 설치한 우분투에서는 이 폴더가 `~/Downloads` 가 아니라 `~/다운로드` 입니다. 다른 폴더에 받았다면 `cd` 로 그 폴더에 들어갑니다.

#### 윈도우

시작 메뉴에서 `cmd` 를 검색해 명령 프롬프트를 열고 입력합니다. 파일을 다른 폴더에 받았다면 경로를 바꿉니다.

```bat
:: 윈도우
certutil -hashfile "%USERPROFILE%\Downloads\lekiwi1017.img.gz" SHA256
```

3GB가 넘는 파일이라 계산이 끝날 때까지 수십 초 걸릴 수 있습니다. 출력된 64자리 값이 위와 같으면 정상입니다. 대소문자는 구분하지 않습니다.

값이 다르면 파일을 지우고 다시 내려받습니다. 두 번 받아도 계속 다르면 이 문서의 값이 오래된 것일 수 있으니, 굽지 말고 [RoboSEasy에 문의](/contact)합니다.

> **팁** 💡`TIP`
> <br>위 값은 이 페이지의 `lekiwi1017.img.gz` 전용입니다. 이 페이지에 적힌 이름과 다른 파일을 받았다면 비교하지 말고 RoboSEasy에 문의합니다.

## 4. [PC] microSD 카드에 굽기

굽기 도구로는 라즈베리파이 공식 도구인 **Raspberry Pi Imager**를 씁니다. 무료이고 우분투와 윈도우 모두에서 쓸 수 있으며, `.img.gz` 파일을 압축을 풀지 않고 바로 카드에 기록합니다.

### 4.1. Raspberry Pi Imager 설치

#### 우분투

터미널에서 설치합니다.

```bash
# 우분투
sudo apt update
sudo apt install -y rpi-imager
```

> **팁** 💡`TIP`
> <br>apt로 설치되는 버전(1.8.x)은 공식 사이트의 최신판(2.x)과 화면이 다릅니다. 4.2절에 두 화면의 버튼 이름을 함께 적었습니다. 공식 사이트의 **Download for Linux (x86_64)**로 받은 AppImage를 쓰려면 받은 폴더에서 `chmod +x imager_latest_amd64.AppImage` 로 실행 권한을 준 뒤 실행합니다. `libfuse.so.2` 오류로 실행되지 않으면 `sudo apt install -y libfuse2t64` 를 먼저 설치합니다.

#### 윈도우

[라즈베리파이 소프트웨어 페이지](https://www.raspberrypi.com/software/)에서 **Download for Windows**를 눌러 설치 파일을 받아 실행합니다.

### 4.2. 카드에 굽기

> **정보** ℹ️ `INFO`
> <br>**Imager는 버전과 PC 언어에 따라 화면 문구가 다릅니다** 윈도우 설치 파일은 2.x(단계별 화면), 우분투 `apt` 버전은 1.8.x(버튼이 모여 있는 한 화면)입니다. 한국어 PC에서는 한국어로 표시되므로 아래 단계에 한국어 문구와 영어 문구를 함께 적었고, 2.x와 1.8.x가 다를 때는 구분해 적었습니다. 문구는 버전에 따라 조금 다를 수 있습니다.

1. microSD 카드 외의 USB 저장장치(외장 하드, USB 메모리)는 모두 뽑아 두고, 카드를 카드 리더기에 꽂아 PC에 연결합니다.
2. **Raspberry Pi Imager**를 실행합니다. 윈도우에서는 관리자 권한을 묻는 창이 뜨면 허용합니다. 우분투에서는 앱 목록의 **Imager** 아이콘(또는 터미널의 `rpi-imager` 명령)으로 실행하며, 쓰기를 시작할 때 로그인 암호를 묻는 창이 뜰 수 있습니다.
3. 장치 선택 단계(2.x 화면 제목 '라즈베리 파이 장치를 선택하세요', 1.8.x 버튼 **장치 선택**)에서 목록 맨 아래의 **No filtering**을 고릅니다. 이 문구는 영어로 표시됩니다. 이 선택은 운영체제 목록을 거르는 용도라서 직접 내려받은 이미지를 굽는 데는 영향이 없습니다. 2.x는 **다음**을 누릅니다.
4. 운영체제 선택 단계(2.x '운영 체제 선택', 1.8.x 버튼 **운영체제 선택**)에서 목록을 맨 아래로 내려 **사용자 정의 사용**(Use custom)을 고르고, 내려받은 `lekiwi1017.img.gz` 를 압축을 풀지 않은 그대로 선택합니다. 바로 위의 **삭제**(Erase)는 고르지 않습니다. 2.x는 **다음**을 누릅니다.
5. 저장소 선택 단계(2.x '저장 장치를 선택하세요', 1.8.x 버튼 **저장소 선택**)에서 **내 microSD 카드**를 고릅니다. 카드 용량이 맞는지 꼭 확인합니다. Imager는 10진수 단위로 보여 주므로 32GB 카드는 약 31.9GB로 보입니다. 다른 저장장치를 고르면 그 안의 데이터가 지워집니다. **시스템 드라이브 제외**(Exclude system drives)가 보이면 켜진 채로 둡니다. 2.x는 **다음**을 누릅니다.
6. 1.8.x만 해당합니다. **다음**(NEXT)을 누르면 OS 맞춤 설정을 적용할지 묻는데 **아니요**(NO)를 고릅니다. 이 이미지에는 계정·호스트명·네트워크 설정이 이미 들어 있는데, 맞춤 설정을 적용하면 Imager가 부팅 영역의 설정 파일(`user-data`)을 덮어써서 그 설정이 바뀌기 때문입니다. 2.x는 직접 내려받은 이미지에 이 단계가 나오지 않으며, **사용자 지정을 건너뛰기**(Skip customisation) 버튼이 보이면 그것을 누릅니다.
7. 쓰기를 시작합니다.
   - **1.8.x (우분투 apt 버전)**: "모든 데이터가 지워집니다. 계속하시겠습니까?" 창에서 카드 이름이 맞는지 확인하고 **예**(YES)를 누릅니다.
   - **2.x (윈도우 설치 파일, 우분투 AppImage)**: 요약 화면에서 **기록**(Write)을 누릅니다. "You are about to ERASE all data on: …" 창에서 카드 이름이 맞는지 확인하고, 2초쯤 뒤에 눌러지는 **이해합니다. 삭제하고 기록**(I understand, erase and write)을 누릅니다.
8. 쓰기가 끝나면 이어서 검증(Verifying)이 자동으로 진행됩니다. 둘 다 끝날 때까지 기다리고, **검증 건너뛰기**(Skip verification)나 취소는 누르지 않습니다. 카드와 리더기 속도에 따라 합쳐서 수 분에서 십수 분 걸립니다.
9. **쓰기 완료**(Write complete) 화면이 나오면 굽기가 끝난 것입니다. 2.x는 저장 장치가 자동으로 꺼졌다고 알려 주고, 1.8.x는 **계속**(CONTINUE)을 누릅니다. 그다음 카드를 뽑습니다.

윈도우에서는 카드를 다시 꽂았을 때 포맷하라는 창이 뜰 수 있습니다.

> **경고** ⚠️ `WARN`
> <br>**포맷하라는 창이 뜨면 취소를 누르세요** "드라이브의 디스크를 포맷해야 합니다"(영어: You need to format the disk in drive X: before you can use it) 같은 안내가 나와도 **디스크 포맷**은 누르지 않습니다. 카드에는 윈도우가 읽는 첫 번째 영역(`system-boot`)과 리눅스 형식이라 읽지 못하는 두 번째 영역이 있어서, 읽지 못하는 쪽에만 이 안내가 나옵니다. 포맷하면 방금 구운 이미지가 지워집니다. 실수로 포맷했다면 4.2절을 처음부터 다시 진행합니다.

### 4.3. (선택) 우분투에서 터미널로 굽기

GUI 없이 터미널만으로도 구울 수 있습니다. 우분투에서 카드 이름을 정확히 확인하는 데 자신이 있을 때만 사용합니다.

> **경고** ⚠️ `WARN`
> <br>`dd` 는 지정한 장치를 되돌릴 수 없게 덮어씁니다. 카드가 아닌 장치를 지정하면 **PC의 디스크가 지워질 수 있습니다.** 장치 이름을 `lsblk` 로 확인할 자신이 없다면 4.2절의 Raspberry Pi Imager를 사용합니다.

먼저 카드의 장치 이름을 찾습니다. **카드를 꽂기 전에 한 번, 꽂은 뒤에 한 번** 실행해서 새로 생긴 장치가 카드입니다.

```bash
# 우분투
lsblk -e7 -o NAME,SIZE,MODEL,TRAN,RM,MOUNTPOINTS
```

카드는 보통 `TRAN` 이 `usb`, `RM` 이 `1` 인 장치입니다. 크기는 카드 겉면보다 작게 보여서 32GB 카드는 약 `29.7G` 입니다. (`-e7` 은 snap이 만드는 `loop` 항목을 숨깁니다.) 노트북 내장 슬롯이라면 `mmcblk0` 으로 보입니다. 아래는 가상의 출력 예시입니다. `sda` 는 PC 안의 디스크이고 카드는 `sdb` 입니다.

```text
NAME     SIZE MODEL    TRAN RM MOUNTPOINTS
sda    476.9G SATA SSD sata  0
├─sda1   512M          sata  0 /boot/efi
└─sda2 476.4G          sata  0 /
sdb     29.7G SD/MMC   usb   1
├─sdb1   256M          usb   1 /media/…/system-boot
└─sdb2  29.5G          usb   1 /media/…/writable
```

SATA 디스크를 쓰는 PC에서는 `sda` 가 PC에 설치된 디스크이므로 카드로 착각하지 않습니다. `nvme0n1` 처럼 시스템이 설치된 장치도 절대 쓰지 않습니다.

확인한 이름을 `CARD=` 뒤에 적고(예: `/dev/sdb`), 마운트된 파티션을 해제한 뒤 압축을 풀면서 바로 카드에 기록합니다.

```bash
# 우분투
CARD=/dev/sdX    # sdX 를 카드 이름으로 바꿉니다 (예: /dev/sdb)
sudo umount "$CARD"?*
gunzip -c "$(xdg-user-dir DOWNLOAD)/lekiwi1017.img.gz" | sudo dd of="$CARD" bs=4M iflag=fullblock conv=fsync,nocreat status=progress
sync
```

`/dev/sdX` 를 바꾸지 않고 실행하면 `conv=nocreat` 때문에 '열기 실패' 오류만 나고 아무것도 쓰이지 않습니다. `umount` 가 '마운트되어 있지 않다'고 알려 주는 것은 괜찮습니다. 끝나면 마지막 줄에 `9230336512` 바이트를 복사했다고 나옵니다. 파일 관리자에서 카드의 꺼내기(⏏)를 눌러 안전하게 제거합니다.

> **팁** 💡`TIP`
> <br>진행 표시가 거의 100%가 된 뒤에도 `conv=fsync` 가 카드에 쓰기를 마무리하는 동안 멈춘 것처럼 보일 수 있습니다. 프롬프트가 돌아올 때까지 기다립니다. 압축 파일이 깨져 있으면 `unexpected end of file` 메시지가 나오고 카드가 중간까지만 쓰인 채 끝날 수 있으니, 3.2절의 해시 확인을 통과한 파일만 씁니다.

## 5. [Pi] LeKiwi에 카드 꽂기

1. LeKiwi의 전원이 꺼져 있는지 확인합니다.
2. 라즈베리파이의 microSD 카드 슬롯에 카드를 끝까지 밀어 넣습니다. 기존에 꽂혀 있던 카드가 있다면 빼고 새 카드로 바꿉니다.
3. 아직 전원은 켜지 않습니다. 랜선을 연결한 뒤 전원을 켜는 순서는 다음 페이지 [유선 연결](/docs/a-go/lekiwi-wired-connection)에서 안내합니다. 이미 켰다면 그대로 두고 랜선만 연결하면 됩니다.

전원을 처음 켜면 **첫 부팅은 보통 2~3분** 걸립니다. 카드 용량과 속도에 따라 더 걸릴 수 있습니다. 이 동안 라즈베리파이가 스스로 두 가지 일을 합니다.

- 줄여 두었던 저장 공간을 **카드 전체 크기로 늘립니다.**
- 이 카드만의 **SSH 호스트 키를 새로 만듭니다.**

이 작업은 처음 한 번만 합니다.

> **경고** ⚠️ `WARN`
> <br>첫 부팅 중에 전원을 끊거나 카드를 빼면 안 됩니다. 저장 공간을 늘리는 도중에 끊기면 카드가 손상될 수 있고, 그러면 4절부터 다시 구워야 합니다.

## 7. 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 드라이브에서 "현재 이 파일을 보거나 다운로드할 수 없습니다"(영어: Sorry, you can't view or download this file at this time)가 뜬다 | 최근에 너무 많은 사람이 이 파일을 받아서 Google이 일시적으로 막은 것입니다. 풀리기까지 **최대 24시간** 걸릴 수 있습니다. 급하면 Google 계정으로 로그인해 파일의 **사본 만들기**(⋮ 메뉴 또는 마우스 오른쪽 버튼)로 **내 드라이브에 복사**한 뒤, 내 드라이브에 생긴 사본을 내려받습니다. 내 드라이브에 약 3.1GB의 빈 공간이 필요하고, 다 받은 뒤에는 사본을 지워도 됩니다. |
| 내려받은 파일의 해시가 다르다 | 다운로드가 끊기거나 일부가 깨진 것입니다. 파일을 지우고 다시 받습니다. 두 번 받아도 계속 다르면 이 문서의 값이 오래된 것일 수 있으니 굽지 말고 [RoboSEasy에 문의](/contact)합니다. |
| Imager 파일 선택 창에 `lekiwi1017.img.gz` 가 보이지 않는다 | 기본 필터에 `.gz` 가 들어 있어 보통은 바로 보입니다. 선택 창이 열린 폴더(보통 다운로드)에 파일이 있는지 확인하고, 파일 이름이 `.crdownload` 나 `.part` 로 끝나면 다운로드가 아직 끝나지 않은 것이니 기다립니다. 그래도 안 보이면 파일 형식을 **All files**(모든 파일)로 바꿉니다. |
| 쓰기 또는 검증 중 오류가 나거나 카드가 '읽기 전용'(1.8.x는 '쓰기 금지된 SD card')으로 표시된다 | microSD 카드를 SD 어댑터에 끼워 쓴다면 어댑터 옆면의 잠금(LOCK) 스위치를 풀림 쪽으로 밉니다. 그다음 카드 리더기나 USB 포트를 바꿔 다시 시도합니다. 같은 카드에서 계속 실패하면 카드 불량일 수 있으니 다른 카드를 씁니다. |
| 쓰는 도중 `Error writing…`(쓰기 오류)나 용량 부족 오류가 난다 | 압축을 풀면 약 8.6GB(9,230,336,512바이트)라서 8GB 이하 카드에는 들어가지 않습니다. `.img.gz` 는 압축을 푼 크기를 Imager가 미리 알 수 없어 쓰기 전에 걸러 주지 못하고, 카드가 가득 차는 순간 쓰기 오류로 나타납니다. 16GB 이상 카드를 씁니다. |
| 굽고 나서 윈도우가 포맷하라고 한다 | **취소**를 누릅니다(4.2절 경고 참고). |
| 전원을 켜도 라즈베리파이가 부팅하지 않는다 | 배터리 스위치가 켜져 있는지, 배터리가 충분히 충전되어 있는지, 카드가 슬롯에 끝까지 들어갔는지 확인합니다. 그래도 안 되면 카드를 다시 굽습니다. |
| 다음 페이지에서 5분이 지나도 접속이 안 된다 | 먼저 [유선 연결](/docs/a-go/lekiwi-wired-connection)의 문제 해결 표(인터넷 공유 설정, 랜선 연결)를 확인합니다. 카드를 다시 굽는 것은 마지막에 시도합니다. |

## 8. 정리

- 라즈베리파이는 **microSD 카드**로 부팅하므로, LeKiwi를 쓰려면 이미지를 구운 카드가 필요합니다.
- **이미지**에는 Ubuntu 24.04, LeRobot 0.6.0 등 LeKiwi에 필요한 소프트웨어가 들어 있어 따로 설치하지 않아도 됩니다.
- 이미지는 `.img.gz` 그대로 **Raspberry Pi Imager**의 **Use custom**으로 구우며, 내려받은 뒤 **SHA-256**으로 파일을 확인할 수 있습니다.
- 첫 부팅 때는 저장 공간을 늘리는 작업이 진행되므로 전원을 끊지 않습니다.

카드가 준비되었습니다. 다음 페이지 [유선 연결](/docs/a-go/lekiwi-wired-connection)에서는 랜선으로 PC와 라즈베리파이를 연결하고 SSH로 접속합니다.
